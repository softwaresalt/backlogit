Plan unit **U1c** (partition 1). The single human-facing rendering of `CheckpointNonConformingError` offender paths.

Files: `internal/errors/checkpoint_errors.go`, `internal/errors/checkpoint_errors_test.go`.

Split out of 147.030-T / U1b in PR #377 cycle 17 to close gate finding **H4**. Cycle 16 made one method serve both a machine array and a human string, so the machine array inherited `strconv.Quote` escaping and a synthetic `+N more` element. The machine form is now raw (147.030-T / U1b); quoting lives here and nowhere else.

Add the exported method:

```go
// FieldPathsForDisplay renders the bounded offender paths for a human reader.
func (e *CheckpointNonConformingError) FieldPathsForDisplay() string
```

It reads `BoundedFieldPaths()`, renders each path through `strconv.Quote`, joins with `", "`, and appends an explicit human clause when the set is truncated, for example `... (5 more omitted, 1 shortened)`. Re-point `Error()` onto it.

Invariant this task establishes: no machine surface may call `FieldPathsForDisplay`, and no human surface may print `BoundedFieldPathSet.Paths` directly.

**Harness-first (cycle-31, P-002.1).** The compile-capable **source-shape** harness lands **first** and is observed red: the `TestU1c_` functions parse `internal/errors/checkpoint_errors.go` with `go/parser` and assert through `go/ast` that `FieldPathsForDisplay` is declared on `*CheckpointNonConformingError` with the stated signature and that `Error()` is re-pointed onto it. They compile against the pre-declaration tree and fail on assertions, not on a build error. The rendering then lands **together with its behaviour** in the green step. **No declaration stub is committed ahead of the harness** — in particular, no `return ""` body is landed to make the package compile.

**Test-lifecycle classification**: source-shape red harness first, then one green step. All three scaffolded `TestU1c_` functions fail on shape assertions before any production delta exists; the quoting, truncation-clause, and `Error()`-delegation behaviour lands with the implementation as `TestU1cGuard_` regression guards.

Red verification: `go test -count=1 -run '^TestU1c_' ./internal/errors`.
