# SQL Schema Introspection in db Package

Add `IntrospectSchema(ctx context.Context, db *sql.DB) ([]TableSchema, error)` to `internal/db/schema.go`.

## Approach

- Query `sqlite_master` for table names, use `PRAGMA table_info` for columns, `PRAGMA index_list` + `PRAGMA index_info` for indexes
- Open a read transaction for schema consistency
- Validate table names from `sqlite_master` before interpolating into PRAGMA queries
- Add `index_list` and `index_info` to `allowedPragmas` in `gate.go`
- Add `slog.Debug` logging for introspection steps
- Identify FTS virtual tables via SQL containing `fts5`

## Acceptance Criteria

- `IntrospectSchema` returns at least `items`, `item_deps`, `commit_links`, `stash_entries`, `item_links`, `stash_links`, `item_logs`, `item_log_entries`, `items_fts`, `item_log_entries_fts` tables
- Column metadata matches the known schema
- FTS virtual tables are identified correctly
- Works on an empty database after `EnsureSchema`

## Implementation Notes

- Files: `internal/db/schema.go`
- Test files: `internal/db/schema_gen_test.go` (extend existing)
- Execution: test-first
- Patterns: `EnsureSchema`, `existingColumns` in `internal/db/schema_gen.go`
- Dependencies: none
