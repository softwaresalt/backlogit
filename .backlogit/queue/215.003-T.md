## Objective

Expose a server-owned operation-coordinator / full-shutdown drain API (`(*Server).CloseCoordinator() error` and `(*Server).Shutdown() error`) in `internal/mcp/session_mux.go` and track/drain admitted in-flight handlers in `OperationCoordinator.Close()` (`internal/mcp/coordinator.go`) while restoring `(*Server).CloseAllSessions()` to pure session-only semantics (`0D073C21` / `092-DL` / Unit U3a).

## Scope and Affected Files

* **Domain**: `code` (`internal/mcp`)
* **Execution posture**: `test-first`
* **Affected files (3)**:
  * `internal/mcp/coordinator.go`
  * `internal/mcp/session_mux.go`
  * `internal/mcp/session_mux_test.go`

## Implementation Details

1. In `internal/mcp/coordinator.go` (`OperationCoordinator`), track and drain all admitted in-flight handlers across `Execute` and `Close`:
   * Add `admitMu sync.Mutex` and `activeHandlers sync.WaitGroup` to `OperationCoordinator`.
   * In `(*OperationCoordinator).Execute`, immediately before executing `next(ctx, req)` (after admission tokens/grants are acquired), synchronize final admission against `c.closed` under `c.admitMu`: if `c.closed` is already closed, release admission resources and return `coordinatorBusy("mutation_queue_full")`; otherwise call `c.activeHandlers.Add(1)` while holding `c.admitMu` and `defer c.activeHandlers.Done()` so every admitted handler is tracked until its frame returns (including on panic unwinding).
   * In `(*OperationCoordinator).Close() error`, close `c.closed` under `c.admitMu` inside `c.closeOnce.Do`, wait for `<-c.loopDone`, and then wait for `c.activeHandlers.Wait()` before returning `nil`, guaranteeing that `Close()` (and therefore `CloseCoordinator()` and `Shutdown()`) never returns while any admitted in-process `InvokeTool` or session tool handler is still executing against `s.Workspace`.
2. In `internal/mcp/session_mux.go`, remove `if s.coordinator != nil { result = errors.Join(result, s.coordinator.Close()) }` from `(*Server).CloseAllSessions()` so `CloseAllSessions()` stops session admission, cancels active sessions, and joins their drains without closing `s.coordinator`.
3. Add `func (s *Server) CloseCoordinator() error` (which calls `s.coordinator.Close()` when `s.coordinator != nil`, idempotently) and `func (s *Server) Shutdown() error` (which calls `errors.Join(s.CloseAllSessions(), s.CloseCoordinator())`) to `*mcp.Server` in `internal/mcp/session_mux.go`.
