Plan unit **U10b** (partition 5). Runtime verification of acceptance, quarantine evidence integrity, and the recovery sweep.

Files: none. Runs entirely inside the scratch workspace 147.019-T / U10 created; appends to the tracked closure artifact.

**The recovery sweep runs against a scratch mirror, never the live directory.** U10 requires every file under `.backlogit/checkpoints/` to be byte-unchanged, while the nine-file acknowledgement requires a sweep that succeeds on every other file there. The two cannot both hold against the live corpus, so the sweep operates on a copied mirror under `docs/scratch/checkpoint-verification/mirror/`, with all CLI invocations bound by `--cwd` to the mirror root and using bare filenames.

U10''s six-point execution contract applies unchanged, including the cycle-17 operation-class split.

**Cycle-17 narrowed evidence-pair claim.** The payload move uses `moveNoReplace` and is genuinely no-clobber; the **sidecar** is written with `atomicfile.WriteFileAtomic`, documented as an idempotent upsert, and therefore **replaces** an existing destination. The pair is protected in aggregate only because the payload move runs first and refuses the collision before the sidecar step is reached. Assert exactly that - payload no-clobber and the pair intact after a refused second quarantine - and make **no** claim that the sidecar write is itself no-replace. Cycles 16 and earlier stated the stronger claim; it is false against the shipped code. Sidecar hardening is follow-up stash `A12BBAFA`.

**Restore row withdrawn (cycle 16):** the executable restore procedure was withdrawn on security grounds (stash `35A27CD0`), so no row executes it.

**Teardown moved to 147.041-T / U10c (cycle 17):** U10c consumes this workspace, so tearing it down here would destroy U10c''s inputs.
