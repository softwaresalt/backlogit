Unit 3: Implement the core MergeSync function in internal/db/merge_sync.go.

Types: MergeSyncResult (Added/Changed/Deleted/Relocated []SyncEntry, StashRefreshed/LogsRefreshed/FallbackUsed/DryRun bool, FallbackReason string), SyncEntry (ID, Path string).

Function MergeSync(ctx, workspacePath, database, manifest, dryRun) (MergeSyncResult, map[string]FileEntry, error):
1. BuildManifest to get current state
2. ComputeDiff against provided manifest
3. ShouldFallback check — if yes, call Rehydrate + BuildManifest, return with FallbackUsed: true
4. If dry-run, return diff without applying
5. Apply incremental changes in RetryWrite-wrapped transaction: parseMarkdownArtifact → UpsertItemTx for added/changed, DeleteItemTx for deleted, UpsertItemTx for relocated
6. If stash.jsonl in diff → rehydrateStash (full rebuild, R8)
7. If logs/*.jsonl in diff → rehydrateItemLogs (full rebuild, R8)
8. Return new manifest and result

Pattern: Rehydrate Phase 3 batch (rehydration.go:108-175), RetryWrite usage.
All errors propagate (compound learning: batch-failure-anti-pattern). Depends on Units 1+2.

Verification:
- Add/modify/delete/relocate artifact → sync detects and indexes
- Exceed threshold → fallback to full rehydrate
- Dry-run returns diff without DB changes
- Stash/log JSONL change triggers respective rebuild
- go test -race ./internal/db/... passes
