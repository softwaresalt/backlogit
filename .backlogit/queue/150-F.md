title: Remove CleanupCheckpoints Windows pre-Remove data-loss window
updated_at: 2026-08-29T16:46:21.6293635Z

CleanupCheckpoints in internal/events/checkpoint_lifecycle.go calls os.Remove(dst) before os.Rename(path, dst) on Windows (lines 435-438). If rename fails after remove succeeds, any previously archived copy at dst is destroyed. Same data-loss pattern as CB71B412/149-F in syncWriteFileAtomic. Go 1.24.0 os.Rename uses MoveFileExW(MOVEFILE_REPLACE_EXISTING) which replaces atomically without pre-Remove. Fix: remove the Windows pre-Remove block and unused runtime import. Source: 132-S adversarial review T1 finding, stash 11FFF601.
