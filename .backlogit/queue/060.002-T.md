# BranchProfile Aggregation and Artifact ID Extraction

Create `BranchProfile` type, `AggregateBranches` function, and `ExtractArtifactIDs` utility.

## Approach

- Create `internal/telemetry/branch_metrics.go`
- `BranchProfile` struct: branch, branch_type, sessions, total_tokens, avg_tokens, model_calls, tool_calls, avg_peak_util, task_count, pr_number, shipment_id, feature_id, first_seen, last_seen
- `AggregateBranches(sessions []SessionSummaryRecord) []BranchProfile`: group by branch, filter ghost sessions via `IsGhostSession(s)`, compute totals/averages, sort by LastSeen desc
- `ExtractArtifactIDs(branch string) (shipmentID, featureID string)`: parse `feature/{NNN}-f-*`→featureID, `ship/{NNN}s-*`→shipmentID, `chore/stage-{NNN}-s-*`→shipmentID

## Acceptance Criteria

- `AggregateBranches` correctly groups sessions by branch with accurate totals/averages
- Ghost sessions are excluded from aggregation
- `ExtractArtifactIDs` handles all known branch patterns and edge cases
- Empty sessions returns empty slice
- Sort order is LastSeen descending
