Trust-anchor mutation WRITE-OUTCOME taxonomy + fail-closed audit contract (behavior). Carved from 168.005-T (cycle-1 items 3/9); REDUCED per cycle-3 item 13 to the MINIMUM implementable mutation+audit-failure contract. It does NOT build a broad crash-recovery/doctor reconciliation subsystem: that broader auto-reconciliation is beyond stash 71F5C21F, is captured under P-021 (out of scope), and is NOT implemented here. There is NO cross-file atomicity claim: a config file + status + separate audit log cannot be atomically committed on a filesystem, so this task defines ONE implementable ordered protocol with typed write outcomes and fail-closed audit handling. Protocol (fixed order, each step fsynced): (1) write a durable INDETERMINATE MARKER recording the intended mutation; (2) apply the config+status mutation; (3) persist the audit event; (4) clear the marker. Typed write outcomes: a failure BEFORE step 2 yields ErrWriteNotApplied (state definitively unchanged, retry-safe); a failure AT/AFTER step 2 and BEFORE the marker clears yields ErrWriteIndeterminate, surfaced fail-closed with the marker left in place for operator visibility -- NO automatic roll-forward or re-emit here (that is the deferred recovery subsystem). Denied-path audit-failure (folded from the WITHDRAWN 168.019-T, cycle-3 item 13): a DENIED mutation (external-pin rejection) makes NO state change but MUST persist a denial audit; if that denial-audit write fails, the denial STANDS (fail-closed, no state change) and the outcome is a typed ErrAuditNotPersisted -- the audit error is NEVER ignored. Marker visibility: an outstanding indeterminate marker is surfaced by doctor as an EXISTING observability signal (no new recovery machinery). Domain: core (internal/core). TDD: RED behavior harness first with injected failures, observed failing. Depends on 168.005-T, 168.012-T. Executable scenarios (3): (a) an injected failure before the mutation returns ErrWriteNotApplied with no state change and the marker absent after; (b) an injected failure after the mutation but before the audit persists returns ErrWriteIndeterminate with the marker present and surfaced (no auto-reconcile); (c) a denied mutation whose denial-audit write fails returns ErrAuditNotPersisted with NO state change and the audit error surfaced (never ignored). Build/test: go build ./cmd/backlogit; go test ./internal/core/ -run TestTrustAnchorWriteOutcome. AC: (1) RED test first, observed failing; (2) ErrWriteNotApplied on pre-mutation failure (state unchanged, marker absent); (3) ErrWriteIndeterminate on post-mutation/pre-clear failure with the marker present and operator-visible (no auto roll-forward); (4) denied-path audit-write failure returns ErrAuditNotPersisted, no state change, audit error never ignored; (5) broad auto-reconciliation/doctor recovery explicitly out of scope (P-021), not implemented; (6) tests GREEN.
