EXACT BASELINE SCOPE (corrected): the frozen migration set is 548 tracked CRLF paths — 518 `*.go` + 30 `*.json` — established from the live read-only `git ls-files --eol` count on the baseline (the earlier `518` figure counted Go files only). 2-HOUR RULE vs FILE-COUNT HEURISTIC: this is ONE homogeneous, purely MECHANICAL line-ending migration whose PRIMARY bound — human-equivalent effort well under 2 hours — is met by a single pathspec-scoped command sequence (`.gitattributes` edit + one scoped `git add --renormalize` + one scoped worktree refresh + verification). SAFETY POSTURE (Freeze-scope + Careful mode): this unit runs under BOTH `Freeze-scope` and `Careful mode`.
- Freeze-scope: the migration set is FROZEN to exactly the 548 enumerated paths (plus `.gitattributes`); no path outside the frozen set may be staged or refreshed, and the set is captured once and reused for staging, refresh, and verification.
- Careful mode: each mutating step declares ProposedAction (the exact command), ActionRisk (index/worktree mutation over 548 tracked files; reversible via `git reset` / `git restore`), an explicit approval checkpoint, a rollback plan (`git reset` of the index and `git restore --worktree --source=HEAD` of the frozen set), and a recorded ActionResult (staged path set + verification outcome) before proceeding.

- CLEAN-TREE PRECONDITION (blocking): before staging anything, assert the working tree and index carry NO unrelated changes (`git status --porcelain` empty except the intended `.gitattributes` edit); FAIL closed and halt if any unrelated index/worktree change exists.

Changes:
- Add explicit `eol=lf` rules for `*.go` and `*.json`.
- The byte-exact golden JSON fixture MUST remain governed by `eol=lf` (LF-normalize its committed bytes and stage under `eol=lf`). The previously-allowed `-text` branch for the golden is REMOVED — do NOT pin the golden as `-text`. The golden is part of the fixed `*.json` set and is checked by U40 (`175.040-T`) and the U14 (`175.014-T`) workflow guard.
- Pin true binaries (`*.exe`, `*.db`, images, intentionally-binary fixtures) as `-text`.
- PATHSPEC-SCOPED RENORMALIZE (replaces the broad `git add --renormalize .`): capture the frozen 548-path set NUL-safe and renormalize ONLY that set, with `.gitattributes` staged separately:
  1. Enumerate NUL-safe: `git ls-files -z --eol -- '*.go' '*.json'`, filter to `w/crlf`/`w/mixed`, write the 548 paths to a temp pathspec file with NUL separators.
  2. Stage `.gitattributes` on its own: `git add -- .gitattributes`.
  3. Renormalize ONLY the frozen set: `git add --renormalize --pathspec-from-file=<temp> --pathspec-file-nul`.
  4. FAIL closed unless the staged EOL-migration set (`git diff --cached --name-only -z`) equals EXACTLY the frozen 548 paths PLUS `.gitattributes` — no unrelated text path may appear; any extra or missing path halts.
- PATHSPEC-SCOPED WORKTREE REFRESH (replaces whole-tree checkout): because `--renormalize` refreshes the INDEX but not the working tree, refresh ONLY the frozen set from the index using an equally pathspec-scoped op: `git restore --worktree --source=: --pathspec-from-file=<temp> --pathspec-file-nul` (or the equivalent `git checkout -- <frozen set>` restricted to the same NUL pathspec file). Do NOT use `git checkout-index -f -a` or any whole-tree removal/re-checkout.

Safety checks (corrected):
- Assert `git ls-files --eol` shows `w/lf` for all 548 tracked `.go`/`.json` ONLY AFTER the scoped worktree refresh; `w/lf` under `eol=lf` for the golden; `-text` for declared binaries.
- Content-identity (EOL-only proof): do NOT use `git diff --cached -w`. For each staged text path EXCLUDING `.gitattributes` and declared binaries, compare base vs index blob after canonicalizing ONLY CRLF->LF: `B = git cat-file blob HEAD:<path>`, `I = git cat-file blob :<path>`; replace every CRLF with LF (leaving all other bytes, including any bare CR, untouched); require `SHA-256(canon(B)) == SHA-256(canon(I))` for every path. Equal hashes prove ONLY line-ending bytes changed.
- Binary identity: do NOT treat `git diff --cached --numstat` `-`/`-` as byte-identity proof. Require each declared binary ABSENT from the staged diff, OR compare pre/post blob hashes (`git rev-parse :<path>`) and confirm identical.
