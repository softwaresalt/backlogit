Review finding AP-001 (P3): `TileRenderer.Bold` requires the caller to pass a TTY-detection result; no CLI command currently does this. All call sites pass `false`, meaning ANSI bold is never applied even when the output is a terminal.

**Recommended fix**: Add a small `isTerminal(w io.Writer) bool` helper (using `golang.org/x/term` or `os.Stdout` identity check) and pass the result to `format.NewTileRenderer()` in `list.go:newRenderer()`. The helper should return `false` when `w` is not `*os.File`.

**Affected files**: `internal/cli/list.go` (`newRenderer` helper), optionally `internal/cli/format/tile.go`.

**Review context**: `docs/closure/` review artifact for branch `shipment/034-b-cli-ux-output-formatting`.
