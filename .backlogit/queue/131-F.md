Refactor (behavior-preserving for core, additive-hardening for events): move the duplicated durable mkdir-all + directory-fsync mechanics from internal/core/durable_fs.go and internal/events/stream.go into a new internal/fsutil stdlib leaf package (mirroring the internal/atomicfile and internal/mdfront leaf pattern), then migrate both call sites. Preserve durable_writes triple-gated semantics and re-fsync-on-retry (U4); the shared primitive adopts core's superset semantics including the Finding-2 nested-partial-create ancestor re-confirm, which events gains as an additive fsync (D2). fsutil returns neutral errors; callers map onto blerrors.ErrWriteNotApplied (D1). Sentinels already live in the internal/errors leaf (not internal/core). Cover the leaf with table-driven unit tests; every pre-existing durable test must pass unchanged.
