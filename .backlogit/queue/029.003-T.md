Unit 3: Two related correctness fixes. (A) The SQL gate semicolon regex rejects valid queries with semicolons inside string literals. Add a stripStringLiterals helper that removes single-quoted content before applying forbiddenPatterns. Handle escaped quotes ('') by replacing them first, then strip remaining '...' pairs, and reject unterminated strings conservatively. (B) writeSectionsToFile processes all sections as a batch; if any section fails, ALL sections get appended (duplication bug). Change to process sections individually, distinguishing "not found" from structural errors.
