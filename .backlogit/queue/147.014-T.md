Plan unit **U7b**. Update the five MCP checkpoint tool descriptions.

Files: `internal/mcp/tools.go` (descriptions at `:176-224`), `internal/mcp/tools_test.go`, `.autoharness/backlog-registry.yaml` (only if it carries description text), `internal/cli/registry_parity_test.go` (re-run; unchanged unless it drifts).

Tool descriptions are the **only** contract most agents ever read; they are the primary context surface. Leaving them stale means an agent selects `resolve` for a legacy file, receives a refusal it was never told about, and burns a retry cycle.

Exact replacement strings (current text captured verbatim in the plan):

| Line | Tool | Delta |
|---|---|---|
| `:178` | `list_checkpoints` | append: ` A summary with needs_quarantine true is not safely rewritable; use quarantine_checkpoint, not resolve_checkpoint or abandon_checkpoint.` |
| `:189` | `get_checkpoint` | append: ` For a schema-valid document, returns conforming false when it carries unmodeled top-level keys; such a document cannot be resolved or abandoned. A schema-invalid document is refused before any conformance verdict is produced.` |
| `:196` | `resolve_checkpoint` | append: ` Refuses a stored document it cannot safely rewrite rather than replacing it: checkpoint_use_quarantine when the document is schema-invalid, checkpoint_non_conforming when it carries unmodeled top-level keys. Use quarantine_checkpoint instead.` |
| `:211` | `abandon_checkpoint` | append: ` Also refuses when the document carries unmodeled top-level keys.` |
| `:220` | `quarantine_checkpoint` | replace `malformed checkpoint file` → `checkpoint file that cannot be safely rewritten (malformed, schema-invalid, or carrying unmodeled top-level keys)` |

The `get_checkpoint` qualifier is load-bearing. `GetCheckpoint` runs `ValidateCheckpoint` and returns `ErrCheckpointInvalid` before any conformance result exists (`internal/events/checkpoint_lifecycle.go:~105-137`), so an unqualified promise of `conforming false` for every document with unmodeled top-level keys would describe a verdict the read path cannot produce for the nine legacy files. This table is reproduced verbatim in plan unit U7b; the two must not drift.
