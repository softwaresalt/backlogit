Export a WorkspaceRootCandidates() accessor from internal/core/workspace.go as the single owner of the two-name concept; back it with a private array so no importing package can mutate the closed set at runtime; never derive it from config. BACKLOGIT_WORKSPACE_DIR is a CLOSED SET: when set and non-empty it must equal one of the candidates exactly; any other value is a hard error. Unset means use precedence; empty means misconfigured and is an error. Candidate probing uses Lstat and REJECTS symlinks or reparse points, realpath-resolves and confirms lexical and resolved containment, requires config.yaml to be a regular file, distinguishes not-found from an indeterminate os.Stat error and FAILS CLOSED on indeterminate, and handles Windows case-insensitive aliases with os.SameFile semantics. Both candidates present with no override returns typed AmbiguousWorkspaceRootError{Roots []string} in internal/errors/workspace_errors.go. NewWorkspace resolves and canonicalizes the root ONCE and stores it; nothing re-reads the environment or re-probes mid-process. Files: internal/core/workspace.go, internal/errors/workspace_errors.go.
