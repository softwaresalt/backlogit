Plan unit **U8b**. Cross-surface parity from one stored state.

Files: `tests/checkpoint_parity_test.go`. **No production change.**

U6/U6b/U7/U7b/U8 each assert their own surface in isolation. Nothing yet asserts that CLI, MCP, and the `events` read layer answer the **same** question about the **same** bytes. Governed-operation parity is an explicit repo contract (`docs/design-docs/governed-operation-parity.md`), and the failure mode this feature exists to prevent is precisely surfaces disagreeing about one file.

Write **one** legacy checkpoint into a scratch workspace, then assert all three surfaces from that single stored state.

**Posture: regression guard — this unit is the parity contract itself.**

<!-- BEGIN:acceptance-criteria -->
- One legacy file is written once; CLI, MCP, and `events` are all read from that single state
- `events.GetCheckpoint` → `conforming: false`; MCP `get_checkpoint` → `conforming: false`; CLI `checkpoint get` → the same
- All three refuse `resolve` with a message naming quarantine
- The file is byte-identical after all three surfaces have been exercised
<!-- END:acceptance-criteria -->
