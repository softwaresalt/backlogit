Behavior RED harness pinning the **flat-manifest non-member-ancestor safety contract** (spec §0.5
point 8 / SBLK-R28; plan §0.4 rev6). It closes the concurrency gap that survives the rev5 flat-scope
tasks: `174.057-T` removes unlisted covering-feature ancestors from the outer artifact-mutation lock
set (`rollbackIDs`/`lockArtifactMutations`, `internal/core/shipment_lifecycle.go:603-612`), but the
**separate** non-member covering-feature **status-rollup** path is preserved —
`snapshotNonMemberFeatureStatuses` (`:598`, snapshot) plus `restoreRolledUpNonMemberFeatures` (the
in-line revert at `:684`, the deferred early-return fallback at `:496`, and the indeterminate branch
inside `classifyShippedEventAppendFailure` at `:927`). Because the unlisted ancestor is no longer in
the lock set, a mutation to that ancestor **between the snapshot and the restore** is silently
overwritten when the restore blindly writes the snapshotted status back — a lost update (P1
concurrency defect). The flat-manifest-consistent contract is that **shipment ship/rollback must not
mutate, snapshot, restore, or lock any non-member artifact absent from the explicit manifest** (the
shipment control record is the SOLE exemption — it is not a `custom_fields.items` member but must be
locked/snapshotted/transitioned because the ship mutates its own status) — a
hierarchy-derived non-member ancestor receives NO status-rollup handling at all, so there is nothing
to overwrite. Asserts BEHAVIOR only; introduces no production change.

Determinism uses seams that **already exist in production today** (so the harness compiles against
current code and is RED now): `persistArtifactPreLockHook func(artifactID string)`
(`internal/core/shipment.go:840`; the existing `withConcurrentArchivedStatusMutation` helper drives
it to inject a single synchronous mutation at a precise persist boundary) and the `persistArtifactWriteFn`
write-failure seam (used by `TestShipShipment_RestoresNonMemberFeatureEvenWhenShipFailsAfterRollup`
to force a deterministic rollback). No new production symbol is required by this harness.

Scenarios (<4, exactly 3):
1. **Unlisted ancestor receives no ship-originated status write (success path) + listed member
   feature still governed (control).** Manifest lists child task `T` whose parent feature `F` is NOT
   in the manifest and whose only recorded children become terminal on ship (the exact
   `ComputeParentStatus` rollup condition). After a successful ship: `F.Status` equals its pre-ship
   value AND `F` has NO shipment-originated `status_changed` event (`"child status rollup"` nor
   `"reverted unintended rollup from partial-feature ship"`). Control: a DIFFERENT shipment whose
   manifest lists the feature `Fm` explicitly still marks `Fm` `done` on ship (governed member
   status handling preserved). RED today: the cascade rolls `F` to `done` then the restore reverts
   it, so `F` carries both rollup and revert events; GREEN after `174.062-T` (cascade bounded to
   members; snapshot/restore removed).
2. **Concurrent mutation to the unlisted ancestor is never overwritten (success path).** Using
   `persistArtifactPreLockHook`, fire the hook at a **listed member's** persist boundary (a boundary
   that fires on BOTH current and fixed code, since `F` itself is never persisted after the fix) and,
   inside the hook, perform a concurrent-writer mutation setting `F` to a distinct sentinel status
   (e.g. `queued → active`) on the writer's own context. Let the ship complete successfully. Assert
   `F.Status == sentinel` — the concurrent value survives. RED today:
   `restoreRolledUpNonMemberFeatures` reverts `F` to the pre-ship snapshot, clobbering the sentinel;
   GREEN after `174.062-T` (no snapshot/restore of `F`). Anchoring on a member boundary (not on `F`)
   keeps the assertion RED-now / GREEN-after rather than vacuously green once `F` stops persisting.
3. **Concurrent mutation to the unlisted ancestor is never overwritten on rollback (failure path).**
   Force a deterministic post-snapshot ship failure via `persistArtifactWriteFn` (fail only the
   shipment-record write) and, via `persistArtifactPreLockHook` fired at a **listed member's** persist
   boundary, inject a concurrent mutation setting `F` to a sentinel status before the deferred
   compensation runs. Assert the ship returns the injected error AND `F.Status == sentinel` — the
   deferred `restoreRolledUpNonMemberFeatures` fallback neither restores nor overwrites it. RED today:
   the deferred fallback reverts `F` to the snapshot, clobbering the sentinel; GREEN after `174.062-T`
   (deferred non-member fallback removed). A member-boundary anchor keeps the injection deterministic
   on both current and fixed code.

AC: (1) the harness FAILS against the current snapshot/restore + cascade-rollup code and PASSES after
`174.062-T`; (2) asserts an unlisted ancestor feature receives no shipment-originated status write on
the success path (no rollup, no revert); (3) asserts a concurrent mutation to an unlisted ancestor is
preserved on BOTH the success and the forced-rollback paths (never overwritten by ship recovery);
(4) asserts an explicitly-listed member feature still receives its governed `done` status (control);
(5) uses only production seams that exist today (`persistArtifactPreLockHook`, `persistArtifactWriteFn`),
introduces no production change, and does not restore any archived/superseded artifact. Domain: tests.
