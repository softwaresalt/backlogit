Regression guard for the OPEN/EXTENSIBLE docline base contract (scope reclassification for PR #241). Symlink/realpath filesystem containment is removed from this task: production docline containment is lexical-only via core.SafeResolve, and ApplyMigration explicitly adds no realpath containment, so a test-only task cannot deliver external-target rejection without implementing production behavior (out of scope, not implemented here). Instead, prove that representative optional extension keys (e.g. the backlogit-owned size, size_source, size_ruleset_version) added to in-scope docs do NOT break base docline ingestion, lint, or migration, and that docline does not assume ownership of extension semantics (extension keys are preserved/tolerated and never validated or emitted by docline). One file, <5 functions, at most three scenario groups; reuses production internal/docline.Scope() and existing decode; no schema or containment changes.
