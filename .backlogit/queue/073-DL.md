## Chosen Direction

<!-- BEGIN:chosen-direction -->
O11 Governed Test Runtime Budget. SOURCE OF TRUTH: new package internal/testbudget (policy constants + formula + static counter, with provenance and revisit criteria in its package doc). FORMULA: timeout = max(Floor, ceil_to_step(N_max x PerTestReference x Headroom)), Floor 10m (never below Go's default), Step 5m (limits go test cache-key churn), PerTestReference 900ms (0.862 s/test measured on the slowest governed platform, the Windows dev/Ship host, rounded up), Headroom 2.0, Ceiling 45m. N_max = the largest count of top-level `func TestXxx(*testing.T)` / `func FuzzXxx(*testing.F)` declarations in any one package directory (internal and external _test packages share one binary; build-tagged files are all counted, which is conservative; testdata/vendor/hidden/_ dirs and nested modules skipped). The counter is static (go/parser), deterministic per commit, and identical on every machine; N_max == 0 fails closed. Above the ceiling (N_max > 1500) the tool FAILS CLOSED with TEST_BUDGET_CEILING_EXCEEDED, forcing a Stage decision (partition/perf or a reviewed ceiling amendment) instead of silently growing. CURRENT VALUE: N_max = 885 (internal/core) -> 885 x 1.8s = 1593s -> 30m0s (886 after 174.073-T -> still 30m0s). ENTRY POINT: new cmd/test-budget (plain os.Args, not cobra): `go run ./cmd/test-budget print` prints the budget; `go run ./cmd/test-budget run <go test args>` prints a TEST_BUDGET derivation header, execs `go test -timeout=<budget> <args>` with streamed output and the child's exit code, REJECTS any caller -timeout/-test.timeout (single source of truth), and prints TEST_BUDGET_SUMMARY (largest package elapsed, utilization) plus TEST_BUDGET_WARN when any package used more than budget/Headroom. GOVERNED COMMANDS: full suite `go run ./cmd/test-budget run ./...`; CI `go run ./cmd/test-budget run -race -coverprofile=coverage.out ./...`. Targeted -run selectors keep explicit small timeouts. HANG DETECTION stays finite: every test binary still has a Go alarm (30m today) with goroutine dump; cmd/go kills at budget+1m. SURFACES migrated (13 dependency-ordered tasks under 174-F, each <=2 files, single domain): internal/testbudget; cmd/test-budget; ci.yml+release.yml; pre-push gates; Makefile+make.ps1; Ship agent+build-feature; workflow-policies+drift-ignore; fix-ci+github-pr-automation; AGENTS.md+constitution (PATCH 1.0.1); copilot-instructions+go.instructions; go-engineer+README; .autoharness harness-manifest TEST_COMMAND+workspace-profile; then a tests/integration coupling contract test. plugin/** is OUT of scope (product bundle for consumer workspaces that do not have cmd/test-budget). REVISIT CRITERIA: R1 TEST_BUDGET_WARN on any governed run -> Stage re-measures PerTestReference from the summary; R2 observed per-test cost > 1.25 x reference -> investigate a cost regression first, do not just raise; R3 ceiling hit or N_max >= 1200 (80% of ceiling) -> deliberate partition/perf follow-up; R4 new governed platform or -race on Windows -> measure before adopting; R5 a timeout whose running test is >= 60s old is a genuine hang/slow-test defect, never a budget raise. Constants change only through a Stage deliberation citing >= 2 governed-run summaries.
