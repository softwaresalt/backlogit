# Prompt for target tool directory, install backlogit binary, and configure .mcp.json on init and install

## Description

<!-- BEGIN:description -->
Enable `backlogit init` and `backlogit install` (`internal/cli/root.go` and `internal/cli/self_install.go`) to prompt the operator on interactive TTY or piped subprocess stdin (or accept `--tools-dir` / `BACKLOGIT_TOOLS_DIR`) for a target tool install directory (`.bin` default, `bin`, or a user-entered alternate workspace-relative directory), create the target tool directory in the workspace via pinned `*os.Root` directory handles if it does not yet exist, install `backlogit[.exe]` there prior to configuring `.mcp.json` (without letting `os.SameFile` short-circuit downstream provisioning), atomically create or merge `.mcp.json` via `map[string]json.RawMessage` (and reconcile existing `<storage_root>/toolchain.yaml` when present, without mutating `config.yaml`), record idempotent `/<tools_dir>/backlogit[.exe]` ignore rules in `.gitignore` and `.git/info/exclude`, and regenerate `docs/cli-reference/backlogit_init.md` via `cmd/gen-docs`.

**References**:
* Stash: `269D054D`
* Deliberation: `103-DL` (`docs/decisions/2026-11-19-init-install-target-tools-dir-mcp-config-deliberation.md`)
* Plan: `docs/plans/2026-11-19-init-install-target-tools-dir-mcp-config-plan.md`
<!-- END:description -->

## Goals

<!-- BEGIN:goals -->
* Prompt the operator on `backlogit init` and `backlogit install` (and support `--tools-dir` / `BACKLOGIT_TOOLS_DIR` plus piped subprocess stdin) with a default target install directory of `.bin` or `bin`, or allow typing an alternate workspace-relative directory, failing closed on invalid inputs or corrupt existing configs.
* Create the target tool directory in the target workspace via step-by-step pinned `*os.Root` handles if it does not yet exist and install `backlogit[.exe]` there prior to configuring `.mcp.json`, without letting `os.SameFile` skip `.mcp.json` or ignore-file provisioning.
* Atomically create or merge `.mcp.json` via `map[string]json.RawMessage` (preserving unrelated top-level and server entries, detecting `backlogit` aliases across `mcpServers` and `servers`, and reconciling `<storage_root>/toolchain.yaml` when present without mutating `config.yaml`), update `.gitignore` and `.git/info/exclude`, and regenerate `docs/cli-reference/backlogit_init.md`.
<!-- END:goals -->
