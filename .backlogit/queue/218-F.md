# Prompt for target tool directory, install backlogit binary, and configure .mcp.json on init and install

## Description

<!-- BEGIN:description -->
Enable `backlogit init` and `backlogit install` (`internal/cli/root.go`, `internal/cli/self_install.go`, `internal/cli/mcp_daemon.go`, and `internal/toolchain/verify.go`) to prompt the operator on interactive TTY or piped subprocess stdin (or accept `--tools-dir`, while disabling stdin reads and prompting when `--jsonrpc` is enabled so buffered JSON-RPC output cannot deadlock or include prompt text) for a target tool install directory (`.bin` default, `bin`, or a user-entered alternate workspace-relative directory), validate every component from the volume/filesystem root anchor handle and create missing suffixes handle-relatively (`openOrCreateValidatedWorkspaceRoot`, never path-based `os.MkdirAll`), perform handle-confined bootstrap writes (`writeWorkspaceBootstrapDefaults` on `storageHandle *os.Root`, rejecting redirected `<storage>/templates` and ancestor swaps during the defaults phase), run unconditional non-short-circuiting read-only preflight across all 5 sources (`defaultTargetToolsDir(cleanRoot string) (string, error)` / `resolveConfiguredDaemonBinaryRel`, treating `BACKLOGIT_WORKSPACE_DIR=""` as unset and validating proposed canonical `ToolEntry.ID = "backlogit"` against any `LockfilePath` provenance plus `start.ps1`/`start.sh` launcher migration compatibility) before any directory creation, binary install, `.mcp.json` write, or manifest write on every path (including `--tools-dir` overrides), create the target tool directory via pinned `*os.Root` directory handles if it does not yet exist, install `backlogit[.exe]` there prior to configuring `.mcp.json` (without letting `os.SameFile` short-circuit downstream provisioning), canonicalize the configured daemon entry into `mcpServers.backlogit` via `map[string]json.RawMessage`, reconcile existing `<storage_root>/toolchain.yaml` via override-aware (`BACKLOGIT_WORKSPACE_DIR`) typed `ToolchainManifest` load-mutate-validate-write (updating `loadToolchainManifest` in `internal/toolchain/verify.go`, canonicalizing any matched alias tool entry `ID` such as `"backlog-alias"` to `"backlogit"`, unconditionally populating `SHA256`, and atomically migrating existing `start.ps1` / `start.sh` launchers on `wsRoot` when relocating the pinned executable directory, without mutating `config.yaml` or introducing unrequested env vars), record literal-escaped `/<escapedToolsDir>/backlogit[.exe]` ignore rules in `.gitignore` and `.git/info/exclude`, and regenerate `docs/cli-reference/backlogit_init.md` via `cmd/gen-docs`.

## Goals

<!-- BEGIN:goals -->
* Prompt the operator on `backlogit init` and `backlogit install` (and support `--tools-dir` plus piped subprocess stdin, while selecting non-interactive flag/default without reading stdin or emitting prompt text in `--jsonrpc` mode) with a default target install directory of `.bin` or `bin`, or allow typing an alternate workspace-relative directory, running handle-relative root validation and unconditional non-short-circuiting preflight (`defaultTargetToolsDir(cleanRoot string) (string, error)`) on every path.
* Create missing workspace, storage (`logs`/`queue`/`templates`), and target tool directory suffixes handle-relatively via step-by-step pinned `*os.Root` handles, perform handle-confined bootstrap default/template/migration writes (`writeWorkspaceBootstrapDefaults`), and install `backlogit[.exe]` into the target tool directory prior to configuring `.mcp.json` without letting `os.SameFile` skip downstream provisioning.
* Pre-validate canonical `id: backlogit` against any `LockfilePath` provenance and `start.ps1`/`start.sh` launcher migration compatibility before any writes, canonicalize `.mcp.json` into `mcpServers.backlogit` via `map[string]json.RawMessage`, make `loadToolchainManifest` (`internal/toolchain/verify.go`) honor `BACKLOGIT_WORKSPACE_DIR` on dual-root workspaces (treating `""` as unset), reconcile existing `<storage_root>/toolchain.yaml` and `start.ps1`/`start.sh` launchers with unconditional `SHA256` population (without mutating `config.yaml`), write literal-escaped `.gitignore` / `.git/info/exclude` entries, and regenerate `docs/cli-reference/backlogit_init.md`.
<!-- END:goals -->
