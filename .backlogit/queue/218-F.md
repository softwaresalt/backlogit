Prompt the operator for a target tool install directory (.bin, bin, or custom workspace-relative directory) on backlogit init and backlogit install, create the directory via pinned *os.Root handles if absent, install backlogit[.exe] there prior to configuring .mcp.json, and configure .mcp.json, config.yaml tools_dir, and .gitignore/.git/info/exclude to use it (269D054D / 103-DL).

<!-- BEGIN:description -->
Enable `backlogit init` and `backlogit install` (`internal/cli/root.go` and `internal/cli/self_install.go`) to prompt the operator for a target tool install directory (`.bin` default, `bin`, or a user-entered alternate workspace-relative directory), create the target tool directory in the workspace via pinned `*os.Root` directory handles if it does not yet exist, install `backlogit[.exe]` there prior to configuring `.mcp.json`, and configure `.mcp.json`, `<storage_root>/config.yaml` (`tools_dir`), and `.gitignore` / `.git/info/exclude` to use that directory.
