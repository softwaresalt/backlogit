# Prompt for target tool directory, install backlogit binary, and configure .mcp.json on init and install

## Description

<!-- BEGIN:description -->
Enable `backlogit init` and `backlogit install` (`internal/cli/root.go`, `internal/cli/self_install.go`, and `internal/cli/mcp_daemon.go`) to prompt the operator on interactive TTY or piped subprocess stdin (or accept `--tools-dir`) for a target tool install directory (`.bin` default, `bin`, or a user-entered alternate workspace-relative directory), validate every component from the volume/filesystem root anchor handle and create missing suffixes handle-relatively (`openOrCreateValidatedWorkspaceRoot`, never path-based `os.MkdirAll`), run unconditional non-short-circuiting read-only preflight across all 5 sources (`defaultTargetToolsDir(cleanRoot string) (string, error)` / `resolveConfiguredDaemonBinaryRel`) before any mutation on every path (including `--tools-dir` overrides), create the target tool directory via pinned `*os.Root` directory handles if it does not yet exist, install `backlogit[.exe]` there prior to configuring `.mcp.json` (without letting `os.SameFile` short-circuit downstream provisioning), canonicalize the configured daemon entry into `mcpServers.backlogit` via `map[string]json.RawMessage` (and reconcile existing `<storage_root>/toolchain.yaml` via override-aware typed `ToolchainManifest` load-mutate-validate-write with unconditional `SHA256` population when present, without mutating `config.yaml` or introducing unrequested env vars), record literal-escaped `/<escapedToolsDir>/backlogit[.exe]` ignore rules in `.gitignore` and `.git/info/exclude`, and regenerate `docs/cli-reference/backlogit_init.md` via `cmd/gen-docs`.

**References**:
* Stash: `269D054D`
* Deliberation: `103-DL` (`docs/decisions/2026-11-19-init-install-target-tools-dir-mcp-config-deliberation.md`)
* Plan: `docs/plans/2026-11-19-init-install-target-tools-dir-mcp-config-plan.md`
<!-- END:description -->

## Goals

<!-- BEGIN:goals -->
* Prompt the operator on `backlogit init` and `backlogit install` (and support `--tools-dir` plus piped subprocess stdin) with a default target install directory of `.bin` or `bin`, or allow typing an alternate workspace-relative directory, running handle-relative root validation and unconditional non-short-circuiting preflight (`defaultTargetToolsDir(cleanRoot string) (string, error)`) on every path.
* Create missing workspace and target tool directory suffixes handle-relatively via step-by-step pinned `*os.Root` handles and install `backlogit[.exe]` there prior to configuring `.mcp.json`, without letting `os.SameFile` skip `.mcp.json` or ignore-file provisioning.
* Canonicalize `.mcp.json` into `mcpServers.backlogit` via `map[string]json.RawMessage`, reconcile existing `<storage_root>/toolchain.yaml` via override-aware (`BACKLOGIT_WORKSPACE_DIR`) typed `ToolchainManifest` load-mutate-validate-write with unconditional `SHA256` population (without mutating `config.yaml`), write literal-escaped `.gitignore` / `.git/info/exclude` entries, and regenerate `docs/cli-reference/backlogit_init.md`.
<!-- END:goals -->
