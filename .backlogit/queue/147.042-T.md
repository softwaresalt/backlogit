Plan unit **U3c** (partition 2). The verb-level conformance refusal harness that must be red before `147.037-T` / U14 migrates `ResolveCheckpoint` onto the guarded seam.

Files: `internal/events/checkpoint_lifecycle_conformance_test.go` (new). **No production change.**

Created in PR #377 cycle 20 to close the Group-B P1 raised on `147.007-T`. The resolve verb's conformance refusal contract - a valid-but-non-conforming document is refused with `ErrCheckpointNonConforming` naming the offender keys, bytes unchanged - is **delivered by U14**, not by U3b. After the migration `ResolveCheckpoint` calls `RewriteCheckpointFile`, whose U13 implementation returns the raw `*CheckpointNonConformingError` before any marshal or write, and that error unwraps to `ErrCheckpointNonConforming`. Cycle 19 attached the contract to U3b's own implementation task and called it red; the review rejected that because case 1 already passes once U14 lands.

This task is the harness the contract actually needs. It lands **before** `147.037-T` and fails against the pre-migration verb, which mutates and rewrites the document and returns `nil`.

**Test-lifecycle classification**: red harness only. One scaffolded function, `TestU3c_ResolveRefusesValidNonConformingDocument`, which fails on assertions. No green-step guard is added by this task; `147.037-T` turns the function green.

Red verification: `go test -count=1 -run '^TestU3c_' ./internal/events`.

**Persistent red across waves (cycle-32, P-002.6).** This task is a **red deliverable**: it completes in wave 4 with its harness landed and confirmed RED, and `147.037-T` / U14 turns it green in wave 8.
