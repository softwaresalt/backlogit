Plan unit **U7d**. Make the MCP `resolve_checkpoint` handler emit the disposition response shape.

Files: `internal/mcp/tools.go`, `internal/mcp/checkpoint_disposition_test.go`.

147.013-T extends `checkpointDispositionErrorResponse` with `code`, `filename`, and `unknown_fields`, but `handleResolveCheckpoint` (`internal/mcp/tools.go:1214-1232`) calls `domainError("resolve checkpoint", err)`. `domainError` (`internal/mcp/errors.go:148`) takes **no filename argument**, so it can never populate `filename`, and it does not build the disposition response at all — no routing change means no `code`, no `filename`, and no `unknown_fields` on a resolve refusal, however complete the mapping table is. Split out of 147.013-T because it is a third file and a distinct behavioural surface.

**Route by class, not wholesale.** Use the U1 predicate, imported through the existing `backlogiterrors` alias `internal/mcp/tools.go` already carries for `github.com/softwaresalt/backlogit/internal/errors` (U1 places the predicate in that package at `internal/errors/checkpoint_errors.go`, **not** in `internal/events`):

```go
if backlogiterrors.QuarantineIsRemedy(err) {
    return checkpointDispositionError("resolve checkpoint", filename, err)
}
return domainError("resolve checkpoint", err)
```

Passing the `op` string `"resolve checkpoint"` here is what U7 / 147.013-T's op-derived remediation reads to render `backlogit_resolve_checkpoint` as the wronged verb rather than the hardcoded `backlogit_abandon_checkpoint` a shipped resolve refusal would otherwise advertise. That op-derived behaviour is a formatter concern (147.013-T); this task pins it from the handler side.

A wholesale swap would regress the errors `checkpointDispositionError` does **not** name — `ErrCheckpointCannotResolveAbandoned` and `ErrCheckpointCorrupt` currently map to `validation_failed` through `domainError` and would fall to that function's `default: InternalError` tail. `ErrCheckpointNotFound` is safe either way: `checkpointDispositionError` handles it explicitly (`internal/mcp/errors.go:~358`) before its default.

The predicate is satisfied by both new refusals: U3 wraps the validity gate as `fmt.Errorf("%w: %w", ErrCheckpointUseQuarantine, valErr)` and U3b returns `ErrCheckpointNonConforming`, so `errors.Is` matches through the wrap.

<!-- BEGIN:acceptance-criteria -->
- Invoking the **`handleResolveCheckpoint` handler** on a schema-invalid legacy document returns `code: checkpoint_use_quarantine` with a populated `filename`, a `remediation` string naming `backlogit_resolve_checkpoint` (not `backlogit_abandon_checkpoint`) as the originating verb — pinning 147.013-T / U7's op-derived interpolation from the resolve side, so the formatter cannot silently regress to a hardcoded wronged verb — and explicitly asserts the payload is **not** `"error":"internal"`
- Invoking it on a valid-but-non-conforming document returns `code: checkpoint_non_conforming` with `unknown_fields` non-empty and a `remediation` string naming `backlogit_resolve_checkpoint` as the originating verb
- A missing file still returns the pre-existing not-found refusal, not `internal`
- An already-abandoned target still returns its pre-existing `validation_failed` refusal, proving the non-disposition path still reaches `domainError`
- Expected red: cases 1 and 2 fail (routing and both remediation-verb assertions); cases 3 and 4 are declared regression guards
