# Make LoadToolchainManifest honor BACKLOGIT_WORKSPACE_DIR for dual-root audits (U2a)

## Description

<!-- BEGIN:description -->
Implement Unit U2a of `docs/plans/2026-11-19-init-install-target-tools-dir-mcp-config-plan.md` (`218-F`, `269D054D` / `103-DL`): update `loadToolchainManifest(rootPath string) (*ToolchainManifest, error)` (`internal/toolchain/verify.go:164`), `verifyWorkspaceToolchain(ctx context.Context, rootPath string, m *ToolchainManifest) (*ToolchainVerificationReport, error)` (`internal/toolchain/verify.go:450`), and `validateMCPConfigPinning(rootPath, configPath string, m *ToolchainManifest) ([]ToolVerificationFinding, error)` (`internal/toolchain/verify.go:735`) so that (1) relative `m.WorkspaceRoot` values (such as `workspace_root: "."`) resolve against the target workspace `abs` (returned by `workspace(rootPath)`) rather than the ambient process `cwd` (`filepath.Abs(m.WorkspaceRoot)`), normalizing `m.WorkspaceRoot = abs` on the loaded manifest so `LoadToolchainManifest`, `VerifyWorkspaceToolchain`, `ValidateMCPConfigPinning`, and `AuditRepositoryToolchain` succeed when invoked from a different process `cwd`; and (2) `loadToolchainManifest` honors non-empty `BACKLOGIT_WORKSPACE_DIR` (`.backlog` or `.backlogit`) on dual-root workspaces while treating `BACKLOGIT_WORKSPACE_DIR=""` as unset and retaining `"ambiguous workspace storage"` refusal when unset/empty.

* **Execution Posture**: `test-first` (P-002.1)
* **Dependencies**: `blocks` on `218.001-T` (Unit U1); prerequisite to `218.008-T` (Unit U2b) and `218.002-T` (Unit U2)
* **Affected Files (2)**: `internal/toolchain/verify.go`, `internal/toolchain/verify_test.go`
* **Functions Changed (3)**: `loadToolchainManifest`, `verifyWorkspaceToolchain`, `validateMCPConfigPinning`
* **Test Scenarios (2)**: `dual_root_override_and_relative_workspace_root_load_verify_and_audit_from_different_cwd`, `dual_root_without_override_or_mismatched_workspace_root_fails_closed`

## Implementation Notes

<!-- BEGIN:implementation-notes -->
* In `loadToolchainManifest` (`internal/toolchain/verify.go:212`), `verifyWorkspaceToolchain` (`internal/toolchain/verify.go:459`), and `validateMCPConfigPinning` (`internal/toolchain/verify.go:744`), resolve `m.WorkspaceRoot` against `abs` when `!filepath.IsAbs(m.WorkspaceRoot) && filepath.VolumeName(m.WorkspaceRoot) == "" && !hasDriveOrUNCPrefix(m.WorkspaceRoot)` (`declared = filepath.Clean(filepath.Join(abs, filepath.FromSlash(strings.ReplaceAll(m.WorkspaceRoot, "\\", "/"))))`), verify `samePath(abs, declared)`, and in `loadToolchainManifest` normalize `m.WorkspaceRoot = abs` on the returned manifest.
* In `loadToolchainManifest`, inspect `override, hasOverride := os.LookupEnv("BACKLOGIT_WORKSPACE_DIR")`: when `hasOverride && override != ""`, validate `override == ".backlog" || override == ".backlogit"` and inspect `root.Lstat(override)` without rejecting the coexisting non-selected storage root; when `!hasOverride || override == ""`, retain the existing dual-root refusal.
