# Make LoadToolchainManifest honor BACKLOGIT_WORKSPACE_DIR for dual-root audits (U2a)

## Description

<!-- BEGIN:description -->
Implement Unit U2a of `docs/plans/2026-11-19-init-install-target-tools-dir-mcp-config-plan.md` (`218-F`, `269D054D` / `103-DL`): update `loadToolchainManifest(rootPath string) (*ToolchainManifest, error)` in `internal/toolchain/verify.go` (called by both `LoadToolchainManifest` at `internal/toolchain/types.go:93` and `AuditRepositoryToolchain` at `internal/toolchain/launcher.go:48`) so that when `BACKLOGIT_WORKSPACE_DIR` is set to a non-empty value (`.backlog` or `.backlogit`), it validates and selects that storage root on dual-root workspaces without failing on the coexisting non-selected root, while treating `BACKLOGIT_WORKSPACE_DIR=""` as unset and retaining `"ambiguous workspace storage"` refusal when both `.backlog` and `.backlogit` exist without an explicit override.

* **Execution Posture**: `test-first` (P-002.1)
* **Affected Files (2)**: `internal/toolchain/verify.go`, `internal/toolchain/verify_test.go`
* **Functions Changed (1)**: `loadToolchainManifest`
* **Test Scenarios (2)**: `dual_root_workspace_with_valid_override_loads_and_audits_selected_manifest`, `dual_root_without_override_or_with_invalid_override_fails_closed`
<!-- END:description -->

## Acceptance Criteria

<!-- BEGIN:acceptance-criteria -->
* **AC1 (RED-First Harness)**: `TestU2a_LoadAndAuditToolchainManifestHonorsWorkspaceDirOverride` in `internal/toolchain/verify_test.go` (`package toolchain`) directly calls pre-existing functions `loadToolchainManifest`, `LoadToolchainManifest`, and `AuditRepositoryToolchain` (without assigning changed function results to `want*`/`expect*`/`exp*`/`golden*` variables), compiles cleanly before `internal/toolchain/verify.go` is edited, and fails on runtime assertions (`Baseline == ResultFail`).
* **AC2 (2 Named `t.Run` Scenarios — Dual-Root Override Audit & Unset/Invalid Refusal)**:
  1. `dual_root_workspace_with_valid_override_loads_and_audits_selected_manifest`: On a workspace containing both `.backlog` (with a valid pinned `.backlog/toolchain.yaml`) and `.backlogit` (plus valid `.mcp.json`, `start.ps1`, `start.sh`, and `.bin/backlogit[.exe]`), setting `t.Setenv("BACKLOGIT_WORKSPACE_DIR", ".backlog")` allows `loadToolchainManifest(root)`, `LoadToolchainManifest(root)`, and `AuditRepositoryToolchain(context.Background(), root)` to load `.backlog/toolchain.yaml` and return `report.Valid == true && report.Violations == 0`.
  2. `dual_root_without_override_or_with_invalid_override_fails_closed`: On the same dual-root workspace, an unset or empty `BACKLOGIT_WORKSPACE_DIR=""` fails closed in `loadToolchainManifest(root)` and `AuditRepositoryToolchain(context.Background(), root)` with `corerrors.ErrValidation` (`"ambiguous workspace storage"`), while invalid overrides (`"   "`, `"invalid"`, `".git"`) or a symlinked `.backlog` directory also fail closed with `corerrors.ErrValidation`. Single-root workspaces with `BACKLOGIT_WORKSPACE_DIR=""` continue to auto-detect the single root.
* **Scoped Verification Command**: `go test -timeout=30m -count=1 -race -v -run '^(TestU2a_LoadAndAuditToolchainManifestHonorsWorkspaceDirOverride|TestU9_)' ./internal/toolchain`
