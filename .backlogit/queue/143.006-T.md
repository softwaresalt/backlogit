# Add RED harness for the doctor reconciliation audit

## Description

<!-- BEGIN:description -->
Unit 6. Test-only; NO production file. Add `internal/core/doctor_shipped_event_test.go` with three scenarios. Scenario 1: an archived shipment with `archived_status: shipped` and no shipped event yields exactly one `missing_shipped_event` finding; the same fixture with the event present yields none; and an archived shipment whose `archived_status` is NOT shipped (for example abandoned) yields none, proving the check filters on `archived_status` rather than on archived. Scenario 3: running the audit leaves every file under `.backlogit/logs` byte-identical (recursive compare, `fix_orphans` off). Doctor exit-code neutrality is asserted in 143.008-T because `core.Doctor` returns a report and an error, not an exit code. Execution posture: test-first (red phase).
