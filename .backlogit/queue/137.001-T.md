## Scope

1. Create a shared `jsonutil.MarshalReadable` (or similar) helper in
   `internal/jsonutil/` that wraps `json.Encoder` with `SetEscapeHTML(false)`.
2. Replace `json.Marshal(cp)` in `internal/events/checkpoint_lifecycle.go`
   with the new helper.
3. Replace `json.Marshal(cp)` in `internal/telemetry/checkpoint.go`
   with the new helper.
4. Optionally migrate existing `SetEscapeHTML(false)` call sites
   (`internal/stash/jsonl.go`, `internal/telemetry/events_harvest.go`,
   `internal/telemetry/harvest.go`) to use the shared helper.
5. Add regression tests verifying `>`, `<`, and `&` are emitted literally
   (not as `\u003e`, `\u003c`, `\u0026`) in checkpoint JSON output.
