Plan unit **U5**. Widen `QuarantineCheckpoint` classification to close the deadlock.

Files: `internal/core/checkpoint_disposition.go`, `internal/core/checkpoint_disposition_test.go`.

**This unit is mandatory, not optional.** Refusing on both mutation verbs without widening quarantine strands valid-but-non-conforming files with no disposition path at all.

Extend the in-memory classification so `validTarget` is `parse OK && validate OK && conformance OK`. Only a target satisfying all three is refused with `ErrCheckpointUseAbandon`. The verbatim `moveNoReplace` path, audit-before-move ordering, sidecar upsert, and `MutationEnvelope` compensation are unchanged.

The paired accept/refuse assertion is the single highest-value assertion in the plan. If it cannot be made to pass, **halt** rather than weakening it.

<!-- BEGIN:acceptance-criteria -->
- Expressed as one table so the paired assertions cannot be removed independently. **Three independent scenarios** (cycle-15 width normalization)
- **Scenario 1** — a valid-but-non-conforming **active** document is **accepted** by quarantine and **refused** by abandon in the same table row
- **Scenario 2** — a **conforming** document is refused by quarantine with `ErrCheckpointUseAbandon`, asserted across two rows of this one scenario: `status: "active"` and `status: "resolved"`. The `resolved` row carries the paired abandon-side postcondition `errors.Is(err, ErrCheckpointNotActive)`
- **Scenario 3** — a quarantined non-conforming document's archived bytes are byte-identical to the original
- Expected red: scenario 1's accept-half fails. Scenario 2's rows and scenario 3 are declared regression guards; P-004 is satisfied by scenario 1
- **State-conflict regression guards (already-green, pinned from retired U5b)**: the `status:"resolved"` rows of scenario 2 assert that such a conforming document is refused by `AbandonCheckpoint` with `errors.Is(err, ErrCheckpointNotActive)` and by `QuarantineCheckpoint` with `errors.Is(err, ErrCheckpointUseAbandon)` — both pre-existing shipped behaviour that this feature does not change, colocated so a future edit cannot silently decouple the two surfaces' state-class agreement. They are **additional rows of scenario 2, not independent scenarios** (counting them separately took this task to five effective scenarios and breached the non-negotiable `<4 independent scenarios` limit). They are green on landing and do not contribute to U5's red gate; they pin the out-of-scope state-conflict class named in the Decisions and Rationale (I3 table, row 3) as a tested invariant rather than an assumed one
