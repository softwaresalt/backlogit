Lightweight `backlogit_merge_sync` MCP tool that detects which `.backlogit/` files changed since the last sync and performs targeted cache updates. Full rehydrate remains the safety fallback for large deltas.

In-memory manifest on the MCP Server struct tracks file mtime/size/kind. On each merge_sync call, re-walks `.backlogit/`, diffs against manifest, and applies incremental upserts/deletes. Falls back to full rehydrate when delta exceeds threshold (50% or 50 files).

Key capabilities: dry-run mode, relocation detection, stash/log selective rebuild, structured JSON response with touched IDs and fallback status.
