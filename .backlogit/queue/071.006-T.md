Scope: in core.DoctorTarget acquire the per-task lock (U4) BEFORE reading the target file and defer-release it, so a concurrent mutation cannot modify a task while under validation (work item 2). Acquisition is NON-BLOCKING: if the lock is already held, return the busy result kind -> U2 maps it to exit code 4 (closes the lock<->timeout<->exit-code hole in the gate contract). Do not hold the lock across unrelated I/O. Files: internal/core/doctor_target.go (+ lock test). ACCEPTANCE CRITERIA: (1) validation acquires+releases the lock (sidecar present during, gone after); (2) when the sidecar is pre-held, target validation returns busy (not a mid-write read, not a block); (3) busy->exit 4 asserted end-to-end via U2; lock-integration test green.
