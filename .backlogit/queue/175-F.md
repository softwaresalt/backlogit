Covering release unit that makes all four mandatory quality gates — `go test ./...`, `go vet ./...`, `golangci-lint run`, and `gofmt -l .` — green by fixing the shared line-ending root cause (`.gitattributes text=auto` producing CRLF on Windows checkout) and the full enumerated golangci-lint debt, and installs a persistent CI line-ending guard so line endings cannot silently re-drift.

## Baseline

The authoritative baseline is the complete unbounded golangci-lint v2.13.2 structured run: exactly 489 findings across 160 files and 15 packages (459 errcheck + 30 staticcheck). It is captured with the same invocation semantics as `scripts/verify-baseline-lint.ps1` (`--max-issues-per-linter 0 --max-same-issues 0 --uniq-by-line=false`), recorded in `docs/decisions/2026-09-17-baseline-lint-inventory.md`, and bound to a committed machine-readable inventory at `docs/decisions/baseline-lint-inventory-489.json` (SHA-256 `7330d6baecc93e9cac4f4f96438a21565994106984f50c239cd1e6d8f86d2b66`) whose identity fields are `path`, `line`, `column`, `linter`, `message`, and `owner_task_id`. Every finding identity has exactly one owning remediation task.

## Release-unit contract

This release unit executes under the installed fail-closed `baseline-convergence` contract: task-scoped lint per member at intermediate waves, exact remaining-baseline monotonicity verified at each intermediate wave, and mandatory zero-warning global `golangci-lint run` only at terminal convergence. Same-wave sibling harnesses may remain red until wave convergence; no later-wave harness or lint scaffolding is created early.

## Members and roles

The release unit is decomposed into 94 executable members under four contract roles:

- `175.001-T` (U1) — `baseline-control`: the sole homogeneous mechanical line-ending migration (`.gitattributes` hardening plus a path-scoped worktree refresh/verification of the tracked CRLF working-tree paths). Its destructive worktree refresh requires immediate operator-only approval during Ship execution and is not pre-authorized here. U1 owns no baseline findings.
- 90 `finding-remediation` members — each owns 1 to 16 exact finding identities across at most 2 files or packages. When a single file carries more than 16 findings it is split into sequential slices; two tasks that mutate the same file never share a wave, and each later slice depends on the preceding slice for that file.
- `175.040-T` (U40) — `support`: the line-ending guard script task (`scripts/check-line-endings.ps1`). Depends on U1. Owns no baseline findings.
- `175.014-T` (U14) — `support`: the always-running `.github/workflows/line-endings.yml` integration task. Depends on U40. Owns no baseline findings.
- `175.012-T` (U12) — `terminal-convergence`: the sole terminal sink. Owns no lintable Go surface and no baseline findings.
