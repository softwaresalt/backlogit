# Telemetry Schema Reference Types

Create `FactTableSchema` struct and `DescribeFactTables`/`DescribeTelemetrySQLTables` functions.

## Approach

- Create `internal/telemetry/schema_ref.go` with `FactTableSchema` struct
- `DescribeFactTables()` returns schema metadata for 3 JSONL fact tables: tool-calls.jsonl, session-facts.jsonl, telemetry-sessions.jsonl
- `DescribeTelemetrySQLTables()` returns schema for 2 SQLite telemetry tables
- Use manual registry (not reflection) for reliability and control over descriptions
- Add drift-detection test comparing registry field names against struct JSON tags via reflection

## Acceptance Criteria

- `DescribeFactTables` returns 3 tables with correct field counts matching struct definitions
- `DescribeTelemetrySQLTables` returns 2 tables
- Field names match JSON tags on the Go structs
- No duplicate field names within a table
- Drift-detection test catches stale registry entries
