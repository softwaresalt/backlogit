Size, size_source, and size_ruleset_version are optional backlogit-owned extensions layered on the docline base Markdown/frontmatter contract; docline does not calculate, default, aggregate, validate domain semantics, or emit size. Bounded investigation for PR #241 found the current core.SetArtifactSize seam accepts only (id, size) with no provenance inputs and emits no event, item history is append-only JSONL (best-effort, warn-on-failure), no canonical XS-XL aggregation ruleset exists, and size writes reach atomicfile via FindArtifactPath/WalkDir without a SafeResolve containment check. Because provenance/history atomicity, ruleset ownership, and the workspace-containment boundary remain unresolved, this feature is a genuine time-boxed architecture spike composed ONLY of four sequenced research/decision tasks (108.001-T base-contract/extension ownership + typed surface inventory; 108.002-T mutation/provenance/JSONL history durability + failure ordering + containment; 108.003-T structured-composition membership/dedup/missing/ruleset; 108.004-T CLI/MCP parity + decision synthesis + explicit proceed/pivot exit record). Each task is <=2h and independently verifiable; the spike is capped at 8h total. It contains NO implementation tasks and asserts NO implementation readiness. Future implementation may be planned, harvested, and reviewed ONLY after 108.004-T records an explicit proceed decision. Harvested from stash D7B1B33D; traceability preserved.
