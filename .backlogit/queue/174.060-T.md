Behavior RED harness pinning the **flat-manifest archive-candidate contract** (spec §0.5 / SBLK-R28; plan §0.4) for `collectArchiveCandidateIDs` (`internal/core/shipment_lifecycle.go:767`). It closes two gaps the rev4 harness left uncovered:

1. **Terminal-but-not-archived descendant (RED-real).** The rev4 archive assertion used *already-archived* descendants, which the current collector **skips** (`item.Status == models.StatusArchived → continue`), so it never actually exercised the expansion and could pass against unfixed code. The genuinely RED case is an **unlisted terminal-but-not-`archived`** descendant of a listed member feature — status `done` or `accepted` (real terminal-release statuses) — which the current collector **does** append (`isTerminalReleaseStatus(item.Status) → candidates = append(...)`). This descendant must remain untouched and be **absent from `ArchivedIDs`** on ship.
2. **Unlisted linked deliberation.** `collectArchiveCandidateIDs` also appends **every linked deliberation** of a listed member feature (`linkedDeliberationIDs(feature)` → `candidates = append(candidates, deliberations...)`), a hierarchy-adjacent expansion with no explicit-membership guard. An unlisted linked deliberation must NOT be archived or touched on ship.

The harness compiles against current code and is RED until SCOPE-IMPL-2 (`174.058-T`) neutralizes both expansions in `collectArchiveCandidateIDs` (guarded by explicit membership per 133.004-T). Asserts BEHAVIOR only; no production change.

Scenarios (<4, exactly 3):
1. **Unlisted terminal-but-not-archived descendant excluded from archival** — a `done`/`accepted` descendant of a listed member feature whose ID is NOT in the manifest is absent from `ArchivedIDs` and is left untouched on ship (RED today: the collector appends terminal non-archived descendants of a member feature).
2. **Unlisted linked deliberation not archived/touched** — a deliberation linked from a listed member feature (via `source_deliberation_id`, description, or references) but NOT in the manifest is absent from `ArchivedIDs` and is not mutated on ship (RED today: the collector appends all linked deliberations).
3. **Archived-descendant projection retained (negative control)** — an already-`archived` unlisted descendant is neither archived again nor **restored** to satisfy scope; it stays archived and untouched. Preserves the archived-descendant coverage separately from scenario 1.

AC: (1) the harness FAILS against the current `collectArchiveCandidateIDs` expansion and PASSES after `174.058-T`; (2) asserts an unlisted terminal-but-not-archived (`done`/`accepted`) descendant is absent from `ArchivedIDs` and untouched; (3) asserts an unlisted linked deliberation is absent from `ArchivedIDs` and untouched; (4) asserts no archived/superseded artifact is restored to satisfy scope. Domain: tests. <4 scenarios.
