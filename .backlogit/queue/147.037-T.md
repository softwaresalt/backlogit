**Cross-unit obligation**: this migration is what delivers the resolve verb''s conformance refusal contract, because the seam returns the raw `*CheckpointNonConformingError` before any write and that error unwraps to `ErrCheckpointNonConforming`. The failing harness for that contract is `147.042-T` / U3c, which MUST be `harness-ready` and red before this task is claimed - enforced by the edge `147.037-T -> 147.042-T`. Completing this task turns `TestU3c_ResolveRefusesValidNonConformingDocument` green.
