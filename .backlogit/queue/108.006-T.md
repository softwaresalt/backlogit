SE-3b: Crash-safe append+write reconciliation at the size seam (core persistence). Scope tightened per Copilot G6 to stay <=2h and single-domain (internal/core/artifact_size.go): the doctor-side CLEAR-recovery reconcile moved to SE-3c (108.011-T). Owns the seam-side crash-safety: (1) op-id ingress on SizeMutation.OpID (a retry reuses the same OpID); (2) applied-check + predecessor capture before append: read current custom_fields.size_op_id C, PrevOpID=C; if C==OpID the write already landed => re-verify and re-UPSERT the artifact into the SQLite index before returning success (G2: SetArtifactSize writes the file at artifact_size.go:79 THEN db.UpsertItem at :90, so a write-succeeded/index-failed crash leaves a stale row; the applied-check path must repair the index, not skip it); (3) orphan dedup by OpID before append: scan the estimate-history stream for an event already tagged with this OpID; if present (write did not land, so C==PrevOpID) reconcile by completing the artifact write from the event pinned desired-state payload (CAS on PrevOpID) instead of appending a duplicate; (4) append the event tagged with OpID+PrevOpID carrying the complete presence-aware desired state (SET(value)/CLEAR(remove) per size, size_source, size_ruleset_version), fail-closed; (5) atomic write applies the desired state and sets custom_fields.size_op_id=OpID in the same mdfront write. Durability scope: PROCESS-crash safety only (G3) -- atomicfile.WriteFileAtomic and events.AppendEvent are both sync-free, so OS-crash/power-loss durability is OUT OF SCOPE for 099-S (tracked separately). Tests: forced append failure leaves no persisted change (fail-closed, no shared-JSONL truncation); write-succeeded/index-failed => retry re-upserts the index (G2); retry-from-orphan => the same OpID re-submitted while its event already exists and the artifact still shows PrevOpID detects the existing event, appends no duplicate, and completes the write (idempotent across the crash window); a fully-applied OpID short-circuits at the applied-check. Depends on 108.002-T (SE-3a). Files: internal/core/artifact_size.go.
