Make append+write crash-safe WITHOUT truncating the shared per-item JSONL (concurrent non-size writers don't hold the per-task lock; truncation = data loss, forbidden). Protocol under per-task lock: (1) SizeMutation.OpID optional (retry reuse); (2) capture current size_op_id as PrevOpID, short-circuit if ==OpID; (3) append event tagged OpID+PrevOpID (fail-closed); (4) atomic mdfront write persists size/provenance + reserved custom_fields.size_op_id=OpID. Doctor CAS on PrevOpID: apply fresh orphan only if current==PrevOpID; ==OpID already-applied; else stale/benign, never replayed. Files: internal/core/artifact_size.go, internal/core/doctor_target.go. Depends on SE-3a. <=2h, core persistence. See impl-plan SE-3b.
