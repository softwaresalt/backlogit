CLASSIFIES WITHOUT REWRITING. Reads the target and attempts parse plus schema validation IN MEMORY. A valid target is refused with ErrCheckpointUseAbandon; only a parse- or schema-invalid target proceeds. Bytes on disk are never re-serialized. On a malformed target: move the bytes verbatim to .backlogit/archive/checkpoints with a CLOBBER-REFUSE guard before the rename (ErrCheckpointDestinationOccupied), then write the sidecar as an IDEMPOTENT UPSERT so an F5 step replay converges. On a failed move after a partial step, rename back to the canonical path and log all diagnostics. Files: internal/core/checkpoint_disposition.go.
