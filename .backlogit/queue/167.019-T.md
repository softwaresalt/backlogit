Reload/CAS under lock (reconcile stale-snapshot clobber protection). AssociateCommit READS the full artifact BEFORE acquiring its locks (commits.go:60-102), so even with a coherent order its STALE pre-lock snapshot can OVERWRITE a completed reconciliation after locks are released (it writes archived_status back from the stale copy). Require AssociateCommit (and any snapshot-before-lock artifact writer that can touch a shipment frontmatter) to RE-READ/RE-VALIDATE the artifact AFTER acquiring its locks (read-under-lock or compare-and-swap on the on-disk state) so a stale snapshot cannot clobber reconcile archived_status:shipped write. This is a CLOBBER-safety requirement, independent of deadlock (A and B are bounded-wait; see 167.008). TDD: a test using an EXISTING competing writer (AssociateCommit — already implemented, and it reads-before-lock, commits.go:60-102) proves a stale pre-lock snapshot is prevented from clobbering a concurrent write. This deliberately does NOT depend on the reconcile symbol (still the 167.003 panic-body in this wave), so it turns GREEN in its own scheduled wave; the end-to-end reconcile-vs-AssociateCommit race assertion stays in 167.020 (RED harness) / 167.008 (green). Single domain (reload/CAS). Domain: code (concurrency). Deps 167.017. Blocks 167.020. SCOPE (PR #424 round 42): the snapshot-before-lock clobber applies to EVERY writer that loads the artifact via findArtifact BEFORE persistArtifact acquires B - not just AssociateCommit: AddDependency (dependencies.go:29), RemoveDependency (dependencies.go:135), AddArtifactLink (artifacts.go:929), and any other persistArtifact caller that reads-before-lock. PREFER a SHARED reload/compare-and-swap at the persist boundary (re-read the on-disk artifact under B and reject/merge if archived_status changed since the pre-lock snapshot) so ALL such writers are protected UNIFORMLY rather than patched individually. TDD covers a REPRESENTATIVE set (AssociateCommit + AddDependency + AddArtifactLink): each, holding a stale archived_status:active snapshot, MUST NOT restore active over a concurrent reconcile's archived_status:shipped.
