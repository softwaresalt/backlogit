# SQL Schema in Metadata Catalog

Integrate `IntrospectSchema` output into the `MetadataCatalog` response.

## Approach

- Add `SQLSchema []db.TableSchema` field to `MetadataCatalog` struct with JSON tag `"sql_schema,omitempty"`
- Pass `[]db.TableSchema` into `BuildMetadataCatalog` (not `*sql.DB`) to keep core package DB-agnostic
- In MCP handler `loadMetadataCatalog`, call `db.IntrospectSchema` and pass the result
- Update existing `TestBuildMetadataCatalog_ReturnsUnifiedCatalog` to verify the `sql_schema` field

## Acceptance Criteria

- `backlogit_get_metadata_catalog` response includes `sql_schema` array
- Each table entry has name, columns, indexes
- `items_fts` and `item_log_entries_fts` appear as virtual tables
- Existing catalog test still passes with nil schema (omitempty)
