# Validate and create target tool directory, install backlogit binary, and update ignore rules (U1)

## Description

<!-- BEGIN:description -->
Implement Unit U1 of `docs/plans/2026-11-19-init-install-target-tools-dir-mcp-config-plan.md` (`218-F`, `269D054D` / `103-DL`): reject line separators and control characters (`\r`, `\n`, `r < 0x20 || r == 0x7f`) before provisioning, create missing target tool directory segments via step-by-step pinned `*os.Root` directory handles (`ensureAndOpenTargetToolsDir`), generalize `installWorkspaceRuntimeExecutable(root, targetDir string)` to install `backlogit[.exe]` into any validated target tool directory without letting `os.SameFile` short-circuit downstream provisioning, and construct escaped literal Git ignore patterns (`escapeGitignoreLiteralPath`: escaping `\`, `*`, `?`, `[`, `]`, `#`, `!`, trailing spaces) in `ensureWorkspaceRuntimeIgnored(root, toolsDirRel, binName string)`.

* **Execution Posture**: `test-first` (P-002.1)
* **Affected Files (2)**: `internal/cli/self_install.go`, `internal/cli/self_install_test.go`
* **Functions Changed (4)**: `escapeGitignoreLiteralPath`, `ensureAndOpenTargetToolsDir`, `installWorkspaceRuntimeExecutable`, `ensureWorkspaceRuntimeIgnored`
* **Test Scenarios (3)**: `creates_target_dir_installs_binary_and_escapes_literal_gitignore_patterns`, `samefile_installed_binary_skips_self_overwrite_without_error`, `rejects_newlines_control_chars_traversal_and_redirected_target_directories`

## Acceptance Criteria

<!-- BEGIN:acceptance-criteria -->
* **AC1 (RED-First Harness)**: `TestU1_TargetToolDirectoryCreationBinaryInstallAndIgnoreEntries` in `internal/cli/self_install_test.go` (`package cli`) directly calls pre-existing functions `installWorkspaceRuntimeExecutable`, `ensureWorkspaceRuntimeIgnored`, and `selfInstallBeforeBinaryReplaceHook` (without assigning changed function results to `want*`/`expect*`/`exp*`/`golden*` variables), compiles cleanly before `internal/cli/self_install.go` is edited, and fails on runtime assertions (`Baseline == ResultFail`).
* **AC2 (3 Named `t.Run` Scenarios — Escaped Literal Gitignore Rules, `os.SameFile` Non-Short-Circuiting, and Line-Separator/Redirected Refusal)**:
  1. `creates_target_dir_installs_binary_and_escapes_literal_gitignore_patterns`: Calling `installWorkspaceRuntimeExecutable` and `ensureWorkspaceRuntimeIgnored` with `".tools/custom"` and metacharacter paths such as `"tools[1]"`, `"tools*"`, `"#tools"`, and `"!tools"` creates missing directory segments on `wsRoot` via pinned `*os.Root` handles, installs `backlogit[.exe]` with executable permissions (`mode & 0o111 != 0` on POSIX), and records literal-escaped patterns (`/.tools/custom/backlogit[.exe]` and `/tools\[1\]/backlogit[.exe]`, verified via `git check-ignore` on `tools[1]/backlogit[.exe]`) once in `.gitignore` and `.git/info/exclude`.
  2. `samefile_installed_binary_skips_self_overwrite_without_error`: Invoking `installWorkspaceRuntimeExecutable` when `selfInstallExecutablePathFn` points to the already-installed `<targetDir>/backlogit[.exe]` (`os.SameFile`) skips only the file copy/rename without error or truncation.
  3. `rejects_newlines_control_chars_traversal_and_redirected_target_directories`: Target tool directories containing `\n`, `\r`, or control characters (`"tools\n!secret"`, `"tools\r\nother"`), traversal (`"../escape"`), reserved (`".git"`), symlink/junction segments, or mid-flight swaps via `selfInstallBeforeBinaryReplaceHook` fail closed with `corerrors.ErrValidation` before provisioning or writing outside the workspace root.

## Implementation Notes

<!-- BEGIN:implementation-notes -->
* Reject `\r`, `\n`, and control characters (`r < 0x20 || r == 0x7f`) before any directory creation or ignore-entry construction.
* Escape Gitignore metacharacters (`\`, `*`, `?`, `[`, `]`, `#`, `!`, trailing spaces) in `escapeGitignoreLiteralPath` so literal paths like `tools[1]` match `tools[1]/backlogit[.exe]` in Git.
