## Objective

Self-install the runtime executable into the workspace storage directory root (`.backlog/` or `.backlogit/`) during `backlogit init` and `backlogit install`, and idempotently wire ignore entries in `.gitignore` and `.git/info/exclude` (`17214531` / `090-DL` / Unit U6).

## Scope and Affected Files

* **Domain**: `code` (`internal/cli`)
* **Execution posture**: `test-first`
* **Dependencies**: `blocks` on `215.001-T` (Unit U1, for `atomicfile.ReplaceTempFileInRoot`) and `215.004-T` (Unit U3b)
* **Affected files (3)**:
  * `internal/cli/root.go`
  * `internal/cli/self_install.go`
  * `internal/cli/init_workspace_dir_test.go`

## Implementation Details

1. In `internal/cli/root.go` (`newInitCommand`), add `Aliases: []string{"install"}` (keeping `Use`, `Short`, `Long`, `Example`, and flags unchanged so `cmd/gen-docs` output in `docs/cli-reference/` has zero drift, and checking all `Close`/`fmt.Fprint*` errors per `TestU175_051_LintFix`). Keep `cmd.CalledAs() != "install"` (`backlogit init`) target-directory resolution **100% unchanged** — `init` always refuses an existing `.backlogit` directory and always initializes `<root>/.backlog` (even if `BACKLOGIT_WORKSPACE_DIR=.backlogit` is set in the environment, preserving `u12InitBacklogitWorkspace` in `TestU12_*`). When `cmd.CalledAs() == "install"`, resolve the target storage root to an existing `.backlog` or `.backlogit` directory (or honor `BACKLOGIT_WORKSPACE_DIR`, defaulting to `.backlogit` when neither exists) without failing the legacy-root check.
2. Create `internal/cli/self_install.go` implementing `installWorkspaceRuntimeExecutable(root, storageDir string) (string, error)` and `ensureWorkspaceRuntimeIgnored(root, storageDir, binName string) error` using **strictly handle-relative (`*os.Root`) reads, temp creation, permission changes, and publication** (closing all `*os.Root` and `*os.File` handles before returning so Windows directory renames immediately after `init` never hit `ERROR_ACCESS_DENIED`):
   * Open `wsRoot, err := os.OpenRoot(root)` and `storageHandle, err := wsRoot.OpenRoot(storageDir)` after verifying `root` and `storageDir` are non-reparse directories.
   * **Runtime binary installation**: Resolve the running binary via `os.Executable()` (with an injectable seam `selfInstallExecutablePathFn`), verify `os.Lstat` + `core.IsSymlinkOrReparsePoint` and `os.SameFile` on the opened source handle; inspect `storageHandle.Lstat(binName)` (rejecting symlinks, reparse points, or directories with `corerrors.ErrValidation`); if `binName` already exists and `os.SameFile(srcInfo, dstInfo)` is true, return early as a no-op (avoiding Windows self-overwrite `ERROR_SHARING_VIOLATION`). Otherwise create the temp file **handle-relatively** via `tmpFile, err := storageHandle.OpenFile(tmpName, os.O_CREATE|os.O_EXCL|os.O_WRONLY, 0o755)`, verify `os.SameFile(openedStat, lstatAfterOpen)` via `tmpFile.Stat()` and `storageHandle.Lstat(tmpName)`, copy the source binary bytes, set executable permissions **on the open temp file handle** via `tmpFile.Chmod(0o755)` (or `storageHandle.Chmod(tmpName, 0o755)` before publication — NEVER pathname `os.Chmod(dstPath, 0o755)` which could follow a swapped leaf!), call `tmpFile.Sync()` and `tmpFile.Close()`, re-verify `storageHandle.Lstat(binName)` + `core.IsSymlinkOrReparsePoint`, and publish `tmpName` -> `binName` **handle-relatively** via `atomicfile.ReplaceTempFileInRoot(storageHandle, tmpName, binName, true)`.
   * **Ignore-file wiring (`.gitignore` and `.git/info/exclude`)**: For `.gitignore` in `wsRoot` (and for `exclude` in `gitInfoRoot, err := wsRoot.OpenRoot(".git/info")` when `.git` and `.git/info` exist as non-reparse directories under `wsRoot.Lstat`), perform **handle-relative reads** (`targetRoot.Lstat(name)` + `core.IsSymlinkOrReparsePoint` + `targetRoot.OpenFile(name, os.O_RDONLY, 0)` + `os.SameFile`), **handle-relative temp creation** (`targetRoot.OpenFile(tmpName, os.O_CREATE|os.O_EXCL|os.O_WRONLY, mode)`), **handle-relative permission setting** (`tmpFile.Chmod(mode)` on the open temp handle before close), and **handle-relative publication** via `atomicfile.ReplaceTempFileInRoot(targetRoot, tmpName, name, false)` (with injectable pre-replace hooks for parent/leaf swap testing), idempotently ensuring `/.backlog/backlogit`, `/.backlog/backlogit.exe`, `/.backlogit/backlogit`, and `/.backlogit/backlogit.exe` are present while leaving `<root>/bin/backlogit.exe` untouched so `TestU12_NegativePinningGlobalPATHRefusalAndPathTraversalContainment` remains green.
