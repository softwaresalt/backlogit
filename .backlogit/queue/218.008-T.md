# Resolve relative manifest workspace_root against target workspace in toolchain provisioning and launcher validation (U2b)

## Description

<!-- BEGIN:description -->
Implement Unit U2b of `docs/plans/2026-11-19-init-install-target-tools-dir-mcp-config-plan.md` (`218-F`, `269D054D` / `103-DL`): update `validateManifestForProvisioning(root *os.Root, abs string, manifest *ToolchainManifest) error` (`internal/toolchain/launcher.go:658`, line 672, called by `WriteToolchainManifest`) to resolve relative `manifest.WorkspaceRoot` values (such as `workspace_root: "."`) against the target workspace `abs` rather than the ambient process `cwd` (`filepath.Abs(manifest.WorkspaceRoot)`), and update `resolveProvisioningStorageDir(root *os.Root) (string, error)` (`internal/toolchain/launcher.go:799`) to honor non-empty `BACKLOGIT_WORKSPACE_DIR` (`.backlog` or `.backlogit`) on dual-root workspaces while treating `BACKLOGIT_WORKSPACE_DIR=""` as unset and retaining `"ambiguous workspace storage"` refusal when unset/empty.

## Implementation Notes

<!-- BEGIN:implementation-notes -->
* In `validateManifestForProvisioning` (`internal/toolchain/launcher.go:669-675`), reject whitespace-padded or empty `manifest.WorkspaceRoot`, resolve relative `manifest.WorkspaceRoot` (when `!filepath.IsAbs(manifest.WorkspaceRoot) && filepath.VolumeName(manifest.WorkspaceRoot) == "" && !hasDriveOrUNCPrefix(manifest.WorkspaceRoot)`) against `abs` via `filepath.Clean(filepath.Join(abs, filepath.FromSlash(strings.ReplaceAll(manifest.WorkspaceRoot, "\\", "/"))))` instead of `filepath.Abs(manifest.WorkspaceRoot)`, and require `samePath(abs, declared)`.
* In `resolveProvisioningStorageDir` (`internal/toolchain/launcher.go:799-849`), check `override, hasOverride := os.LookupEnv("BACKLOGIT_WORKSPACE_DIR")` before the dual-root ambiguity check: when `hasOverride && override != ""` (treating `""` as unset), validate `override == ".backlog" || override == ".backlogit"`, create `override` if missing, and return `override` even when the other candidate directory also exists; when `!hasOverride || override == ""`, retain the existing `if hasBacklog && hasBacklogit` ambiguity refusal.
<!-- END:implementation-notes -->
