# Self-Contained Sandbox and Multi-Session Runtime Hardening (CAP-2)

## Summary

Covering feature for **CAP-2 (Self-Contained Sandbox & Multi-Session Runtime Hardening)**, delivering six coupled runtime, toolchain, ID-allocation, and Git-discovery hardenings across `internal/atomicfile`, `internal/toolchain`, `internal/mcp`, `internal/cli`, `internal/core/gate`, and `internal/core`:

* **`C5189EAF` (`094-DL`, Unit U1 — `215.001-T`)**: Export directory-handle-relative `atomicfile.ReplaceTempFileInRoot(root *os.Root, dirAbs, tmpRel, dstRel string, durable bool)` (taking the caller's verified absolute directory path `dirAbs` separately from `root`) and harden `WriteToolchainManifest` (`internal/toolchain/launcher.go`) to replace `toolchain.yaml` relative to `storageHandle` with Windows `MoveFileExW` sharing-violation retry semantics, permanent-denial detection, `MOVEFILE_WRITE_THROUGH` durability, `ErrWriteNotApplied` classification, and parent-directory-swap + non-CWD workspace regression coverage.
* **`D1455316` (`093-DL`, Unit U2 — `215.002-T`)**: Extend static workspace-toolchain validation (`internal/toolchain/verify.go`, `internal/toolchain/launcher.go`) to identify `backlogit` by executable identity as well as inventory ID and require `./bin/backlogit.exe` pinning and workspace-root `--cwd` bindings on aliased entries without duplicating `--cwd` in `RenderPinnedMCPConfig`.
* **`0D073C21` (`092-DL`, Units U3a & U3b — `215.003-T`, `215.004-T`)**: Preserve `(*mcp.Server).CloseAllSessions()` session-only semantics for in-process `InvokeTool` callers, decouple `stopAdmission()` from draining and track/drain all admitted in-flight handlers inside `(*OperationCoordinator).Close()` (`internal/mcp/coordinator.go`), expose `(*mcp.Server).CloseCoordinator() error` and `(*mcp.Server).Shutdown() error` in `internal/mcp/session_mux.go` so `Shutdown()` stops both session admission and coordinator admission before waiting on either drain (with blocked in-process handler and blocked-session + concurrent-`InvokeTool` regressions), and wire `RunMCPDaemon` in `internal/cli/mcp_daemon.go` to invoke `s.Shutdown()` before `workers.Wait()` and `s.Workspace.Close()`.
* **`1CED4AD6` (`095-DL`, Unit U4 — `215.005-T`)**: Repair `ExecGitRunner.Verify` `withTempGitCeiling` in `internal/core/gate/baseref.go` so repositories legitimately rooted at `os.TempDir()` (`TMPDIR=/work/repo`, `/work/repo/.git`, nested workspace `/work/repo/subproject`) remain discoverable by shifting the ceiling to `filepath.Dir(tempDir)` while preserving ancestor-checkout isolation for non-repository temp directories.
* **`3083FC1A` (`091-DL`, Units U5a & U5b — `215.006-T`, `215.008-T`)**: Add cross-branch and multi-session artifact ID sequence counter reservation (`<storage_root>/.locks/id-sequences.json`) and leaf advisory allocation locking (`<storage_root>/.locks/id_allocator.lock` with 30s bounded wait) confined to a pinned `.locks` `*os.Root` directory handle (`atomicfile.ReplaceTempFileInRoot`, rejecting leaf symlinks/reparse points and parent-directory swaps) across `CreateArtifact` (`internal/core/id_history.go`, `internal/core/artifacts.go` in `215.006-T`), `AdoptItemWithOptions` (`internal/core/shipment_lifecycle.go` in `215.008-T`), and `ReconstituteShipments` (`internal/core/shipment_reconstitute_exec.go` in `215.008-T`, requiring durable operation ownership via `recordCreated` / `recordAdoption` pre-publish callbacks and `correlationID` tagging before publishing each reservation and unreserving via `unreserveIDSequences(ws, journal.CorrelationID, ours)` on rollback/recovery), plus local Git branch tree discovery (`refs/heads/*`) and `eventLogIDs` reconstitution history.
* **`17214531` (`090-DL`, Unit U6 — `215.007-T`)**: Support `backlogit init` and `backlogit install` (`Aliases: ["install"]` on `newInitCommand` in `internal/cli/root.go` and `internal/cli/self_install.go`) to self-install the runtime executable into `<storage_root>/backlogit[.exe]` and idempotently wire ignore entries in `.gitignore` and `.git/info/exclude` using strictly handle-relative (`*os.Root`) reads, temp creation, `tmpFile.Chmod`, and `atomicfile.ReplaceTempFileInRoot` publication (with Windows `os.SameFile` self-overwrite guard and parent/leaf-swap regressions).
