Plan unit **U16** (partition 4). The only surface allowed to render an operator-runnable disposition command.

Files: `internal/cli/checkpoint.go`, `internal/cli/checkpoint_remediation_test.go` (new).

Created in PR #377 cycle 17 as the safe half of gate finding **H1** (P0). The CLI is the only layer that knows the resolved workspace, so it is the only layer that may render a command. It consumes `events.RemediationIntent` (147.032-T / U1d) and emits a bound, approval-gated block wherever a refusal or a `needs_quarantine` summary is printed.

Binding rules, all mandatory:

1. the rendered command **always** carries an explicit `--cwd` bound to the workspace the intent was computed for
2. the argument is the **bare filename** from `RemediationIntent.TargetFilename`, never a path and never a concatenation
3. the A4c approval line, the preimage line, and the no-clobber destination line are part of the block and cannot be suppressed by a flag
4. when the resolved workspace path or the filename contains a character the target shell would treat specially, emit the block **without** the command line and print `command not rendered: workspace or filename requires manual quoting`

No cross-shell paste-safety claim is made. The approval step is a human step by construction.

**Test-lifecycle classification**: red harness plus one green-step guard. Two scaffolded `TestU16_` functions fail because no renderer exists; the conforming-path assertion is green on landing and is committed with the implementation as `TestU16Guard_ConformingPathUnchanged`.

Red verification: `go test -count=1 -run '^TestU16_' ./internal/cli`.
