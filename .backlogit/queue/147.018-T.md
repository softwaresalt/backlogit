Plan unit **U9b**. Update `.github/instructions/backlogit.instructions.md` (requirement R10).

Files: `.github/instructions/backlogit.instructions.md`.

The shipped Continuity Protocol §6 currently tells agents a rejected create "means retry with the offending keys nested under context… there is nothing to recover". That advice is correct for **create** and wrong for a **stored legacy** document, where the keys are already on disk and the only safe path is quarantine.

Add:
* a clause stating a stored checkpoint carrying unmodeled top-level keys cannot be resolved or abandoned and must be quarantined
* the **body-preserving repair path**: quarantine the original (verbatim, archived), then create a fresh conforming checkpoint carrying the recovered fields under `context`. Without this an operator reads "quarantine" as "throw the session state away".

**This unit is a HARD MERGE GATE.** A pull request containing U3b, U4, or U5 MUST NOT merge without this file's delta present in the same merge commit. Shipping the refusal while the instruction file still tells agents to retry-and-nest strands every agent that hits it. If this unit cannot land in the same merge commit, **halt the merge** — do not defer it to a follow-up PR.

Must pass `backlogit docs lint`.
