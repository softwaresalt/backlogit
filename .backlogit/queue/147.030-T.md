Plan unit **U1b** (partition 1). The single bounded **raw** machine projection for `CheckpointNonConformingError` field paths.

Files: `internal/errors/checkpoint_errors.go`, `internal/errors/checkpoint_errors_test.go`.

**Cycle-17 rewrite (gate finding H4).** Cycle 16 had this method quote every path through `strconv.Quote` and append a synthetic `+N more` marker element, then feed that same output to the MCP `unknown_fields` array. The cycle-16 gate ruled that blocking: a quoted path forces a consumer to parse a Go string literal before it can compare the value against the document''s own key, and a `+N more` element is indistinguishable from a real offender of that name. Machine arrays now carry raw paths; quoting moved to 147.031-T / U1c.

```go
// BoundedFieldPaths returns the sorted, de-duplicated offender paths in RAW form,
// bounded for machine consumption. Truncation is reported structurally.
func (e *CheckpointNonConformingError) BoundedFieldPaths() BoundedFieldPathSet
```

`BoundedFieldPathSet` is exported with `Paths []string`, `Truncated bool`, `OmittedPaths int`, and `TruncatedPaths int` - JSON tags `paths`, `truncated`, `omitted_paths`, `truncated_paths`, none with `omitempty`.

Cap semantics, UTF-8 safe:

* at most **16** paths; `OmittedPaths` carries the exact count not returned
* each path capped at **128 bytes**, cut at the last rune boundary at or before byte 128, so a returned path is always valid UTF-8 and never ends mid-rune
* `TruncatedPaths` counts how many paths were shortened
* a path whose first rune already exceeds the cap is returned as the empty string and counted in `TruncatedPaths`
* selection is deterministic: sort, de-duplicate, take the first 16

**Single-projection rule.** `BoundedFieldPaths()` is the only sanctioned source of machine offender data. 147.012-T / U6b, 147.022-T / U6c, and 147.013-T / U7 all read it; none re-derives from the raw `Fields` slice and none applies its own cap.

**Harness-first (cycle-31, P-002.1).** The compile-capable **source-shape** harness lands **first** and is observed red. The `TestU1b_` functions parse `internal/errors/checkpoint_errors.go` with `go/parser` and assert the declared shape through `go/ast` — `BoundedFieldPathSet` is declared with the four named fields and their exact JSON tags and no `omitempty`, and `BoundedFieldPaths` is declared on `*CheckpointNonConformingError` with the stated signature — so the harness compiles against the pre-declaration tree and fails on assertions rather than on a build error. The carrier and the cap logic then land **together** in the green step and turn those functions green; the three cap/round-trip assertions land in that same commit as `TestU1bGuard_` regression guards. **No declaration stub is committed ahead of the harness.**

Red verification: `go test -count=1 -run '^TestU1b_' ./internal/errors`.
