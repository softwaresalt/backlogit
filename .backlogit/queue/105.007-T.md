Implement atomic waiver reservation and consumption using the shared atomicfile primitive, immutable payload hash, and one-time raw-token ownership.

<!-- BEGIN:acceptance-criteria -->
Two files and no more than four production/test functions. Reuse internal/atomicfile.WriteFileAtomic; fsync is not required because governance needs atomic visibility and Git supplies repository durability. Under a plan lock/CAS, reserve returns a cryptographically random raw token once to the winning long-lived in-process GateSession, persists only its SHA-256/fingerprint plus immutable authorization-payload hash, and binds owner/mode/phases/expiry. The token never leaves process memory or enters output/logs. Compare token hashes timing-safely under lock. Consume changes only defined transition fields. Concurrent reserve has one winner; loser/public-session-handle adoption, payload tamper, wrong owner/phase, and reuse fail closed.
