        Migrate the backlogit Copilot CLI plugin install/binary-resolution off npm to GitHub Releases.

        Context: v1.5.0 retired npm publishing from the release workflow (PR #205). But the plugin still resolves/runs the binary via npm: `plugin/.mcp.json` and `plugin/plugin.json` use `npx -y @backlogit/backlogit-mcp mcp`, and docs (docs/plugin-guide.md, docs/installation.md, README) document `npm install -g @backlogit/backlogit-mcp`. Since @backlogit/* is no longer published (NPM_TOKEN never provisioned / npmjs access lost), the npx path is unreliable or broken for new versions — v1.5.0 binaries exist only on GitHub Releases now.

        Goal: make plugin install work WITHOUT npm, resolving the platform binary from GitHub Releases (SHA256-verified, cached), consistent with how the CLI install scripts already work.

        Scope / tasks:
        1. Replace the plugin MCP command (plugin/.mcp.json + plugin/plugin.json `mcpServers.backlogit`) so it launches backlogit without npx — e.g., a small cross-platform resolver that: (a) uses `backlogit` on PATH if present; else (b) downloads the matching `backlogit-{os}-{arch}[.exe]` from the latest/pinned GitHub Release, verifies against SHA256SUMS, caches under ~/.cache/backlogit/bin/, then runs `backlogit mcp`. (Mirror the existing npm-wrapper Tier 1/Tier 3 logic, drop the npm Tier 2.)
        2. Update docs: docs/plugin-guide.md, docs/installation.md, README plugin section — remove npm/npx instructions; document the GitHub Releases resolution + the go install / binary-download alternatives.
        3. Retire now-unused npm artifacts: scripts/package-npm.sh, the npm/ wrapper dir (npm/backlogit-mcp, npm/platforms/*), and any npm references in the harness/registry.
        4. Keep SHA256 verification and platform matrix (linux/darwin/windows x64/arm64) aligned with release.yml assets.

        Acceptance criteria:
        - `copilot plugin install softwaresalt/backlogit` (or the plugin's MCP launch) resolves and runs the correct backlogit binary with NO npm/npx dependency.
        - Binary is platform-matched, SHA256-verified against the release SHA256SUMS, and cached for subsequent starts.
        - Docs no longer instruct npm install; the GitHub Releases path is the documented default.
        - npm/ wrapper + package-npm.sh removed; no dangling references.

        Priority: high -- the current plugin distribution path is npm-dependent and effectively broken for v1.5.0+.
