# Schema Discoverability

Make schema metadata programmatically discoverable through both MCP and CLI surfaces:

1. Add `sql_schema` section to `MetadataCatalog` containing SQLite table definitions extracted at runtime via PRAGMA introspection
2. Add `backlogit telemetry schema` CLI subcommand printing JSONL fact table and SQLite telemetry table definitions in text/json/markdown format

## Acceptance Criteria

- `backlogit_get_metadata_catalog` response includes `sql_schema` with all tables, columns, types, indexes, and FTS virtual tables
- `backlogit telemetry schema` prints fact table definitions in text/json/markdown formats
- Both surfaces are tested with unit and contract tests
- All quality gates pass
