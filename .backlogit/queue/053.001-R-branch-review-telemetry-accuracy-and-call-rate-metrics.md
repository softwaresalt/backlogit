### P2 → P3 Advisory (reclassified)

**CR-1** · `internal/telemetry/reporter.go` · Constitution Reviewer  
*Exported TrendGroup fields lack GoDoc comments*  
Reclassified P2→P3: Go convention requires doc comments on exported types, functions, and methods — not on individual struct fields. The `TrendGroup` struct already carries a type-level GoDoc comment. No field-level comments exist on any other `TrendGroup` fields; adding them only to the two new fields would be inconsistent. No `golangci-lint` rule enforces per-field comments by default. No fix required.

### P3 Advisory

**CR-2** · `internal/telemetry/reporter_test.go` · Constitution Reviewer  
*TDD process verification*  
Tests and implementation arrived in the same commit. TDD process was followed per agent execution log (tests written first, confirmed failing, then implementation added). 11 tests cover ghost predicate, ghost filtering, `[empty]` marker (table and markdown), call-rate JSON/table columns, and ghost exclusion from averages.

**LR-1** · Learnings Researcher  
*Integer arithmetic vs float for averages* — `AvgModelCalls` and `AvgToolCalls` use `float64` which is appropriate for per-session averages that are not required to be exact integers. Float formatting (`%.1f`) gives one decimal place of precision. No action required.

**LR-2** · Learnings Researcher  
*Telemetry fixes must be applied across all readers* — Ghost-session filtering was applied in both the aggregation loop and the finalisation loop in `GenerateTrendReport`. Session-list formatters (`formatSessionTable`, `formatSessionMarkdown`) handle ghost display independently. Cross-path coverage confirmed.

**LR-3** · Learnings Researcher  
*Centralize shared telemetry helpers* — Ghost filtering is done via a single exported predicate `IsGhostSession` called from both reporter.go and potentially other consumers. Centralisation achieved.

**LR-4** · Learnings Researcher  
*Support alternate fixture shapes* — Test fixture `writeGhostTrendJSONL` covers the critical ghost+active mix. Existing `writeMinimalTelemetryJSONL` and `writeTrendTelemetryJSONL` fixtures remain unchanged. Advisory: future tests may add more JSONL shapes if new edge cases emerge.

**LR-5** · Learnings Researcher  
*Treat empty values as absent input* — `IsGhostSession` explicitly gates on all-zero conditions. Both loops in `GenerateTrendReport` use `continue` to skip ghost sessions early. Consistent with the learning.

## Learnings Applied

- LR-3 (centralize helpers): `IsGhostSession` is a single exported predicate reused across reporter.go, making ghost logic easy to update or extend.
- LR-5 (empty-as-absent): Ghost sessions filtered at report generation time, preserving auditability in the JSONL source.
