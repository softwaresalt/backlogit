Add compact projection mode to list_items, get_queue, and fetch_stash MCP tools.

Files: internal/mcp/tools.go, internal/models/artifact.go, internal/core/queue.go, internal/core/stash.go
Test files: internal/mcp/tools_test.go, internal/models/artifact_test.go
Execution note: test-first

Approach:
1. Define CompactArtifact struct in models/artifact.go with ID, Title, Status, ArtifactType, ParentID, Priority. Add Compact() method on *Artifact.
2. Add compact boolean parameter to the 3 MCP tool definitions.
3. In each handler, when compact=true, map results through Compact() before serializing.
4. For get_queue, define CompactQueueView and CompactQueueGroup structs that use []CompactArtifact. Handler constructs compact view before serializing. (Review F-1: must map both top-level items AND group items.)
5. For fetch_stash, define CompactStashEntry with ID, Priority, Kind, Text (truncated to 120 chars).

Verification:
- list_items with compact=true returns only compact fields (no description, no custom_fields)
- get_queue with compact=true returns compact items in both top-level and groups. 80%+ payload reduction.
- fetch_stash with compact=true returns entries with truncated text
