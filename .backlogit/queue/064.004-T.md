# Telemetry Branch CLI Command

Add `backlogit telemetry branch` subcommand for per-branch metrics with enrichment.

## Approach

- Add `newTelemetryBranchCmd(cwd *string) *cobra.Command` in `internal/cli/telemetry.go`
- Load sessions from JSONL, call `AggregateBranches`, call `ParseGitMergePRs` + `EnrichBranchProfiles`
- Flags: `--format` (table|json|markdown), `--type` (filter by branch type), `--limit`
- Table columns: BRANCH | TYPE | SESSIONS | TOKENS | AVG/SESSION | TASKS | PR | FEATURE | SHIPMENT | LIFESPAN
- LIFESPAN = LastSeen - FirstSeen formatted as duration
- Register in `NewTelemetryCmd`

## Acceptance Criteria

- Command exists and accepts `--format` flag
- Table output contains expected columns
- `--type feature` filters to only feature branches
- JSON output unmarshals to `[]BranchProfile`
- Command appears in `backlogit telemetry --help`
