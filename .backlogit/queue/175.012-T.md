Terminal sink of the file-owned lint DAG: it depends on every other executable task (U1 line-ending baseline, all 36 file-owned lint tasks, and U14), records green evidence for behavior delivered by those prerequisites, commits ONLY its named evidence artifact, and adds NO new red assertion, so it scaffolds no red harness. It owns NO code guards (the prior unowned "green guards" wording is removed); its sole deliverable is the named evidence artifact.

The exempt_verification_command is a single-quoted pwsh -Command payload (literal child payload -- no premature outer-shell expansion; AST-validated with zero single quotes inside). It EXECUTES the four mandatory gates directly (never trusts hand-authored claims): go test ./..., go vet ./..., golangci-lint run, and gofmt -l . -- FAILS on any nonzero exit and SEPARATELY FAILS when gofmt -l . stdout is non-empty. Only after all four gates pass does it (a) confirm the evidence artifact exists, (b) assert the four exact gate markers, and (c) validate the machine-readable //nolint suppression inventory against the actual source tree.

//nolint inventory validation (machine-readable, exact): the command enumerates every //nolint directive in the tree (git grep -n //nolint -- *.go, normalized to path:line), parses the evidence artifact fenced NOLINT-INVENTORY block (rows of the form path:line | linter | justification), and FAILS on a malformed row of fewer than three columns (exit 10), an empty path (exit 11), an EMPTY JUSTIFICATION (exit 12), a DUPLICATE row (exit 13), a MISSING directive that is present in the tree but absent from the inventory (exit 14), or a STALE/EXTRA inventory row absent from the tree (exit 15). An empty inventory while directives still exist fails (exit 9). Distinct nonzero exit codes make every negative state auditable.

Negative-state proof (part of this contract, validated at Stage against synthetic inputs before commit): gate failure -> nonzero (exit 2-6); absent artifact -> exit 7; missing gate marker -> exit 8; tampered suppression inventory -> exit 9-15 by the class above; the positive marker EXEMPT_VERIFY_OK:175.012-T prints ONLY on exit 0 after every check passes. The classification logic was unit-proven across eight positive/negative scenarios and the full one-line command was AST-parsed clean (zero errors) before being written to this contract.

Deliverable (evidence artifact -- verification-only class delta surface, under docs/closure/): docs/closure/175-baseline-convergence-convergence-evidence.md, GENERATED FROM OBSERVED gate outputs (never hand-authored). It records the four gate markers and the full NOLINT-INVENTORY block:

- golangci-lint run: GREEN
- gofmt -l .: GREEN
- a fenced block delimited by the literal lines # BEGIN NOLINT-INVENTORY and # END NOLINT-INVENTORY, one row per //nolint directive as path:line | linter | justification, each justification NONEMPTY.

Must-fail-before-deliverable: on the pre-work tree the four gates are RED (the errcheck/staticcheck/gofmt debt is unremediated) so the command exits nonzero; even once the gates are green it still exits nonzero until the evidence artifact exists, records all four markers, AND its NOLINT-INVENTORY matches the tree exactly. Only after the gates pass AND the deliverable is correct does it exit 0 and print EXEMPT_VERIFY_OK:175.012-T.
