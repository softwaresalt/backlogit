Scope and approach:
1. In `internal/cli/mcp_daemon.go`:
   * Implement `StopMCPDaemon(ctx context.Context, rootPath string) (MCPDaemonStopResult, error)` (and `stopMCPDaemonWithOptions`):
     * Probe `<runtimeDir>/mcp-daemon.lock` via `opts.OpenLock`. If `acquired == true` (no daemon running), remove any stale `mcp-daemon.json` (`os.Remove`, ignoring `os.ErrNotExist`) while still holding the `mcp-daemon.lock` probe handle, then close the probe handle, and return `MCPDaemonStopResult{Stopped: false, Running: false, WorkspaceRoot: workspaceRoot, StorageRoot: storageRoot, LockPath: lockPath}`, `nil`.
     * If `acquired == false`: read `<runtimeDir>/mcp-daemon.json`. Validate `info.PID > 0` and `info.PID != opts.PID()` (refuse invalid or self PID with a descriptive error). Call `opts.KillProcess(info.PID)` (default: `os.FindProcess(pid)` -> `proc.Kill()`, treating `os.ErrProcessDone` as already exited). Poll `opts.OpenLock(lockPath)` at 25ms intervals up to `opts.StopTimeout` (default `5 * time.Second`, respecting `ctx.Done()`) until `acquired == true`. Remove `mcp-daemon.json` (`os.Remove`, ignoring `os.ErrNotExist`) while still holding the `mcp-daemon.lock` probe handle, then close the probe handle, and return `MCPDaemonStopResult{Stopped: true, Running: false, PID: info.PID, WorkspaceRoot: workspaceRoot, StorageRoot: storageRoot, LockPath: lockPath}`, `nil`.
   * Complete the `replace == true` branch in `acquireMCPDaemonLockWithOptions`: when the initial `OpenLock` returns `acquired == false` and `replace == true`, invoke `stopMCPDaemonWithOptions(ctx, rootPath, opts)` and then re-acquire `OpenLock` and write the new holder's `mcp-daemon.json`.
2. In `internal/cli/root.go`:
   * Add package-level test seam `var serveMCPStdio = mcpinternal.RunStdio`.
   * Add `--replace` boolean flag (`"stop any running workspace MCP daemon before starting"`) to `newMCPCommand`.
   * In `newMCPCommand`'s `RunE`, call `release, err := AcquireMCPDaemonLock(cmd.Context(), *cwd, replaceFlag)` before `openMCPServer`; if `err != nil`, return `err`; immediately register `defer func() { _ = release() }()` (so the lock and `mcp-daemon.json` are released even if `openMCPServer` returns an error), then call `serveMCPStdio(s)`.
   * Add subcommands `newMCPStatusCommand(cwd *string)` (`backlogit mcp status [--format text|json]`) and `newMCPStopCommand(cwd *string)` (`backlogit mcp stop [--format text|json]`) under `newMCPCommand`.
