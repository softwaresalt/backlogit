Plan unit **U6e** (partition 4). Makes the published `remediation_intent` contract total over every `needs_quarantine` summary.

Files: `internal/events/checkpoint_lifecycle.go`, `internal/events/checkpoint_lifecycle_test.go`.

Created in PR #377 cycle 20 to close the P2 raised on `147.014-T`. U7b publishes, on `backlogit_list_checkpoints`, the sentence *"The accompanying remediation_intent is a structured record of the required disposition, not a runnable command."* After `147.011-T` / U6 alone that sentence is false: `ListCheckpoints` sets `NeedsQuarantine: true` on three branches and U6 populates `RemediationIntent` on only one of them. The shipped parse-failure branch (`internal/events/checkpoint_lifecycle.go:52-54`) and the schema-invalid branch (`:72-74`) still carry `RemediationCommand` alone. Publishing a universal contract the read path does not satisfy is the class of defect this plan exists to close, so the code is made total rather than the description narrowed.

Populate `RemediationIntent` on the two remaining quarantine-candidate branches with the carrier `147.032-T` / U1d declares - `Verb: "quarantine"`, `TargetFilename: <bare filename>`, `RequiresApproval: true`, `ApprovalClass: "A4c"` - using `Reason: "unparseable"` on the parse-failure branch and `Reason: "schema_invalid"` on the schema-invalid branch. These are exactly the two remaining values U1d''s `Reason` field enumerates.

**Precedence, decided here**: `unparseable` is terminal because that branch appends and continues, so no later branch runs. When a document is both schema-invalid and non-conforming, U6''s conformance branch runs after the validity branch and overwrites `Reason` with `non_conforming`, matching the `ValidationErr` append order that already reports both reasons.

`RemediationCommand` keeps its shipped population on both branches, unchanged and still `// Deprecated:`. This task neither extends nor removes it; removal remains follow-up stash `F350503F`.

**Test-lifecycle classification**: red harness only. Two scaffolded functions, both failing against the post-U6 state where `RemediationIntent` is `nil` on both branches. No green-step guards.

Red verification: `go test -count=1 -run '^TestU6e_' ./internal/events`.
