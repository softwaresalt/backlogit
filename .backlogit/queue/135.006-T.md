Add CheckWorkspaceRootConflict and a finding type through the existing DoctorOptions boolean pattern. Because dual-root resolution makes an ambiguous workspace fail normal resolution, this check must be reachable through an explicit READ-ONLY PRE-RESOLUTION ROUTE that detects the conflict from the candidate list without requiring a resolved workspace, and that route is tested through the real CLI and MCP entry points, not only a direct core call.
