title: Propagate context through findCrossArtifactReferences WalkDir
updated_at: 2026-04-20T21:52:54.7257007-07:00
---

findCrossArtifactReferences accepts a context.Context parameter but discards it (_ context.Context). The filepath.WalkDir closure never checks ctx.Err(), so a user-initiated cancel (SIGINT, deadline) cannot interrupt a scan of a large workspace.\n\n**Fix direction:** Capture ctx in the walk closure. At the top of each walk callback (after the dir/ext guard), call ctx.Err() and return it if non-nil. This will propagate the cancellation signal up through WalkDir.\n\n**References:** internal/core/artifact_references.go:34-57, review 035.001-R (finding GQ-001/CC-001)
