Plan unit **U15** (partition 3). Declares the get-result carrier ahead of every behavioural unit so the cross-surface parity harness can compile.

Files: `internal/events/checkpoint_lifecycle.go`, `internal/events/checkpoint_readresult_test.go` (new).

Created in PR #377 cycle 17 to close the compile premise of gate finding **H2**. `GetCheckpoint` returns `(*CheckpointV1, error)` and there is no get-result type at all, so 147.016-T / U8b cannot compile until a carrier exists.

```go
type CheckpointReadResult struct {
    Checkpoint          *CheckpointV1
    Valid               bool
    Conforming          bool
    NeedsQuarantine     bool
    RemediationIntent   *RemediationIntent
    NonConformingFields backlogiterrors.BoundedFieldPathSet
}

func GetCheckpointResult(ctx context.Context, checkpointDir, filename string) (*CheckpointReadResult, error)
```

The declaration lands `GetCheckpointResult` as a thin wrapper over the **existing** `GetCheckpoint`, returning `&CheckpointReadResult{Checkpoint: cp, Valid: err == nil}` with every other field zero-valued. `GetCheckpoint` is retained as a wrapper returning `res.Checkpoint`, so every existing caller compiles untouched.

**Declaration boundary**: no conformance evaluation, no intent population, no offender projection. Those are 147.012-T / U6b''s production delta.

**Test-lifecycle classification: harness-required, source-shape RED (cycle-29).** This task is
**not** `harness-exempt`. It lands an exported `CheckpointReadResult` type and an exported
`GetCheckpointResult` wrapper — observable production surface — so Constitution Principle II
applies in full. The `declaration-only` class cycle 20 gave this unit was withdrawn in cycle 29
(`workflow-policies.md` P-002.1): PR #377 review found it admitted an executable exported wrapper
with no observed failing test, which is a carve-out from a NON-NEGOTIABLE principle.

Cycle 20's objection stands on its own terms — a test that fails only because
`CheckpointReadResult` does not exist is a **build error** (P-004 rejects it), and the wrapper's
`Valid: err == nil` assertion passes the instant the symbol lands (never red). A **source-shape
harness** is neither. It parses `internal/events/checkpoint_lifecycle.go` with `go/parser` and
asserts the declared shape through `go/ast`, referencing no undeclared identifier, so it compiles
before the declaration exists and fails on an assertion.
