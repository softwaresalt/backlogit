Plan unit **U15** (partition 3). Declares the get-result carrier ahead of every behavioural unit so the cross-surface parity harness can compile.

Files: `internal/events/checkpoint_lifecycle.go`, `internal/events/checkpoint_readresult_test.go` (new).

Created in PR #377 cycle 17 to close the compile premise of gate finding **H2**. `GetCheckpoint` returns `(*CheckpointV1, error)` and there is no get-result type at all, so 147.016-T / U8b cannot compile until a carrier exists.

```go
type CheckpointReadResult struct {
    Checkpoint          *CheckpointV1
    Valid               bool
    Conforming          bool
    NeedsQuarantine     bool
    RemediationIntent   *RemediationIntent
    NonConformingFields backlogiterrors.BoundedFieldPathSet
}

func GetCheckpointResult(ctx context.Context, checkpointDir, filename string) (*CheckpointReadResult, error)
```

The declaration lands `GetCheckpointResult` as a thin wrapper over the **existing** `GetCheckpoint`, returning `&CheckpointReadResult{Checkpoint: cp, Valid: err == nil}` with every other field zero-valued. `GetCheckpoint` is retained as a wrapper returning `res.Checkpoint`, so every existing caller compiles untouched.

**Declaration-only boundary**: no conformance evaluation, no intent population, no offender projection. Those are 147.012-T / U6b''s production delta.

**Test-lifecycle classification: `harness-exempt: declaration-only` (cycle-20).** The declaration step lands a wrapper that already returns `&CheckpointReadResult{Checkpoint: cp, Valid: err == nil}`, so the planned "returns the parsed document with `Valid: true`" assertion passes the instant the symbol exists, and the schema-invalid assertion pins the shipped, unchanged read contract. Cycle 19''s claim that "case 1 fails against the pre-declaration state (the symbol does not exist)" described a **build error**, which P-004 explicitly does not accept as a red phase; the cycle-20 Copilot review raised this as a P1. The fabricated RED is withdrawn rather than replaced with invented behaviour.

**No harness test function is scaffolded for this task.** Both assertions land in this task''s own declaration commit as green-step guards named `TestU15Guard_*`.

**Where the RED for this carrier lives**: `147.012-T` / U6b owns the failing harness for the projected fields - its cases 1 and 2 fail precisely *because* this declaration leaves `Conforming`, `NeedsQuarantine`, `RemediationIntent`, and `NonConformingFields` at their zero values. `147.016-T` / U8b adds the cross-surface RED against the same declaration state.

Verification: `go test -count=1 -run '^TestU15Guard_' ./internal/events`.
