## Objective

Reorder `db.Open` DSN pragmas in `internal/db/connection.go` (`_pragma=busy_timeout(30000)` first) and execute a passive WAL checkpoint at the end of `EnsureSchema` and `EnsureSchemaWithExtensions` in `internal/db/schema.go` (`F448AA52` / `098-DL` / Unit U4) so pooled SQLite connections (`SetMaxOpenConns(4)`) never fail with `no such table: commit_links` under concurrent `-race` load.

## Scope and Affected Files

* **Domain**: `code` (`internal/db`)
* **Execution posture**: `test-first`
* **Affected files (3)**:
  * `internal/db/connection.go`
  * `internal/db/schema.go`
  * `internal/db/connection_test.go`

## Implementation Details

1. In `internal/db/connection.go` (`Open`, lines 58-62), add `_pragma=busy_timeout(30000)` FIRST in `q` before `_pragma=journal_mode(WAL)` and `_pragma=foreign_keys(1)` so every newly opened physical connection in the `database/sql` pool (`SetMaxOpenConns(4)`) sets its 30-second busy timeout before executing `PRAGMA journal_mode(WAL)`.
2. In `internal/db/schema.go`, execute `_, _ = db.Exec("PRAGMA wal_checkpoint(PASSIVE)") //nolint:errcheck // best-effort passive WAL flush after schema DDL` at the **very end** of `EnsureSchema` (line 505, after `tx.Commit()` and the `migrations` `ALTER TABLE` loop) AND at the **very end** of `EnsureSchemaWithExtensions` (`internal/db/schema.go:523`, after `ApplySchemaExtensions(db, headerDef)` returns `nil`) so all base and extension schema tables (`items`, `commit_links`, `item_deps`, `item_links`, `item_logs`, `custody_receipts`, custom columns) are immediately materialized in the main `backlogit.db` file and visible to any concurrently opened pooled connection.

## Acceptance Criteria

* **AC1 (RED-First Harness)**: `TestU4_OpenPragmaOrderAndEnsureSchemaCheckpointsMainDB` in `internal/db/connection_test.go` (checking all `database.Close()` errors per `TestU175_075_LintFix`) compiles cleanly before `connection.go` or `schema.go` is edited and fails on a deterministic runtime assertion (`assertion RED`): (a) right after `db.Open(dbPath)` + `db.EnsureSchema(database)` (while `database` remains open), the main `dbPath` file on disk has non-zero checkpointed size (`info.Size() > 4096`) and contains `commit_links` in its main database pages (failing deterministically today because `EnsureSchema` leaves all schema pages uncheckpointed in `backlogit.db-wal` with `info.Size() <= 4096`); and (b) 4 concurrent goroutines simultaneously starting `IMMEDIATE` transactions and querying/inserting into `commit_links` on a freshly opened `database` succeed with zero `no such table: commit_links` or `SQLITE_BUSY` errors.
* **AC2 (GREEN Verification)**: `go test -timeout=30m -count=1 -race -v -run '^(TestU4_OpenPragmaOrder|TestOpen|TestEnsureSchema|TestU175_025_LintFix|TestU175_075_LintFix)' ./internal/db` passes with 0 failures.
