Covering feature B for stash 6434A4D7 (DEFERRED SCOPE EXPANSION, 074-DL layer L2; second feature harvested from the same stash, whose official `source_stash_id` harvest provenance is carried by sibling feature 184-F). Adds a governed, Stage-only, operator-authorized disposition that moves a `queued` shipment to `abandoned` without activation. Status and the provenance keys (`disposition_reason`, `disposition_by`, `disposition_authorization_ref`, optional `superseded_by`) are written in one governed write. The disposition needs a target-bound, decided `deliberation` (`authorizes_disposition`) and `--confirm`. It never moves members, never cascades, never archives, and refuses `active`, `blocked`, `shipped`, and shipments with live `blocks` dependents. Generic paths (`UpdateArtifact`, `BulkUpdateStatus`) refuse `queued` to `abandoned`. `156-S` is NOT disposed by this work; it is only the motivating example for a future, separately authorized use.

Execution authority (mandatory guard, delegated ADVISORY authorization): only Stage may invoke the disposition, through the MCP tool `backlogit_dispose_shipment` or the confirmed CLI `backlogit shipment dispose`. Ship and the Orchestrator never invoke it, including as runtime verification. Ship builds and tests the capability with in-process unit and handler tests only.
