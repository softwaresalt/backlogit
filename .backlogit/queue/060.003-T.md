# Git PR Enrichment via Merge Commit Parsing

Add git merge-commit parsing to extract branch→PR number mappings.

## Approach

- Add to `internal/telemetry/branch_metrics.go`
- `ParseGitMergePRs(repoPath string) (map[string]string, error)`: runs `git -C <repoPath> log --merges --oneline --all`, delegates to parser
- `parseMergeLines(r io.Reader) map[string]string`: pure parser, parses "Merge pull request #N from owner/branch" format
- `EnrichBranchProfiles(profiles []BranchProfile, prMap map[string]string)`: fills PRNumber on each profile
- Returns empty map (not error) when git is unavailable or repo has no merges

## Acceptance Criteria

- `parseMergeLines` correctly handles multi-line fixture input including non-merge commits, malformed lines, branches with slashes
- `EnrichBranchProfiles` fills PR numbers for matched branches, leaves empty for unmatched
- Graceful fallback when git is not available (returns empty map)

## Implementation Notes

- Files: `internal/telemetry/branch_metrics.go`
- Test files: `internal/telemetry/branch_metrics_test.go`
- Execution: test-first
- Split into exec wrapper + pure parser for testability
- Dependencies: none (independent, but used together with 060.002-T)
