# Telemetry Schema CLI Subcommand

Add `backlogit telemetry schema` command with text/json/markdown output formats.

## Approach

- Add `newTelemetrySchemaCmd` returning `*cobra.Command` in `internal/cli/telemetry.go`
- `--format` flag: text (default), json, markdown
- For each fact table and SQLite table, print table name, description, and field listing
- Register via `cmd.AddCommand(newTelemetrySchemaCmd(cwd))` in `NewTelemetryCmd`

## Acceptance Criteria

- `backlogit telemetry schema` prints all fact tables and SQLite telemetry tables
- `--format json` produces valid JSON with all tables
- `--format markdown` produces valid markdown tables
- Command appears in `backlogit telemetry --help`
