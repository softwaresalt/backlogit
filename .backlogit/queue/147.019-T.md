Plan unit **U10**. Runtime verification of the **refusal** path in a scratch workspace.

Files: `.gitignore` (ignore rule for the scratch directory). No product code changes.

**Scope note.** The acceptance and restore half moved to **147.026-T** (U10b). Five verification steps in one task exceeded the four-scenario limit, and the restore step also carried the contradiction described below. This task owns the scratch workspace, the ignore rule, the binary under test, and the live-corpus guard, so 147.026-T inherits them rather than re-declaring them.

**Scratch containment (Constitution IV).** The scratch workspace is created **inside the repository working tree** at `docs/scratch/checkpoint-verification/` — never `%TEMP%`, never outside the cwd. Assert the resolved path is repo-root-relative **before the first write**, add the directory to the freeze-scope declaration, and add the `.gitignore` rule: there is no `docs/scratch/` rule today, and while `*.exe` already covers the built binary the copied fixtures are not covered.

**Binary under test.** Build from the branch HEAD — `go build -o docs/scratch/checkpoint-verification/backlogit-verify.exe ./cmd/backlogit` — and exercise that binary. The pinned repo-root `backlogit.exe` predates the change and must not be used.

**The live corpus is evidence, never a fixture and never a target.** The nine live legacy checkpoints under `.backlogit/checkpoints/` MUST NOT be used as verification fixtures and MUST NOT be mutated by any verb. Copy representative bytes into the scratch workspace instead. The only operation this task performs against the live directory is a read-only SHA-256 enumeration before and after the whole run.

Verify end to end, in the scratch workspace:

1. **Read verdict** — `list` reports `needs_quarantine: true` with a paste-runnable, PowerShell-safe remediation command, and `get` reports `conforming: false` for the same fixture
2. **Refusal** — `resolve` refuses and `abandon` refuses, both naming quarantine; the fixture is byte-unchanged after both refusals
3. **Quarantine accept** — `quarantine` accepts and archives the bytes verbatim (byte-identical comparison against the pre-quarantine original)

Scratch teardown is `ActionRisk: destructive` (A4b) and requires operator approval; if approval is withheld the directory stays in place and is recorded as a cleanup follow-up. This is the documented Principle VII deviation recorded in the plan's Constitution Check.
