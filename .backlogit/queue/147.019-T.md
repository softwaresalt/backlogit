Plan unit **U10** (partition 5). Runtime verification of the refusal path.

Files: `.gitignore` (scratch-directory ignore rule); otherwise none. Produces `docs/closure/` evidence.

Build the binary **from the branch under test** with the repository''s own version ldflags (`Makefile:6-8`), then exercise the **refusal** path against a scratch workspace seeded with copies of the legacy document shapes. The nine live files under `.backlogit/checkpoints/` are read for shape reference only and are never mutation targets; the check is a programmatic before/after SHA-256 comparison of **every** file in that directory, enumerated rather than count-pinned.

Assert `docs/scratch/checkpoint-verification/backlogit-verify.exe version --format json --no-update-check` reports a `commit` equal to `git rev-parse --short HEAD`. `--format json` is the JSON selector - there is no `--json` flag.

**Execution contract (cycle-17 corrected), mandatory and fail-closed:** (1) run under an explicit A4c approval batch obtained immediately before execution; (2) bind with `--cwd docs/scratch/checkpoint-verification` and pass bare filenames, logging the resolved storage root first; (3) display per file, before and after each step, the bare filename, SHA-256 hash, classified state, and destination; (4) take a pre-run preimage byte copy of every fixture a mutating verb will touch; (5) **apply the precondition that matches the operation class** - for an **in-place rewrite** (`resolve`, `abandon`) the destination is the target file and is necessarily present, so absent-destination and no-clobber must **not** be asserted; the preconditions are the preimage plus a post-step SHA comparison (equality on refusal, inequality plus a validating re-parse on acceptance). For an **archive move** (`quarantine`) the destination must be asserted absent and the move must refuse to clobber. A declared **intentional-collision** row creates the collision deliberately and expects a refusal; (6) fail closed - a destination outside the bound root, a missing preimage, an unexpected occupied destination, or an unclassifiable state is a halt.

**Evidence persistence (cycle-17):** each row writes a deterministic, human-readable record - filename, sha256, state, destination, outcome - to the tracked file `docs/closure/2026-08-checkpoint-disposition-runtime-verification.md`. The git-ignored scratch directory is a working area, not the artifact of record.

Scratch containment: the workspace is created **inside the repository working tree** at `docs/scratch/checkpoint-verification/`, never `%TEMP%`, and the resolved path is asserted repo-root-relative before the first write. **Teardown does not run here** - it moved to 147.041-T / U10c in cycle 17, because U10b and U10c both consume this workspace.

**Test-lifecycle classification**: `harness-exempt: verification-only`. No Go test function is scaffolded, no RED is claimed, and there are no green-step guards; the gate is the recorded runtime evidence appended to the tracked closure artifact.

keys; Ship Step 4.1a runs `exempt_verification_command` once against the pre-work tree and MUST
observe it fail before this task may be claimed.

**Durable evidence manifest (cycle 23).** Cycle 22 left this unit with no executable command at
all, so its gate was unfalsifiable. The evidence artifact
`docs/closure/2026-08-checkpoint-disposition-runtime-verification.md` is a tracked, human-readable
closure document under the existing `docs/closure/` convention, carrying docline frontmatter like
every other artifact in that directory. Inside it, this unit appends a fenced `text` block whose
lines use this exact grammar, one record per line at column 0:

```text
evidence_row: unit=U10 row=<n> filename=<bare-filename> sha256=<64-hex> state=<classified-state> destination=<bare-destination|none> outcome=<refused|accepted|unchanged>
evidence_scalar: unit=U10 live_corpus_sha_unchanged=true
evidence_scalar: unit=U10 binary_commit=<short-sha>
```

At least **five** `evidence_row` records are required, one per acceptance row: the `list` read
verdict, the `get` read verdict, the refused legacy-shaped `resolve`, the refused
valid-but-non-conforming `abandon`, and the accepted `quarantine`. The two scalars carry the
enumerated live-corpus comparison and the branch-built binary provenance
(`git rev-parse --short HEAD`). The git-ignored scratch directory remains a working area; only
this artifact is the record.

**Why this command is a gate.** The probe fails while the artifact is absent, fails while the
block is present but under-populated, and fails when a row is missing any required field — so it
cannot pass on a created-but-empty file or on a no-op run. It passes only once every declared
field is present.
