## Findings

### P1 (Fixed) — GQ-001: --format flag silently did nothing

`StringVar(&formatOutput, ...)` bound the flag but `formatOutput` was never read in `RunE` across `list.go`, `queue_cmd.go`, `stash.go`, `shipment.go`. The `internal/cli/format` package (TableRenderer, JSONRenderer, TileRenderer) was built but not used.

**Fix applied** in commit `4a4ca1e`: wired `--format` to format renderers in all four commands. Added `artifactColumns`, `artifactsToRows`, and `newRenderer` helpers in `list.go` (shared across commands). `--json` backward-compat preserved in `list`.

### P2 (Fixed) — GQ-002: discarded error in version_cmd.go

`format, _ := cmd.Flags().GetString("format")` — constitution violation (errors must not be discarded).

**Fix applied** in same commit: `format, err :=` with `if err != nil { return err }`.

### P2 (Follow-up: 033.010-T) — CR-001: gen-docs DisableAutoGenTag fragile

`cmd/gen-docs/main.go` sets `DisableAutoGenTag` only 2 levels deep. Correct today; will miss grandchild commands when added. Recursive walk recommended.

### P3 (Follow-up: 033.011-T) — WF-001: CI workflow-level permissions

`.github/workflows/cli-reference-drift.yml` has `permissions:` at workflow scope; CI security instructions require job-level declarations.

### P3 (Follow-up: 033.012-T) — AP-001: TileRenderer TTY detection not wired

All `NewTileRenderer(false)` call sites hard-code `false`; ANSI bold is never applied even when writing to a terminal. TTY detection helper follow-up.
