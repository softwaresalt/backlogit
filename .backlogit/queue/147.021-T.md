Plan unit **U2f** (partition 2). Supplemental caller-set regression guard for the guarded rewrite seam.

Files: `internal/events/checkpoint_writesite_test.go` (new). No production change.

**Cycle-17 rewrite (gate finding H8). This task is no longer the authoritative I1 enforcement.** The cycle-16 gate ruled that an AST enumeration of write calls cannot fully enforce protected invariant I1: it must resolve call targets, aliased imports, indirect writers, and any future helper that wraps an atomic write, and each unresolved case is a silent hole. **I1 is now enforced architecturally** by 147.034-T / U11, 147.035-T / U12, 147.036-T / U13, and 147.037-T / U14, which make `events.RewriteCheckpointFile` the only in-place rewrite path.

This task keeps the enumeration as a supplemental guard: walk `internal/events` and `internal/core` for calls to `syncWriteFileAtomic` / `atomicfile.WriteFileAtomic` / `os.WriteFile` whose target resolves under the checkpoint directory, and assert the call-site set equals the **post-migration** allow-list - the seam''s own write plus the excluded verbatim-move and create sites, and nothing else.

**Honest bound.** It proves that no direct, statically resolvable atomic-write call to the checkpoint directory was added outside the seam. It does not prove the absence of an indirect or dynamically dispatched writer, and it is not relied on for that.

**Halt condition:** if the enumeration cannot be implemented reliably, mark this task `blocked` and record a follow-up. Because I1 no longer depends on it, a blocked U2f does **not** block the release unit - that is the concrete benefit of moving enforcement into the seam.

Red verification: `go test -count=1 -run '^TestU2f_' ./internal/events`.
