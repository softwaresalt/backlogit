Plan unit **U2d**. Read-boundary derived key set, the refactor onto it, and the decision-anchored carrier guard.

Files: `internal/events/checkpoint_conformance.go`, `internal/events/checkpoint_conformance_test.go`.

Introduce `checkpointV1AllTopLevelKeys` as a **package-level derived set** — `modeledJSONTagKeys(reflect.TypeOf(CheckpointV1{}))` with **no** reserved-key subtraction — and **refactor `CheckConformingTopLevelNamespace` off the inline two-set check landed by 147.002-T / U2 onto this single derived set**. This is U2d's real production delta (cycle-8 rebalance under P-004): the read boundary stops carrying the reserved-key admission as two runtime lookups against `checkpointV1TopLevelKeys ∪ checkpointV1ReservedKeys` and instead consults one authoritative derivation of every modeled top-level key, so the hand-written `checkpointV1ReservedKeys` literal cannot drift out of the modeled field set without a failing test.

Add a **decision-anchored** guard that `CheckpointV1` declares no `json:"-"` map carrier, with a comment naming `docs/decisions/2026-08-24-checkpoint-toplevel-key-disposition-deliberation.md`. This is a "revisit the decision before changing this" marker, **not** a permanent ban.

Add the tag-coverage guard closing the `modeledJSONTagKeys` untagged-exported-field escape hatch.

Protected invariant **I1** (the checkpoint rewrite write-site enumeration) is **not** part of this unit — it is a distinct deliverable with its own file and is tracked separately as **147.021-T**, so this unit stays within one skill domain.

**Harness-first (cycle-31, P-002.1).** The compile-capable **source-shape** harness lands **first** and is observed red: the `TestU2d_` function parses `internal/events/checkpoint_conformance.go` with `go/parser` and asserts through `go/ast` that `checkpointV1AllTopLevelKeys` is declared from `modeledJSONTagKeys(reflect.TypeOf(CheckpointV1{}))` and that `CheckConformingTopLevelNamespace` consults it rather than the inline two-set check. It compiles against the pre-delta tree and fails on those assertions. The derived set **and** the conformance-check refactor then land together in the green step. **No empty `map[string]struct{}{}` stub is committed ahead of the harness** — the cycle-8 "declaration step lands an empty stub" posture is withdrawn.
