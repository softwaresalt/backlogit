core.MutationEnvelope registers ordered idempotent steps, each an Apply and a Compensate closure. It takes NO domain types — no *events.EventWriter, no *sql.DB; callers capture what they need in their own closures. Snapshot the caller-supplied pre-state, track the applied set, and on failure branch FIRST on classification: ErrWriteNotApplied compensates in reverse; ErrWriteIndeterminate does NOT compensate and finishes remaining safe steps then surfaces the accumulated error; any other error compensates then surfaces. NAMED INVARIANT: if any step is indeterminate, the top-level classification is Indeterminate regardless of other joined errors. Result is typed MutationPartialError{Completed []string; FailedStep string; CompensationState string; Class string; Cause error} with Error and Unwrap, in internal/errors/mutation_errors.go, extracted via errors.As; accumulate with errors.Join. FailedStep and CompensationState are populated at classification time so the MCP mapping (U6) never parses error text. Log all diagnostic values on a double fault. Files: internal/core/mutation_envelope.go, internal/errors/mutation_errors.go.
