Eliminate success-shaped evidence loss on two governed diagnostic paths. Covering feature synthesized by Stage from external source entries 3C7AAC71 (checkpoint create silently discards caller context keys) and 90F2A9F8 (docs lint aborts the whole corpus on the first decode error). External source entry 84D8E6AB is explicitly NOT in scope and NO duplicate item was created for it: the deliberation proved it was already fixed by archived feature 143-F / shipment 127-S with prevention hardening in 144-F / shipment 128-S. Defect 1: events.CreateCheckpoint probes a V1 state dump, parses into CheckpointV1, and re-marshals the parsed struct, so every unmodeled context key and every unknown top-level key vanishes from disk while both surfaces return a bare path-only envelope. Defect 2: docline.LintTree returns nil, err on the first per-file decode failure, so backlogit docs lint exits 1 having printed nothing and MCP returns InternalError, making corpus-wide conformance unobservable. The fix makes the checkpoint context namespace open while closing the schema namespace, reports the persisted context key names on both transports, and converts per-file frontmatter decode failures into decode_error findings while keeping containment and I/O failures as hard errors and retaining the non-zero lint exit.
