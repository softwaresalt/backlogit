## Description

<!-- BEGIN:description -->
Unit 4. Add TWO advisory DoctorFindingTypes -- FindingMissingShippedEvent = "missing_shipped_event" (the shipped event is absent) and FindingShippedUnarchivedResidue = "shipped_unarchived_residue" (a shipped-but-unarchived shipment, the indeterminate residue) -- plus DoctorOptions.CheckShippedEventCompleteness bool. In Doctor, gate a new check (off by default, advisory and exit-code-neutral like FindingOverArchivedCoveringFeature) that walks the FULL canonical artifact scan already used by Doctor (both queue/ and archive/, since a shipped-but-unarchived shipment stays under queue/ because shipped is not an archive-routed status), parsing each exact path raw Markdown once (extend artifactRef to carry archived_status), not a per-ID findArtifact second lookup. Flag a shipment when EITHER (a) it is archived with archived_status: shipped and its item JSONL log has no shipment_status_changed event with status == shipped -> FindingMissingShippedEvent, OR (b) it has status: shipped but is not archived (the indeterminate residue) -> FindingShippedUnarchivedResidue, anomalous regardless of event presence so an event-present residue is reported truthfully as shipped_unarchived_residue and never mislabeled missing_shipped_event; record whether the shipped event is present in the finding detail in both cases. Carry the same "verify actual history; may be transient during an in-flight ship" caveat as FindingOverArchivedCoveringFeature. Never write or rewrite JSONL. Files: internal/core/doctor.go (+ internal/core/canonical_scan.go artifactRef field). Test-first.
<!-- END:description -->

## Acceptance Criteria

<!-- BEGIN:acceptance-criteria -->
- Two advisory, off-by-default finding types (missing_shipped_event and shipped_unarchived_residue) and one option exist; the check never changes the doctor exit code.
- Detection reads authoritative state from the full canonical raw-Markdown scan (queue and archive), not the DB projection, and covers both the archived missing-event state and the shipped-but-unarchived residue state.
- The event-present shipped-but-unarchived residue is reported as shipped_unarchived_residue, never mislabeled missing_shipped_event.
- The check never writes or rewrites historical JSONL (asserted by unchanged log bytes).
<!-- END:acceptance-criteria -->
