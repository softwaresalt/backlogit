# Make ShipShipment rollback class-aware with honest compensation

## Description

<!-- BEGIN:description -->
Unit 4. In `internal/core/shipment_lifecycle.go`. (1) Classify ONLY the `shipmentEventAppendError` boundary value; every other closure error keeps the existing unconditional rollback. (2) Classification matches `MutationEnvelope` precedence (`internal/core/mutation_envelope.go:25-30`, `:83-90`): `blerrors.IsWriteIndeterminate` suppresses rollback; everything else, including untagged plain errors, compensates. (3) Place the classification branch and the `restoreRolledUpNonMemberFeatures` call BEFORE the existing `closureErr == nil || len(shipSnapshots) == 0` guard at `:391-393`; only `restoreShipArtifacts` stays behind it. (4) Make compensation honest: in `restoreShipArtifacts` (`:184-188`) apply a PER-CALL bounded retry budget to the per-item log-lock re-acquisition and, if an item still cannot be restored, promote to `MutationPartialError` with `Class: not-applied` and `CompensationState: partially-compensated` listing the un-restored IDs; apply the same promotion to every per-item rollback stage that can fail (`:194`, `:207`, `:211`, `:216`, `:220`, `:225`), not only lock acquisition. (5) On the indeterminate branch suppress `restoreShipArtifacts`, synchronously restore rolled-up non-member covering features while artifact locks are held, halt archival, and return `MutationPartialError` with `Class: indeterminate`, `FailedStep: blerrors.StepShippedEventAppend`, `CompensationState: not-compensated`, and `Cause` wrapping with `%w` and populating `Completed`; join any restore failure onto the error, indeterminate dominates. (6) Track `restoreAttempted` and `restoreSucceeded` separately and allow the outer fallback exactly one retry. (7) SWAP the two defer registrations at `:365` and `:375` so `releaseArtifactLocks` unwinds LAST and the non-member fallback unwinds first with locks genuinely held; nilling the releaser was evaluated and rejected because it would make the fallback unconditionally dead. (8) Emit `slog` on both branches with a fixed shape including `class`, `failed_step`, `compensation_state`, and `unrestored_ids`. (9) Doc-comment the invariant that only the shipment's own terminal transition is durability-gated. Execution posture: test-first.
<!-- END:description -->

## Acceptance Criteria

<!-- BEGIN:acceptance-criteria -->
- Only the captured append error is classified; tagged indeterminate suppresses rollback and everything else compensates.
- The classification branch sits before the `len(shipSnapshots)` guard.
- An un-restorable item yields `CompensationState: partially-compensated` naming the IDs, never a silent skip, across all per-item rollback stages.
- The defer registrations are swapped so the non-member fallback runs with artifact locks held.
- All three 143.002-T scenarios are green and the four existing ship tests stay green unchanged.
- A new regression asserts a post-closure `archiveItems` failure still restores the non-member covering feature.
<!-- END:acceptance-criteria -->
