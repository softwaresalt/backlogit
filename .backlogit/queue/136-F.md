Exact-target administrative checkpoint disposition. Adds checkpoint abandon FILE --reason REASON for VALID checkpoints the operator intentionally will not resume, and checkpoint quarantine FILE --reason REASON for MALFORMED checkpoints that cannot pass normal validation. Both verbs exist on CLI and MCP, routed through one shared core function each. The verbs are disjoint: abandon refuses a malformed target naming quarantine, quarantine refuses a valid target naming abandon. Disposition is atomic, filename-scoped (basename only), archive-only, and audited BEFORE any move so a failed audit always means nothing moved. A malformed checkpoint is never parsed-and-rewritten; its bytes move verbatim and metadata goes to a sidecar. ListCheckpoints becomes strictly read-only and reports NeedsQuarantine with a remediation command instead of silently moving files. Consumes the F6 governed-operation contract and the F5 mutation envelope rather than duplicating them. Source stash FDEDE39A.
