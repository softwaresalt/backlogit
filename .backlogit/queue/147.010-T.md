Plan unit **U5b**. State-scoped classification pinning invariant I3 plus a real observability-parity delta on the quarantine refusal.

Files: `internal/core/checkpoint_disposition.go`, `internal/core/checkpoint_disposition_test.go`.

Production delta (cycle-8 rebalance under P-004): extend `QuarantineCheckpoint` to wrap its `ErrCheckpointUseAbandon` return with the target `baseName` for **observability parity** with the other `blerrors.ErrCheckpoint*` returns in the same file. Every other refusal in `checkpoint_disposition.go` already wraps (`ErrCheckpointNotFound` — `%w: %s + baseName`; `ErrCheckpointUseQuarantine` — `%w: %v + parseErr/valErr`; `ErrCheckpointNotActive` — `%w: status=%s + cp.Status`; `ErrCheckpointDestinationOccupied` — `%w: %s + baseName`). `ErrCheckpointUseAbandon` is the one bare `blerrors.ErrCheckpoint*` return in the file. Wrapping it names the offending filename so operators handling a state-conflict double-refusal see which file is stranded without cross-referencing the CLI or MCP invocation. Change form: `return fmt.Errorf("%w: %s", blerrors.ErrCheckpointUseAbandon, baseName)`. `errors.Is(err, blerrors.ErrCheckpointUseAbandon)` continues to hold, so 147.009-T / U5's row-2 regression guard and every downstream caller stay green.

State-scoping rationale: the pre-existing state-conflict class (`status: "resolved"` conforming refused by both verbs) is deliberately not widened here — widening quarantine to accept it would change what "quarantine" means, from "these bytes are untrustworthy" to "I want this file gone". Invariant I3's totality is scoped to `status: "active"`. Leaving this untested would let a future reader believe I3's totality claim covers it. This unit's tests pin that state-scoped totality and the observability wrap together, so a future reader cannot break either without a failing test.
