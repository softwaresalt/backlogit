# Normalize forward and backslashes in MCP validateSessionPath on Windows (39F868B1)

## Problem Frame

<!-- BEGIN:problem-frame -->
In internal/mcp/session_mux.go:384, (*Server).validateSessionPath replaces only '\\' with string(filepath.Separator). On Windows (filepath.Separator == '\\'), forward slashes '/' remain unnormalized, so strings.Split(path, string(filepath.Separator)) fails to split '/' segments: 'sub/../existing.md' bypasses the per-segment '..' check and 'junction/missing.md' returns nil on os.ErrNotExist without inspecting the 'junction' reparse-point ancestor.
<!-- END:problem-frame -->

## Options

<!-- BEGIN:options -->
Option A: Leave strings.ReplaceAll(path, '\\', string(filepath.Separator)) unchanged and rely on filepath.IsLocal (Rejected - forward-slash '..' and junction ancestor segments bypass per-segment inspection on Windows). Option B (Recommended): Normalize both '/' and '\\' to string(filepath.Separator) via strings.NewReplacer before filepath.IsLocal, component splitting, '..' rejection, and per-component root.Lstat + core.IsSymlinkOrReparsePoint inspection, verified by colocated unit tests including real Windows junction fixtures.
<!-- END:options -->

## Chosen Direction

<!-- BEGIN:chosen-direction -->
Option B (Selected): Deliver 39F868B1 as Unit U1 (220.001-T, harness-ready, 2 files: internal/mcp/session_mux.go and internal/mcp/session_mux_test.go) in Feature 220-F / Shipment 221-S (sequenced after 220-S via blocks edge).
