Fix stale cross-artifact frontmatter references after AdoptItem ID rewrites. When AdoptItem reassigns an artifact to a new parent, other artifacts whose Markdown frontmatter references the old ID (parent_id, dependencies, links) are not updated. The next rehydration reverts corrected DB edges. This feature adds a two-phase cross-artifact reference scanner/rewriter integrated into AdoptItem.
