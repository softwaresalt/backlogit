Add checkpoint discovery, validation, cleanup, and interactive recovery to the backlogit MCP tool surface and agent harness protocols.

When an agent session terminates unexpectedly — remote disconnect, power failure, context window exhaustion, terminal close, or MCP process kill — work in progress is lost. Infrastructure-level crash safety exists (atomic writes, stale lock recovery, DB-FS reconciliation) but application-level recovery orchestration is missing: checkpoints are written but never read back, there's no discovery/validation tool, no cleanup mechanism, and no standardized schema.

This feature adds: (1) a standardized CheckpointV1 schema with Go validator tags, (2) checkpoint lifecycle functions (list, get, resolve, cleanup) with path containment and context.Context, (3) four new MCP tools and matching CLI commands for checkpoint management, (4) configurable retention with non-destructive archive cleanup, (5) agent harness protocol updates with a deterministic recovery state machine for Stage and Ship agents.
