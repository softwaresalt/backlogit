Plan unit U9c. Red harness for the docs lint surface contract text, authored and observed failing BEFORE U8b writes that text - exactly as U3d precedes U4b. Scenario 1: the REGISTERED backlogit_docs_lint tool description names the decode_error rule value and states that a malformed document is returned as a finding in a successful tool result rather than failing the tool call. Scenario 2: that same description does NOT mention exit codes, because MCP has none and importing a shell concept into an agent-facing tool contract is a leaky abstraction. Scenario 3: the docs lint Cobra Short, Long, and Example strings name the decode_error rule value and state that the non-zero exit is retained. Assertions read the registered tool description through the exported server handle and the constructed Cobra command, never a package-level literal, so a description that is written but never registered cannot produce a false green. Split out of U9a during the PR #372 remediation cycle: bundling these contract-text assertions into U9a forced U9a to be scheduled after U8b, which made its red result unobservable at its own commit boundary and violated test-first development.
