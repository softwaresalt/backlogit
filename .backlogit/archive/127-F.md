Bug from stash EF4C0EC6: docline lint (MCP backlogit_docs_lint and CLI docs lint) fails on Windows when the workspace root resolves relative (MCP server RootPath equals dot), erroring on filepath.Rel making an absolute path relative to a relative base. Root cause: collectInScopeDocs walks an absolute base from SafeResolve but calls filepath.Rel with the raw possibly-relative root. Fix (Ship implements, test-first): U1 failing relative-root test in internal/docline/service_test.go, U2 absolutize the Rel base via filepath.Abs(root).
