Backlogit synchronously invokes autoharness gate check before writing task/subtask -> done and shipment -> shipped, as an inline core completion service (one-way core->gate boundary). Two-level gating, three-valued enabled (auto/true/false), exit trichotomy, repeated_failure requeue/escalate (backlogit sole executor), CLI-only audited force, logs-only evidence, advisory doctor check. Min autoharness >= 1.4.7.
