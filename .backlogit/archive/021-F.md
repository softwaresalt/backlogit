Build a telemetry harvester that reads workspace-scoped Copilot CLI telemetry from `.copilot/`, correlates it with backlogit task completions, attributes tool calls to their originating MCP servers, and exposes metrics through backlogit's existing SQL query surface. The headline metric is tokens-per-completed-task.
