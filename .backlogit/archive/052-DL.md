# Make plan-review gate dispatchable and fail-closed

## Problem Frame

<!-- BEGIN:problem-frame -->
The formal plan-review skill requires independent persona subagents before harvest, but this Stage invocation exposes no agent/runSubagent tool even though repo Stage definitions declare it. Determine whether dispatch is supported and make absence explicit rather than silently substituting inline self-review.
<!-- END:problem-frame -->

## Options

<!-- BEGIN:options -->
A. Use the declared agent/runSubagent tool when exposed, require per-persona attributed evidence, and fail closed otherwise. B. Allow hosted Copilot review to substitute. C. Permit a narrow operator waiver when dispatch is unavailable.
<!-- END:options -->

## Chosen Direction

<!-- BEGIN:chosen-direction -->
Adopt A as the normal path. The repository is structurally dispatch-capable in supported Copilot environments: plugin/agents/stage.agent.md declares agent/runSubagent, .github/agents/.stage.agent.md declares agent, Stage has subagent_depth 2, and the Orchestrator depth budget reaches reviewer personas. This API invocation omitted the agent tool, so the failure is invocation-surface degradation, not an impossible architecture. Hosted review remains supplemental. Add an explicit, operator-authorized, plan-scoped, expiring/fail-closed waiver only as contingency; absent dispatch or valid waiver blocks harvest.
<!-- END:chosen-direction -->

## Open Questions

<!-- BEGIN:open-questions -->
Exact waiver storage should be an appended gate artifact in the plan with operator identity/authorization reference, scope, reason, missing capability, timestamp, expiry or single-use boundary, acknowledged risks, and verdict. Formal success requires actual attributed persona outputs; inline self-assessment must never be labeled formal.
<!-- END:open-questions -->

## Notes

<!-- BEGIN:notes -->
Evidence: .github/skills/plan-review/SKILL.md requires persona spawning; .github/agents/.stage.agent.md tools include agent and subagent_depth 2; plugin/agents/stage.agent.md exposes agent/runSubagent; _orchestrator.agent.md permits depth 3 through review personas; reviewer agents are leaf subagent_depth 0. Current Stage API tools contain no agent/task dispatch tool.
<!-- END:notes -->
