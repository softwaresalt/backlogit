# docline extension ownership: Model A (nested docline.backlogit.*) vs Model B (top-level)

## Problem Frame

<!-- BEGIN:problem-frame -->
Where do backlogit-owned extension properties (size, size_source, size_ruleset_version) live in docline frontmatter, and who owns/validates them? Base top level is additionalProperties:false (closed shared contract engram/graphtor read); the docline map is additionalProperties:true (sanctioned extension bag).
<!-- END:problem-frame -->

## Options

<!-- BEGIN:options -->
Model A (CHOSEN): nest a backlogit owner-profile under the docline map as docline.backlogit.* ; top level stays additionalProperties:false; a layered ext schema (allOf on base v1) validates ONLY the docline.backlogit subtree, owned+versioned by backlogit. // Model B (095-S: 107.009/010/011/012-T; also baked into 109.001-T): open base schema top-level (additionalProperties:true), keep extension keys TOP-LEVEL, docline stops folding under docline.
<!-- END:options -->

## Chosen Direction

<!-- BEGIN:chosen-direction -->
Model A (operator decision 2026-07-16). Nest the backlogit sub-schema under the docline property bag (docline.backlogit.*, per-owner schema_version, additive-not-enveloping); keep top level closed (additionalProperties:false). Rationale: a consumer such as engram can be BOTH docline- AND backlogit-schema-aware via a composed/layered schema; the closed top-level shared contract engram/graphtor trust is preserved. DURABILITY SCOPE (corrected): nesting is round-trip-durable for docline DOCUMENTS - docline own codec preserves the whole docline map (internal/docline BaseFrontmatter.Docline, FromMap/ToMap). It is NOT automatically durable on .backlogit ARTIFACT frontmatter: backlogit generic artifact codec (models.ArtifactFromFrontmatter / core.WriteArtifactFile) carries only custom_fields and has no docline carrier, so a top-level docline map is DROPPED on artifacts. (Model A is still closer to current HEAD, which folds unknown top-level keys under docline for DOCUMENTS.) Persisting docline.backlogit ON .backlogit ARTIFACTS therefore requires an artifact-codec bridge whose selection stays OPEN in the 109.x size spike and must be proven by an executable round-trip test. SUPERSEDES Model B: 107.009/010/011/012-T are archived (terminal) and removed from 095-S; 096-S/109.001-T size-ownership framing flips from top-level to docline.backlogit.* (e.g. docline.backlogit.size).
<!-- END:chosen-direction -->
