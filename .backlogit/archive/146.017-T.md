Plan unit U7b, NARROWED by the PR #372 remediation cycle. Scenario 1 is a DIRECT sentinel guard on decodeDoc: call the unexported decodeDoc(root, rel) - reachable because internal/docline tests are in-package - with a rel that makes its own core.SafeResolve fail, and assert errors.Is(err, ErrPathEscapesWorkspace) is true while errors.Is(err, ErrFrontmatterDecode) is false. Provenance is established by construction; no assertion may read err.Error(). The previously required "and LintTree over the same corpus returns nil, err" clause is REMOVED as unconstructible: LintTree feeds decodeDoc only the paths collectInScopeDocs produced, and those are filepath.Rel(absRoot, p) results for files walked INSIDE the already-SafeResolved base (service.go:225-283), so decodeDoc's own SafeResolve can never fail for them, and the direct decodeDoc call does not inject its error into LintTree. Keeping it would give this green-throughout guard an unattainable acceptance condition. The propagation guarantee is relocated to U8's classifyDecodeFailure table test plus U8's obligation to return the classifier's fatal value unchanged. Scenario 1b is the honest LintTree-level guard: Options{Path: "../escape"} returns nil findings and ErrPathEscapesWorkspace via collectInScopeDocs, labelled as covering that edge only. Scenario 2 constructs the unreadable file portably by passing a rel resolving to a DIRECTORY (chmod 0o000 is rejected as a Windows no-op), asserts errors.Is(err, ErrFrontmatterDecode) is false, and asserts over an ordinary corpus that no finding's File or Fix contains the workspace absolute path prefix. Must not reference classifyDecodeFailure, which does not exist until U8.
