Add three new Go structs to `internal/telemetry/records.go`: `ToolCallFact` (one row per tool call with tool name, server, session, branch, repo, model, duration_ms, success, timestamp), `SessionFact` (one row per shutdown session with context window breakdown and total API duration), and `ModelUsageMetrics` (per-model token breakdown: input, output, cache_read, cache_write, reasoning). All fields use `omitempty` for additive schema evolution. No star-schema joins required at query time.
