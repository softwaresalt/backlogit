Node.js built-in https module does not respect HTTPS_PROXY env var. Users behind corporate proxies cannot download the backlogit binary via tier3. Add proxy agent support: check HTTPS_PROXY/https_proxy env and configure an https.Agent accordingly, or document the workaround (pre-install via go install).
