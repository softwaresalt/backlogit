Plan unit **U2**. Conformance helper skeleton plus the unknown top-level key rule.

Files: `internal/events/checkpoint_conformance.go` (new), `internal/events/checkpoint_conformance_test.go` (new).

Add exported `CheckConformingTopLevelNamespace(data []byte) error`. Reuse `decodeTopLevelEntries` and `isFoldKeyIn` unchanged; return `*backlogiterrors.CheckpointNonConformingError` directly so `errors.As` resolves in one hop. The read-boundary legal-key set is `checkpointV1TopLevelKeys ∪ checkpointV1ReservedKeys`; U2 wires this as an **inline two-set check** (`isFoldKeyIn(k, checkpointV1TopLevelKeys) || isFoldKeyIn(k, checkpointV1ReservedKeys)`) against the two already-existing sets. The named package-level derived set `checkpointV1AllTopLevelKeys` is deliberately **not** introduced by this unit — its introduction and the refactor of `CheckConformingTopLevelNamespace` onto it belong to **147.005-T / U2d** as that unit's real production delta (cycle-8 rebalance under P-004). Perform **no** reserved-status-value check: `status: "abandoned"` is a legal read-boundary value because the reserved keys are admitted.

Use a new file, not `checkpoint_strict.go`: the read boundary and the create boundary have deliberately different legal key sets and must not read as one mechanism.
