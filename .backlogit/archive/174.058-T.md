Flatten the **machine-readable member projection** and the **ship/closure feature-hierarchy cleanup** to flat explicit membership (spec §0.5 / SBLK-R28; plan §0.4). Green-maker for `174.056-T` (`TestUReleaseScopeRegression_`) **and `174.060-T` (`TestUArchiveCandidateFlat_`)**.

Changes (all in `internal/core`):
- **(a) Member projection** — `compositionMemberIDs` (`size_composition.go:291`) for shipments returns the **flat explicit manifest members** and does NOT expand a listed feature into its child tasks. the function already excludes the feature itself as non-sizable, so `size_composition.members` becomes the set of **explicitly-listed task members** (`155-S`: **25 task members**, down from the hierarchy-expanded superset of ~60); the covering feature `174-F` remains excluded from the sizable member set (manifest `items` is now **26 incl. `174-F`**).
- **(b) Ship/closure feature-hierarchy cleanup** — neutralize the descendant **and linked-deliberation** re-expansions that survive a flat `releaseScope`, all inside the covering-feature loop of `collectArchiveCandidateIDs` (`shipment_lifecycle.go:800`, guarded by explicit membership per 133.004-T): (i) it must NOT archive unlisted **terminal-but-not-archived** descendants — status `done`/`accepted`, which `isTerminalReleaseStatus` currently appends (already-`archived` descendants are skipped today, so they were never the RED-real case); (ii) it must NOT append a member feature's **linked deliberations** (`linkedDeliberationIDs(feature)` → `candidates = append(candidates, deliberations...)`) — an unlisted linked deliberation must be left untouched and absent from `ArchivedIDs`. Separately, `returnUnreleasedFeatureItems` (`:735`) must NOT return-to-backlog or **`clearParentID`/orphan** unlisted non-terminal descendants. A listed member feature is still marked done (`:748`); its unlisted descendants and linked deliberations are left entirely untouched (flat membership). Update the tightly-coupled existing tests that encode the old expand-and-cleanup behavior (e.g. `TestShipShipment_CleansReleasedFeatureScope` in `shipment_test.go`, the archive-cascade assertions in `archive_test.go`).
- **(c) Feature-only / zero-executable-task lifecycle** — a manifest whose only executable content is the covering feature ships/closes by completing the listed members only, touching NO unlisted descendant, and **frees the single active slot** (P-001) because the shipment reaches terminal `shipped`; the completion gate must not block on an empty/feature-only member set. Kept tightly coupled to flat-manifest semantics.

Constraints: **no public/exported API** introduced; internal behavior change only. Do NOT restore archived/superseded tasks. Do NOT authorize or apply any topology `--force` (the external wave/topology gate is independent of this projection/cleanup).
