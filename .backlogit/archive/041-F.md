Fix filesystem/SQLite index ordering bugs in CLI delete, stash harvest, and archive operations. All three share the same root cause: filesystem operations and DB operations are not ordered correctly for crash-safety, so partial failure can leave the workspace in an inconsistent state. Fix pattern is reorder operations or add rollback/restore logic following the persistArtifact() model in internal/core/shipment.go.
