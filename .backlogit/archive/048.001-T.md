Create plugin/ directory with plugin.json manifest, .mcp.json config, and copies of universal agents and skills for Copilot CLI plugin distribution.

<!-- BEGIN:acceptance-criteria -->
- `copilot plugin install ./plugin` succeeds
- `copilot plugin list` shows backlogit plugin
- `/agent` shows stage and ship agents
- `/skills list` shows all 19 bundled skills
- `make verify-plugin` passes when copies match source
- `make verify-plugin` fails when copies are out of date
<!-- END:acceptance-criteria -->

<!-- BEGIN:description -->
Create `plugin/` directory at repo root with:

1. `plugin.json` manifest: name `backlogit`, version synced from Go release tag, author, license (MIT), keywords (backlogit, mcp, workflow, agents), component paths.
2. `plugin/agents/`: copies of `stage.agent.md` and `ship.agent.md`. Excluded: go-engineer, go-mcp-expert, prompt-builder, auto-tune, auto-mergeinstall, adversarial-review (repo-specific).
3. `plugin/skills/`: copies of all 19 universal skills: build-feature, compact-context, compound, compound-refresh, deliberate, file-lock, fix-ci, harness-architect, harvest, impl-plan, operational-closure, plan-harden, plan-review, pr-lifecycle, review, runtime-verification, safety-modes, skill-search, spike.
4. `plugin/.mcp.json`: backlogit MCP server config using `npx -y @backlogit/backlogit-mcp mcp`.
5. `make verify-plugin` target or CI step that diffs plugin copies against `.github/` source to detect drift (addresses plan review P2-1).
<!-- END:description -->
