## Findings

### CR-002 (P2) — internal/telemetry/harvest.go — FIXED

`writeTelemetryJSONL` called `os.Rename(tmpPath, jsonlPath)` without first removing the destination file. On Windows, `os.Rename` fails when the destination already exists. The same `_ = os.Remove(path)` pre-remove pattern used in `syncWriteFileAtomic` and `telemetry/checkpoint.go` was missing here. **Fixed**: added `_ = os.Remove(jsonlPath)` before rename in commit d9033bb.
