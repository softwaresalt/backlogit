title: Add comment explaining direct io.EOF equality in harvest.go ReadString loop
updated_at: 2026-04-25T22:31:44.5442355-07:00

In `internal/telemetry/harvest.go`, `io.EOF` is compared using direct equality (`readErr == io.EOF`) rather than `errors.Is(readErr, io.EOF)`. This is technically correct because `bufio.ReadString` returns unwrapped `io.EOF`, but it differs from the idiomatic pattern used in `parser.go` and is confusing without explanation.\n\nAdd a comment above the EOF check in `readSessionJSONL` explaining why direct equality is used instead of `errors.Is`: the `internal/errors` import shadows the standard `errors` package and `bufio.ReadString` guarantees an unwrapped `io.EOF`.\n\nReview context: P2-B from 047.001-R. Affected file: `internal/telemetry/harvest.go`.
