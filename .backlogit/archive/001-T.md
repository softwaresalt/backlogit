title: QueryItems pagination produces non-deterministic pages without ORDER BY
updated_at: 2026-04-08T17:02:27.6652216-07:00
---

LIMIT/OFFSET pagination in QueryItems appends SQL clauses without a preceding ORDER BY. SQLite does not guarantee row ordering without ORDER BY, so paginated results are non-deterministic. Callers using offset>0 may see different or repeated rows across pages.\n\nAffected file: internal/db/queries.go (QueryItems, ~line 256)\n\nFix: when filters.Limit > 0, prepend ORDER BY id ASC before the LIMIT clause. The id column is indexed and provides stable, repeatable pagination.\n\nReview reference: 019.001-R (finding F-1)
