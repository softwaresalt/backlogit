# DeriveBranchType Classifier

Add `DeriveBranchType(branch string) string` to classify branches by naming convention.

## Approach

- Add function adjacent to `DeriveModelClass` in `internal/telemetry/records.go`
- Classification rules in order: empty→"", feature/→"feature", chore/stage-→"stage", ship/→"ship", post-merge/→"post-merge", chore/→"chore", main|master→"main", fallback→"other"
- Rule ordering is critical: `chore/stage-*` must be matched before generic `chore/*`

## Acceptance Criteria

- `""` → `""`
- `"feature/057-f-slug"` → `"feature"`
- `"chore/stage-056-s-slug"` → `"stage"`
- `"ship/055s-slug"` → `"ship"`
- `"chore/fix-x"` → `"chore"`
- `"post-merge/slug"` → `"post-merge"`
- `"main"` → `"main"`, `"master"` → `"main"`
- `"release/v1"` → `"other"`
