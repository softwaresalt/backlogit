## Findings

### P1 — Fixed

**P1-A: ValidateSessionSummary not wired into harvest pipeline** (`internal/telemetry/harvest.go`)
- `ValidateSessionSummary` existed in `validate.go` and was tested, but was never called in the production path. Partial sessions with `TotalTokens==0 && ToolCalls>0` were still written to JSONL.
- Fix: Added filter loop after `Correlate` call in `Harvest()` (commit c56504d).

**P1-B: RehydrateTelemetry in db/telemetry_schema.go uses bufio.Scanner with 1MB limit** (`internal/db/telemetry_schema.go`)
- `RehydrateTelemetry` still used `bufio.NewScanner` with a 1MB buffer cap. This is the same bug fixed in `parser.go` but was missed in the DB rehydration path. Oversized JSONL records would silently drop during SQLite rehydration.
- Fix: Replaced with `bufio.NewReader` + `ReadString` loop (commit c56504d).

### P2 — Backlog follow-up items created

**P2-A: Integer division truncation in proportional token attribution** (`internal/telemetry/reporter.go:formatServerTable`)
- `tokensByServer[server] += s.TotalTokens * count / totalCalls` uses integer arithmetic. For non-divisible values the result is correct but slightly imprecise due to truncation.
- Recommendation: Use float64 intermediate for accumulation, round at display time.
- Follow-up: See backlogit task created.

**P2-B: Inconsistent io.EOF handling between parser.go and harvest.go** (`internal/telemetry/`)
- `parser.go` uses `errors.Is(readErr, io.EOF)` (correct, idiomatic Go) while `harvest.go` uses `readErr == io.EOF` (necessary due to internal/errors import shadowing standard `errors`).
- The inconsistency is correct but confusing; a comment should explain why direct equality is used in harvest.go.
- Follow-up: See backlogit task created.

## Learnings Applied

- Pattern: `bufio.NewReader + ReadString('\n')` for robust unbounded JSONL line reading (from prior session learning — same fix applied to db rehydration path that was missed the first pass).
- Import disambiguation: `internal/errors` import prevents use of `errors.Is` from stdlib in harvest.go; direct `== io.EOF` comparison is correct because `bufio.ReadString` returns unwrapped `io.EOF`.
