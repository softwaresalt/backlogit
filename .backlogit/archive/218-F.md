Enable `backlogit init` and `backlogit install` (`internal/cli/root.go`, `internal/cli/self_install.go`, `internal/cli/mcp_daemon.go`, `internal/toolchain/verify.go`, and `internal/toolchain/launcher.go`) to prompt the operator on interactive TTY or piped subprocess stdin (or accept `--tools-dir`, while disabling stdin reads and prompting when `--jsonrpc` is enabled so buffered JSON-RPC output cannot deadlock or include prompt text) for a target tool install directory (`.bin` default, `bin`, or a user-entered alternate workspace-relative directory), validate every component from the volume/filesystem root anchor handle and create missing suffixes handle-relatively (`openOrCreateValidatedWorkspaceRoot`, never path-based `os.MkdirAll`), perform handle-confined bootstrap writes (`writeWorkspaceBootstrapDefaults` on `storageHandle *os.Root`, tested in `package cli` via `initBeforeWriteDefaultsHook` in `218.007-T`), resolve relative `workspace_root` values (such as `"."`) against the target workspace rather than ambient process `cwd` across loading, verification, and provisioning and expose `VerifyProposedLauncherScripts` (`218.006-T` and `218.008-T`), run unconditional non-short-circuiting read-only preflight across all 5 sources (`defaultTargetToolsDir(cleanRoot string) (string, error)` / `resolveConfiguredDaemonBinaryRel`, treating `BACKLOGIT_WORKSPACE_DIR=""` as unset and verifying the running/external source image separately, all unchanged non-`backlogit` inventory entries via `VerifyWorkspaceToolchain` on `unchangedManifest` without inserting an external installer path, proposed canonical `ToolEntry.ID = "backlogit"` against any `LockfilePath` provenance, and `start.ps1`/`start.sh` launcher migration compatibility via `VerifyProposedLauncherScripts`) before any directory creation, binary install, `.mcp.json` write, or manifest write on every path (including `--tools-dir` overrides), create the target tool directory via pinned `*os.Root` directory handles if it does not yet exist, install `backlogit[.exe]` there prior to configuring `.mcp.json` (without letting `os.SameFile` short-circuit downstream provisioning), canonicalize the configured daemon entry into `mcpServers.backlogit` via `map[string]json.RawMessage`, reconcile existing `<storage_root>/toolchain.yaml` and existing `start.ps1`/`start.sh` launchers via override-aware (`BACKLOGIT_WORKSPACE_DIR`) typed `ToolchainManifest` load-mutate-validate-write (publishing the reconciled manifest before running disk-based `VerifyLauncherScripts`), record literal-escaped `/<escapedToolsDir>/backlogit[.exe]` ignore rules in `.gitignore` and `.git/info/exclude`, and regenerate `docs/cli-reference/backlogit_init.md` via `cmd/gen-docs`.
