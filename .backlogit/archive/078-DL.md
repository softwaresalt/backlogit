# Deliberation: Reconstitution Scoped Recovery Preimage Invariant vs Deferred Cross-Writer Attribution (7E14915F / 210-S)

## Problem Frame

<!-- BEGIN:problem-frame -->
During 210-S / 209.002-T (PR #638) remediation of shipment reconstitution crash recovery (internal/core/shipment_reconstitute_exec.go), stash entry 7E14915F was captured as a DEFERRED SCOPE EXPANSION for designing durable mutation attribution or cross-writer coordination so crash recovery can distinguish reconstitution's own changes from later independent artifact updates. Stage deliberation under P-021 C6 is required to establish the exact boundary between: (1) the bounded preimage-invariant check and ctx lock propagation that belong in-scope for 210-S / 209.002-T within the existing reconstituteJournalState contract surface, and (2) the broader cross-writer coordination / durable per-mutation attribution architecture that remains out-of-scope for 210-S and deferred in 7E14915F.
<!-- END:problem-frame -->

## Options

<!-- BEGIN:options -->
* Option A (Chosen — Bounded Preimage-Invariant Check in 210-S + Defer General Cross-Writer Attribution in 7E14915F): Enforce fail-closed preimage invariants in rollbackReconstitute using only existing reconstituteJournalState fields (Images, ScopedImages, Adoptions, EventIDs) for all fields reconstitution never mutates (including CustomFields keys outside {"items", "origin_feature", "blocked_reason", "claim_marker"} such as size/complexity, plus cross-reference-only rewind matching for owners not in state.EventIDs), and complete applyReconstitution ctx lock propagation for newly created features. Defer general cross-writer coordination / durable per-mutation attribution for reconstitution-mutable fields on direct targets in state.EventIDs to a future shipment harvested from 7E14915F.
* Option B (Rejected for 210-S — Expand reconstituteJournalState Schema with Post-Image / Per-Mutation Attribution inside 210-S): Introduce new journal schema fields or cross-writer attribution metadata during 210-S remediation. Rejected because P-021 C1 forbids expanding the journal schema or introducing a new cross-writer coordination contract inside an active shipment remediation pass.
* Option C (Rejected — Unconditional Byte-Snapshot Overwrite on ScopedImages Rollback): Allow ScopedImages rollback to overwrite artifacts without checking reconstitution-immutable fields. Rejected because it overwrites independent updates to fields reconstitution never touches (such as size/complexity) and fails TestRound3RecoveryPreservesIndependentSize and Copilot comment 4434730479.
<!-- END:options -->

## Chosen Direction

<!-- BEGIN:chosen-direction -->
Option A (Split in-scope bounded preimage-invariant check for 210-S / 209.002-T from out-of-scope general cross-writer coordination / durable mutation attribution deferred in 7E14915F):

1. IN-SCOPE FOR 210-S / 209.002-T (PR #638) UNDER P-021 C1/C3 (SAME CONTRACT SURFACE, ZERO NEW JOURNAL SCHEMA):
   * In rollbackReconstitute (internal/core/shipment_reconstitute_exec.go), using ONLY the existing reconstituteJournalState fields (Images, ScopedImages, Adoptions, EventIDs — zero new journal fields or cross-writer attribution schema), add a bounded preimage-invariant check when state.ScopedImages && image.Exists && !bytes.Equal(current, image.Content):
     (a) Move the knownLogs / discovered / pairs (oldID -> newID) calculation before the state.Images validation loop.
     (b) Parse preArt from image.Content and curArt from current. Reject rollback fail-closed (reconstituteValidationError("snapshot %s changed outside reconstitution", image.Path)) if any field that reconstitution never modifies differs between preArt and curArt: ID, Title, ArtifactType, Description, Sprint, Priority, AssignedTo, Owner, Commit, !preArt.CreatedAt.Equal(curArt.CreatedAt), !slices.Equal(preArt.References, curArt.References), any CustomFields key other than "items", "origin_feature", "blocked_reason", "claim_marker" (checked in both directions across preArt.CustomFields and curArt.CustomFields — deterministically protecting independent size, size_source, size_ruleset_version, and complexity updates), or curArt.Links after rewinding newID -> oldID via pairs.
     (c) When owner is not in state.EventIDs (a cross-reference-only snapshot owner), also reject rollback fail-closed if rewinding newID -> oldID across ParentID, Dependencies, Links, and shipment CustomFields["items"] (with UpdatedAt = preArt.UpdatedAt) does not match preArt via recoveryArtifactMatchesAny.
   * Complete the in-scope applyReconstitution ctx lock propagation for newly created features (P2).
   * This satisfies TestRound3RecoveryPreservesIndependentSize (scoped=false/true, cross_reference=false/true) and Copilot comment 4434730479 within the existing 210-S contract surface.

2. OUT-OF-SCOPE AND DEFERRED IN 7E14915F (078-DL) AND D3C8D13B (080-DL) UNDER P-021 C1/C2/C6:
