Decompose into five independent test-first tasks, one per file, each reconciling the two-class durability contract (commit-then-surface: never roll back ErrWriteIndeterminate; ErrWriteNotApplied is safe-retry). Sites: (1) UnarchiveItem non-git restore [archive.go]; (2) AddDependency/RemoveDependency via persistArtifact [dependencies.go]; (3) appendDurable parent re-flush [events/stream.go]; (4) core mkdirAllDurable parent re-flush [durable_fs.go]; (5) MCP append_comment explicit durability outcomes [mcp/tools.go]. Only U1 depends on U4: UnarchiveItem calls the shared core.mkdirAllDurable, whereas U2 uses persistArtifact(relocate=false), which returns before mkdirAllDurable is reached. U2 and U5 require a new package-local write seam (no existing seam fires on their path). durable_writes=false behavior unchanged; opt-in default-off => P2. Each task keeps <=3 test scenarios (2-Hour Rule).
