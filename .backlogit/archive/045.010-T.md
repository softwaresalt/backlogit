Update Stage and Ship agent Session Continuity sections with deterministic recovery state machine and mid-session checkpoint cadence. Depends on Unit 4 (protocol references the new MCP tools).

Files: .github/agents/stage.agent.md, .github/agents/ship.agent.md

Recovery state machine (add to both agents):
SESSION_START -> call list_checkpoints(consumer_id=self, status="active", max_age_hours=168) -> if empty: FRESH_START -> if non-empty: RECOVERY_DECISION
RECOVERY_DECISION -> present summaries (phase, context, tasks, resume hint, validation status) -> surface quarantined checkpoints as warnings -> ask operator -> if resume: RESUME_FROM_CHECKPOINT -> if fresh: FRESH_START
RESUME_FROM_CHECKPOINT -> call get_checkpoint(filename) -> if valid=false: warn, fall back to FRESH_START -> restore context -> resolve other active checkpoints -> continue from phase
FRESH_START -> resolve all active checkpoints from prior sessions -> proceed with existing memory scan

Mid-session checkpoint cadence:
- Ship: harness-complete, per-task-complete, review-gate, CI-pass, PR-ready
- Stage: triage-complete, deliberation-complete, plan-review-complete, harvest-complete
- Include resume_hint with actionable next step

Session-end: resolve all active checkpoints; on graceful context-window shutdown write final checkpoint (best-effort).
