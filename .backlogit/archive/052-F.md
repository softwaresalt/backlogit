title: Fix harvest scanner overflow in session events parser
updated_at: 2026-05-08T18:43:05.2030071-07:00
---

The `backlogit harvest` (telemetry harvest) command fails with `scan session events: bufio.Scanner: token too long` when Copilot CLI `events.jsonl` files contain lines exceeding 1MB. Root cause: `ParseSessionEvents` in `internal/telemetry/session_events.go` uses the default `bufio.Scanner` without increasing the buffer or switching to `bufio.NewReader`. The fix pattern is established — `parser.go` already uses `bufio.NewReader` + `ReadString('\n')` to handle oversized lines gracefully. Apply the same pattern to `session_events.go`. Source stash: 8F88FABE.
