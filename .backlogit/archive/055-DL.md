# Shipment sequencing primitives for dark-factory queue ordering (spike 001-SP Option B)

## Problem Frame

<!-- BEGIN:problem-frame -->
Stash 0B5FA82B captures backlogit product-side shipment-sequencing gaps that make multi-shipment ordering uneven for long-running dark-factory (P-017) runs. Candidates: (a) shipment-scoped queue_position, (b) shipment->shipment blocking-order affordance, (c) meaningful shipment priority, (d) optional non-authoritative ship_sequence audit surface. Decision question: smallest high-value coherent backlogit release unit supported by spike 001-SP. Durable deliberation: docs/decisions/2026-08-01-shipment-sequencing-primitives-deliberation.md
<!-- END:problem-frame -->

## Options

<!-- BEGIN:options -->
Opt1 (a+b+c): complete but over-scoped; (a) rewrites global ordering SQL, high blast radius. Opt2 (b+c): spike Option B primitives; complete sequencing surface (priority tie-break + blocking order); reuses existing plumbing; low-moderate blast radius. Opt3 (c only): minimal but incomplete; leaves blocking-order half unaddressed. Opt4 (+d): contradicts spike Option D and stash gating; no multi-shipment evidence of insufficient activation evidence; fails YAGNI.
<!-- END:options -->

## Chosen Direction

<!-- BEGIN:chosen-direction -->
SELECT Option 2 = candidates (b)+(c) as one coherent release unit. (c) meaningful/settable shipment priority resolves the spike's named Orchestrator selection gap and reuses existing priority plumbing (WithPriority, priority filter, buildQueueOrderClause priority sort). (b) first-class validated documented shipment->shipment blocking affordance over existing item_deps blocks mechanism with a sync-surviving regression guard. Together they give dark-factory a complete low-risk sequencing surface via queue view --type shipment --status queued without touching shared global ordering SQL or adding a new authoritative scheduler. DEFER (a) global queue_position refactor (highest blast radius, not spike-required) and (d) ship_sequence.jsonl audit surface (spike Option D + YAGNI; 113-S/114-S/115-S closed successfully on activation evidence). Both deferrals stay captured for a future Stage session.
<!-- END:chosen-direction -->
