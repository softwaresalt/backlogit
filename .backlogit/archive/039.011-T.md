Create minimal bash and PowerShell one-liner install scripts. Primary user path: download the standalone binary from GitHub Releases and place it wherever they want, then add that location to PATH. The install script is a convenience wrapper that automates this — detect OS/arch, download, verify checksum, place in a standard location. Must be invocable as a single copyable command (curl|sh for unix, irm|iex for Windows), similar to how uv, rustup, or Homebrew installers work. Files: scripts/install/install.sh, scripts/install/install.ps1. Effort: medium. Domain: scripts.
