updated_at: 2026-04-08T17:02:27.9051578-07:00

lockStashFile creates stash.jsonl.lock using O_CREATE|O_EXCL. If the process crashes while the lock is held, the sidecar persists and all subsequent stash writes fail with 'stash locked by another process' until the sidecar is manually removed.\n\nAffected file: internal/core/stash_lock.go\n\nFix: in lockStashFile, before failing with an error, check the sidecar file mtime. If it is older than a configurable threshold (e.g., 60 seconds), log a warning, remove the stale sidecar, and retry the O_CREATE|O_EXCL open.\n\nReview reference: 019.001-R (finding F-2)
