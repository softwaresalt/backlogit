## Objective

Implement cross-branch and multi-session artifact ID sequence counter reservation and isolation (`3083FC1A` / `091-DL` / Unit U5a, paired with Unit U5b in `215.008-T`) in `internal/core/id_history.go` and `internal/core/artifacts.go` using a pinned `.locks` directory handle (`*os.Root`) for all ledger, allocator-lock, and rollback operations so concurrent or interleaved branch sessions never allocate duplicate `NNN-F` or `NNN.MMM-T` work item numbers.

## Scope and Affected Files

* **Domain**: `code` (`internal/core`)
* **Execution posture**: `test-first`
* **Dependencies**: `blocks` on `215.001-T` (Unit U1, for `atomicfile.ReplaceTempFileInRoot`); prerequisite for `215.008-T` (Unit U5b, extending reservation/rollback to `AdoptItemWithOptions` in `internal/core/shipment_lifecycle.go` and outer-operation rollback/recovery in `internal/core/shipment_reconstitute_exec.go`)
* **Affected files (3)**:
  * `internal/core/id_history.go`
  * `internal/core/artifacts.go`
  * `internal/core/id_history_test.go`

## Implementation Details

1. In `internal/core/id_history.go`, implement a workspace-scoped sequence reservation store backed by `<storage_root>/.locks/id-sequences.json` and confined to a **pinned `.locks` directory handle (`*os.Root`)**:
   * Open `storageHandle, err := os.OpenRoot(storageRoot)` (after verifying `storageRoot` via `Lstat` + `EvalSymlinks` + `pathContained` + `IsSymlinkOrReparsePoint`) and open `locksRoot, err := storageHandle.OpenRoot(".locks")` (creating `.locks` via `storageHandle.Mkdir(".locks", 0o755)` only on write/lock paths after `storageHandle.Lstat(".locks")` rejects any symlink or reparse point, while keeping read-only `historicalIDsFromDisk(ws)` and `allocateTypedHierarchicalID` strictly zero-write when `.locks` or `id-sequences.json` is absent so `ReconstituteShipments` `DryRun: true` writes nothing).
   * Perform **all** ledger reads, temp creation, publication, rollback, and allocator-lock operations relative to the pinned `locksRoot` handle (closing `locksRoot` and `storageHandle` on return):
     * **Allocator lock (`id_allocator.lock`)**: Reject any symlink or reparse point at `locksRoot.Lstat("id_allocator.lock")` (`ErrValidation`), verify on Windows that `locksRoot`'s live kernel path (`GetFinalPathNameByHandle`) still matches `EvalSymlinks(locksDirAbs)` (so a `.locks` directory swap after validation fails closed before acquiring or writing any lock file), and acquire the in-process allocator mutex plus cross-process advisory lock (`id_allocator.lock`) with a dedicated `idAllocatorLockBoundedWait = 30 * time.Second` budget.
     * **Handle-relative ledger reads, publication, and rollback (`id-sequences.json`)**: Reject any leaf symlink, reparse point, or non-regular file at `locksRoot.Lstat("id-sequences.json")` (`ErrValidation`), read existing bytes via `locksRoot.OpenFile("id-sequences.json", os.O_RDONLY, 0)` + `os.SameFile(openedStat, lstatAfterOpen)`, create temp files via `locksRoot.OpenFile(tmpName, os.O_CREATE|os.O_EXCL|os.O_WRONLY, 0o600)` + `os.SameFile`, publish via `atomicfile.ReplaceTempFileInRoot(locksRoot, locksDirAbs, tmpName, "id-sequences.json", WorkspaceDurableWrites(ws))`, and roll back via `locksRoot.Remove("id-sequences.json")` (when the preimage was absent or when `unreserveIDSequences(ws, ids)` empties the reserved set) or `atomicfile.ReplaceTempFileInRoot` (when restoring non-empty preimage bytes).
   * Include all reserved IDs from `<storage_root>/.locks/id-sequences.json`, `delta.new_id` / `delta.created_features` / `delta.created_shipments` / `delta.adopted_id_map` from `adopted` and `shipment_reconstituted` events in `eventLogIDs` (`.backlogit/logs/*.jsonl`), and a fingerprint-cached scan of `.backlog/` and `.backlogit/` artifact filenames across local `refs/heads/*` branches (when `.git` exists at `ws.RootPath` with multiple branches, executed with `ws.boundedHelperTimeout()`, `gate.MinimalEnv()`, `--no-replace-objects`, and `--no-optional-locks`) inside `historicalIDsFromDisk(ws)`.
2. In `internal/core/artifacts.go` (`CreateArtifact`), place `id_allocator.lock` at the innermost leaf of the canonical lock hierarchy (`stash -> lifecycle-global -> A -> C -> B -> id_allocator.lock`): acquire `id_allocator.lock` strictly *after* `validateArtifactParent` and `ws.HookRunner.FirePre(ctx, hooks.HookCreateArtifact, hookCtx)`, hold it across ID computation (`allocateTypedHierarchicalID` / `NextID`), durable outer-operation ownership journaling, and `MutationEnvelope`, and release `id_allocator.lock` *before* `ws.HookRunner.FirePost(ctx, hooks.HookCreateArtifact, hookCtx)`. Inside `CreateArtifact`, make persisting the newly allocated `artifactID` to `<storage_root>/.locks/id-sequences.json` a **compensated `MutationStep` (`Name: "id-sequence-reservation"`) inside `MutationEnvelope` unconditionally** (with **NO `shipmentOperationContextKey` exception**, and when `ctx` carries an active reconstitution pre-create ownership callback `shipmentOperationBeforeCreateContextKey`, invoke that callback **after `artifactID` is allocated under `id_allocator.lock` and BEFORE `MutationEnvelope` publishes the reservation or `.md` file** so `state.CreatedIDs` durably owns `artifactID` in the operation journal on disk before `id-sequences.json` is written; see `215.008-T`):
   * Capture the preimage of `<storage_root>/.locks/id-sequences.json` (existence + raw bytes) via `locksRoot` before running `MutationEnvelope`.
   * In `Apply`: persist the updated `<storage_root>/.locks/id-sequences.json` handle-relatively via `locksRoot` and `atomicfile.ReplaceTempFileInRoot` (with deterministic sorted JSON keys and an injectable seam `writeIDSequenceReservationFn` for deterministic failure and parent-swap testing). If `Apply` fails, `MutationEnvelope` automatically compensates prior steps (`db-upsert` and `file-write`) so neither Markdown nor SQLite retains an unreserved artifact.
   * In `Compensate`: restore `<storage_root>/.locks/id-sequences.json` to its exact preimage via `locksRoot` (`locksRoot.Remove("id-sequences.json")` if it did not exist before, or `atomicfile.ReplaceTempFileInRoot` to rewrite the preimage bytes) if any subsequent `MutationEnvelope` step fails.
