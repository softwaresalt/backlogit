# Honor .mcp.json, configurable tools_dir, and .bin default in MCP daemon startup and toolchain verification (2CCDFDED)

## Problem Frame

<!-- BEGIN:problem-frame -->
In released backlogit binaries, pinnedMCPDaemonBinary(workspace) (internal/cli/mcp_daemon.go:384-418, called by PrewarmMCPDaemon, RunMCPSessionShim, and VerifyMCPDaemonAttachment) hard-codes filepath.Join(workspace, 'bin', name) and rejects any workspace where bin/backlogit[.exe] is absent. Similarly, isPinnedBacklogitRelPath and isBacklogitExecutable (internal/toolchain/verify.go:304-335) and toolRemediation/launcherFinding/inspectLauncher (internal/toolchain/launcher.go:86-120,228) hard-code bin/. Additionally, scanLocalBranchArtifactIDsContext (internal/core/id_history.go:1148-1188) runs git ls-tree sequentially across all merged local branches in refs/heads under a 5s timeout, timing out in repositories with many historical branches. Because GSD defaults the workspace tool directory to .bin (and workspaces may configure custom tool directories or .mcp.json paths), other workspaces using .bin/backlogit[.exe] or custom .mcp.json command paths fail to start backlogit mcp with ErrDaemonBinaryMissing and fail static toolchain/MCP verification.
<!-- END:problem-frame -->

## Options

<!-- BEGIN:options -->
Option A: Replace hard-coded bin with .bin only. Pros: minimal diff. Cons: breaks existing bin/ workspaces and all TestU6/TestU9/TestU11/TestU12 fixtures, and ignores custom paths in .mcp.json or configurable tool directories. Option B (Recommended): Layered root-confined resolution in pinnedMCPDaemonBinary (.mcp.json -> toolchain.yaml -> config.yaml tools_dir -> .bin default -> bin fallback) descending step-by-step through pinned child *os.Root directory handles (matching openLocal in internal/toolchain/verify.go:102-153), paired with configurable tools_dir and .bin/bin/custom tool-directory support in internal/toolchain (verify.go preserving !isBacklogitTool early return for mixed inventories, launcher.go, types.go) and internal/config (schema.go), plus batched git cat-file --batch and tree/subtree OID deduplication across all refs/heads in scanLocalBranchArtifactIDsContext (internal/core/id_history.go). Pros: honors .mcp.json directly, defaults to .bin, supports configurable tools_dir (including mixed inventories), preserves strict *os.Root pinned child-handle no-follow containment, keeps all legacy bin/ fixtures green, and eliminates 5s branch-scan timeouts on repos with hundreds of branches while preserving all merged and unmerged branch-tip reservations (including merged-then-reverted artifacts). Option C: Fall back to os.Executable() or ambient PATH when bin/backlogit.exe is missing. Cons: violates Level 1 workspace-local pinning and breaks TestU6 and TestU12.
<!-- END:options -->

## Chosen Direction

<!-- BEGIN:chosen-direction -->
Option B (Selected): Implement layered root-confined resolution in pinnedMCPDaemonBinary (.mcp.json -> toolchain.yaml -> config.yaml tools_dir -> .bin default -> bin fallback) under os.OpenRoot(absWorkspace) descending step-by-step through pinned child *os.Root directory handles (Lstat + rejectLink + OpenRoot + Stat('.') + SameFile, opening the final leaf on the innermost pinned parent handle), add optional ToolsDir (tools_dir) to ToolchainManifest and WorkspaceConfig, update internal/toolchain/verify.go (preserving !isBacklogitTool early return so mixed inventories with remote-declared and built-in-host tools remain valid) and launcher.go to support .bin (default), bin, and configurable tool directories, and batch/deduplicate branch-tree inspection in scanLocalBranchArtifactIDsContext (internal/core/id_history.go) across all refs/heads using git cat-file --batch and subtree OID deduplication so all branch-tip reservations (including merged-then-reverted artifacts) are preserved without 5s timeouts.
<!-- END:chosen-direction -->
