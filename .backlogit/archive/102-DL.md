# Honor .mcp.json, configurable tools_dir, and .bin default in MCP daemon startup and toolchain verification (2CCDFDED)

## Problem Frame

<!-- BEGIN:problem-frame -->
In released backlogit binaries, pinnedMCPDaemonBinary(workspace) (internal/cli/mcp_daemon.go:384-418, called by PrewarmMCPDaemon, RunMCPSessionShim, and VerifyMCPDaemonAttachment) hard-codes filepath.Join(workspace, 'bin', name) and rejects any workspace where bin/backlogit[.exe] is absent. Similarly, isPinnedBacklogitRelPath and isBacklogitExecutable (internal/toolchain/verify.go:304-335) and toolRemediation/launcherFinding/inspectLauncher (internal/toolchain/launcher.go:86-120,228) hard-code bin/. Additionally, scanLocalBranchArtifactIDsContext (internal/core/id_history.go:1148-1188) runs git ls-tree sequentially across all merged local branches in refs/heads under a 5s timeout, timing out in repositories with many historical branches. Because GSD defaults the workspace tool directory to .bin (and workspaces may configure custom tool directories or .mcp.json paths), other workspaces using .bin/backlogit[.exe] or custom .mcp.json command paths fail to start backlogit mcp with ErrDaemonBinaryMissing and fail static toolchain/MCP verification.
<!-- END:problem-frame -->

## Options

<!-- BEGIN:options -->
Option A: Replace hard-coded bin with .bin only. Pros: minimal diff. Cons: breaks existing bin/ workspaces and all TestU6/TestU9/TestU11/TestU12 fixtures, and ignores custom paths in .mcp.json or configurable tool directories. Option B (Recommended): Layered root-confined resolution in pinnedMCPDaemonBinary (.mcp.json -> toolchain.yaml -> config.yaml tools_dir -> .bin default -> bin fallback) paired with configurable tools_dir and .bin/bin/custom tool-directory support in internal/toolchain (verify.go, launcher.go, types.go) and internal/config (schema.go), plus --no-merged=HEAD / unique-OID optimization in scanLocalBranchArtifactIDsContext (internal/core/id_history.go). Pros: honors .mcp.json directly, defaults to .bin, supports configurable tools_dir, preserves strict *os.Root no-follow containment, keeps all legacy bin/ fixtures green, and eliminates 5s branch-scan timeouts on repos with many merged branches. Option C: Fall back to os.Executable() or ambient PATH when bin/backlogit.exe is missing. Cons: violates Level 1 workspace-local pinning and breaks TestU6 and TestU12.
<!-- END:options -->

## Chosen Direction

<!-- BEGIN:chosen-direction -->
Option B (Selected): Implement layered root-confined resolution in pinnedMCPDaemonBinary (.mcp.json -> toolchain.yaml -> config.yaml tools_dir -> .bin default -> bin fallback) under os.OpenRoot(absWorkspace), add optional ToolsDir (tools_dir) to ToolchainManifest and WorkspaceConfig, update internal/toolchain/verify.go and launcher.go to support .bin (default), bin, and configurable tool directories, and bound scanLocalBranchArtifactIDsContext in internal/core/id_history.go to unmerged/unique branch trees (--no-merged=HEAD with HEAD fallback) so ID allocation never times out on repositories with hundreds of merged local branches.
<!-- END:chosen-direction -->

## Open Questions

<!-- BEGIN:open-questions -->
None. Preserves 100% backward compatibility with existing bin/ unit and integration fixtures while enabling .bin/ (GSD default), .mcp.json command paths, and configurable tools_dir across all workspaces.
