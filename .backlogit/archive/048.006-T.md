The resolve.js tier3() uses version from package.json directly in the GitHub Releases URL. If version is invalid (e.g. 0.0.0 placeholder) the download fails with a confusing HTTP 404. Add a semver check: reject versions that are 0.0.0 or non-semver before attempting tier3.
