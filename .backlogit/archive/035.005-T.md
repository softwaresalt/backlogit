title: Preserve original dep_type when applyCrossArtifactRewrites rebuilds item_deps
updated_at: 2026-04-20T22:48:25.0744411-07:00
---

applyCrossArtifactRewrites deletes and reinserts item_deps rows for each cross-referencing artifact, always using dep_type = 'blocks'. The original dep_type value from the DB is not fetched before deletion. This currently matches the rehydration convention (which also hardcodes 'blocks'), so no data is lost today, but the pattern silently discards type information when dep types beyond 'blocks' are introduced.\n\n**Fix direction:** Either (a) document 'blocks' as the canonical dep_type convention in both rehydration and cross-ref rewrites, or (b) SELECT dep_type from item_deps before the DELETE and reuse the original value on re-INSERT.\n\n**References:** internal/core/artifact_references.go:194, internal/db/rehydration.go, review 035.001-R (finding SQ-001)
