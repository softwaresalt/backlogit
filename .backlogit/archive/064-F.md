# Branch-Level Telemetry Metrics

Add branch as the base telemetry aggregation unit with type classification, git PR enrichment, and backlogit artifact linkage:

1. `DeriveBranchType` classifier for branch naming conventions
2. `BranchProfile` aggregation grouping sessions per branch
3. Git merge-commit parsing for branch → PR mapping
4. `backlogit telemetry branch` CLI subcommand with table/json/markdown output
5. `--by branch-type` trend grouping for roll-up aggregation

## Acceptance Criteria

- `backlogit telemetry branch` outputs per-branch profiles with type, sessions, tokens, tasks, PR, feature/shipment IDs
- `backlogit telemetry trend --by branch-type` produces roll-up aggregation by branch type
- Ghost sessions are filtered from aggregation
- Branch naming conventions correctly classified (feature, stage, ship, post-merge, chore, main, other)
- All quality gates pass
