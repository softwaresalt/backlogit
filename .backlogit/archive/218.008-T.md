* In `validateManifestForProvisioning` (`internal/toolchain/launcher.go:669-675`), reject whitespace-padded or empty `manifest.WorkspaceRoot`, resolve relative `manifest.WorkspaceRoot` (when `!filepath.IsAbs(manifest.WorkspaceRoot) && filepath.VolumeName(manifest.WorkspaceRoot) == "" && !hasDriveOrUNCPrefix(manifest.WorkspaceRoot)`) against `abs` via `filepath.Clean(filepath.Join(abs, filepath.FromSlash(strings.ReplaceAll(manifest.WorkspaceRoot, "\\", "/"))))` instead of `filepath.Abs(manifest.WorkspaceRoot)`, and require `samePath(abs, declared)`.
* In `resolveProvisioningStorageDir` (`internal/toolchain/launcher.go:799-849`), check `override, hasOverride := os.LookupEnv("BACKLOGIT_WORKSPACE_DIR")` before the dual-root ambiguity check: when `hasOverride && override != ""` (treating `""` as unset), validate `override == ".backlog" || override == ".backlogit"`, create `override` if missing, and return `override` even when the other candidate directory also exists; when `!hasOverride || override == ""`, retain the existing `if hasBacklog && hasBacklogit` ambiguity refusal.
* Add exported `VerifyProposedLauncherScripts(rootPath string, m *ToolchainManifest, startPS1, startSH []byte) ([]ToolVerificationFinding, error)` in `internal/toolchain/launcher.go` (`PRRT_kwDORzozKM651Bom`): open `abs, root, err := workspace(rootPath)` (`defer root.Close()`), validate `m` via `validateManifestForProvisioning(root, abs, m)`, create a shallow copy `manifestCopy := *m` with `manifestCopy.WorkspaceRoot = abs`, verify any existing on-disk `start.ps1` / `start.sh` is a regular non-redirected file on `root`, and run `inspectLauncher(root, abs, name, string(scriptBytes), &manifestCopy)` on each non-nil `startPS1` / `startSH` slice without calling `LoadToolchainManifest` or reading `start.ps1`/`start.sh` from disk.
