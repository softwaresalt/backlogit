Two-layer hooks system for backlogit lifecycle operations: (1) internal pre/post callback registry wired into every lifecycle mutation for synchronous validation and async side-effects, and (2) external HTTP webhook dispatch for pushing change events to configured endpoints. Bridges the existing 008-DL agent-automation event layer to actual mutation events via a built-in post-hook that emits compact, versioned events to hooks_queue.jsonl.
