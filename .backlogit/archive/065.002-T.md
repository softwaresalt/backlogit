## Operator Sign-off (2026-06-25, RUN 2)

Operator confirmed the two open questions; the migration gate is **CLOSED**.

- **Q1 — `ingested_at` ownership: SEED-ONCE AT MIGRATION.** `backlogit docs migrate`
  writes an RFC3339 `ingested_at` once; re-runs preserve the existing value
  (idempotent, no churn). `graphtor-docs` may overwrite with the authoritative
  ingest time later (pipeline-enriched tier).
- **Q2 — `source` convention: REPO-RELATIVE POSIX PATH (default).** The bulk
  migration seeds `source` = repo-relative POSIX path (e.g.
  `docs/closure/045-S-...md`). **Nuance:** a full origin URI MAY be used where a
  document's source is a known online source; the validator/codec MUST accept and
  MUST NOT reject or rewrite a pre-existing full-URI `source`. Default =
  repo-relative path; full URI = allowed exception.
