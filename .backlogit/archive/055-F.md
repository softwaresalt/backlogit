Adds granular fact-table telemetry by parsing `.copilot/session-state/*/events.jsonl` files. Produces two JSONL fact tables in `.backlogit/telemetry/`: `tool-calls.jsonl` (one row per matched tool call) and `session-facts.jsonl` (one row per session with a shutdown event). Extends `backlogit telemetry report` with `--by tool` and `--by context` dimensions. Incremental checkpoint via `HarvestCheckpoint.ProcessedEventSessions`. Live harvest verified: 38,910 tool call facts across 60 sessions, 44 session facts. All quality gates pass. PR #98 on feat/054-events-fact-harvest awaiting merge.
