Introduce core.AssociateCommit covering all three representations, built as an ORDERED LIST OF DISCRETE STEPS (frontmatter scalar, commit_links upsert, JSONL append LAST) so F5 compensating envelope can wrap it later without a rewrite. Frontmatter and commit_links are genuinely idempotent and reversible. The JSONL append is NOT: events.EventWriter.AppendEvent is a plain append with no dedup key and explicitly documents ErrWriteIndeterminate on partial/fsync failure as unsafe to blindly retry. It is sequenced last so no later step ever requires compensating it; its Compensate is a documented no-op (an audit trail is never rewritten); ErrWriteNotApplied before any bytes are written leaves the whole call safely retryable; ErrWriteIndeterminate is surfaced without retry and without compensating the prior two steps, matching F5's existing indeterminate-outcome rule -- no new dedup/locking mechanism is introduced. Reload from markdown via findArtifact, never the DB fast path. Thread the caller *events.EventWriter as a parameter. Both surfaces pass a real instance: MCP passes the server's shared instance, the CLI constructs a per-invocation writer via the existing workspace writer constructor, mirroring the checkpoint disposition plan. No caller passes nil; the core function never mints one itself. Return a typed error on append failure instead of warning and continuing. Files: internal/core/commits.go.
