Implement `ParseEventFacts` in `internal/telemetry/events_harvest.go` to parse `.copilot/session-state/*/events.jsonl`. Handle the dual-schema format: old-format uses `event_type` (compaction events only, skipped); new-format uses `type` + nested `data` (used exclusively). Emit one `ToolCallFact` per matched tool-call event. Resolve MCP tool names: use `mcpToolName` (short form) when present; otherwise strip server prefix from `toolName`. Emit one `SessionFact` per `session.shutdown` event.

<!-- BEGIN:acceptance-criteria -->
- Parses new-format events (type + data) only
- Skips old-format event_type rows silently
- mcpToolName used for MCP tools; server prefix stripped from toolName when absent
- session.shutdown events produce SessionFact with full token breakdown
- Non-tool-call, non-shutdown events silently skipped
<!-- END:acceptance-criteria -->
