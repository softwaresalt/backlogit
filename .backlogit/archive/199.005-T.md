<!-- BEGIN:acceptance-criteria -->
1. With durable writes off, an append to an item log whose open fails (for
   example a read-only log path) returns an error that satisfies
   `errors.Is(err, ErrWriteNotApplied)`. The test fails on `main`, where the
   error is unclassified. Short-write classification is already covered by
   the `syncAppendLineDetailed` tests that A6 reuses.
2. Reconcile `internal/core/shipment_compensation_order_u20c3_harness_test.go:129`
   (`TestU20C3_CompensationEventFailureLeavesRecoverableIntent`) from
   `assert.False(t, errors.Is(operationErr, blerrors.ErrWriteNotApplied))` to
   `assert.True(t, errors.Is(operationErr, blerrors.ErrWriteNotApplied))` so it
   expects the `ErrWriteNotApplied` sentinel wrapped via `step error: %w`
   (A2) when `appendFast` (A6) fails to open the directory-obstructed item
   event log, while preserving `assert.False` for `ErrShipmentConflict`,
   `ErrValidation`, and `ErrNotFound` (proving `cause: %v` still isolates the
   pre-compensation cause) and preserving all recovery assertions.
3. Reconcile `internal/core/shipment_events_test.go:140`
   (`TestAppendShipmentEventErr_WriterErrorClassPassthrough/non_durable_writer_failure_stays_untagged`)
   from `assert.False(t, blerrors.IsWriteNotApplied(err), "the default non-durable path cannot prove pre-write status, got: %v", err)`
   to `assert.True(t, blerrors.IsWriteNotApplied(err), "the non-durable path tags a pre-write open failure not-applied, got: %v", err)`
   so that when `events.LogPathForItem(logsDir, "001-S")` is obstructed by a
   directory (`os.MkdirAll`) with `ws.Config.DurableWrites = false`, the
   provably pre-write `os.OpenFile` failure from `appendFast` (A6) is expected
   to carry `blerrors.ErrWriteNotApplied`, while preserving
   `assert.False(t, blerrors.IsWriteIndeterminate(err))` at line 142 and
   preserving `wrapping_preserves_sentinels/untagged_stays_untagged` at lines
   93-95 (proving `wrapShipmentAppendError` adds no class of its own to a
   genuinely untagged writer error).
