Plan unit **U2h** (partition 1). Closes a false negative in the 147.028-T / U2g context-member scan.

Files: `internal/events/checkpoint_conformance.go`, `internal/events/checkpoint_conformance_test.go`.

`encoding/json` matches struct fields case-insensitively, so every top-level member whose key satisfies `strings.EqualFold(name, "context")` is decoded into `CheckpointV1.Context`. A document carrying a lone `Context` - one occurrence, no literal `context` sibling - therefore routes its members through `CheckpointContext.UnmarshalJSON` and is subject to the identical collapse loss U2g refuses, yet a scan keyed on the literal spelling never inspects it.

Extend the read-boundary helper so the context-member walk runs against whichever top-level member the decoder would route to the modeled field, selecting it with `isFoldKeyIn` against the single-key set `{"context"}` rather than a literal string comparison. Offenders keep U2g''s reporting form, `duplicate:context.<key>`, naming the **modeled** member regardless of the spelling found on disk.

Interaction with 147.004-T / U2c: when a document carries two or more fold-equal `context` spellings, U2c already refuses it at the top level and this walk is not reached. This task closes only the lone non-canonical spelling case.

**Test-lifecycle classification (cycle-20)**: red harness plus one green-step guard. The red gate is `go test -count=1 -run '^TestU2h_' ./internal/events` and it selects exactly one failing function, because the open-namespace guard is **not committed in the harness step**. Cycle 17''s narrowed `^TestU2h_Duplicate` red gate is withdrawn for the same reason as U2g''s: P-002/P-004 gate the harness commit, not the selector. The guard lands with the implementation as `TestU2hGuard_OpenNamespaceUnderFoldVariantSpelling`.

Red verification: `go test -count=1 -run '^TestU2h_' ./internal/events`.
