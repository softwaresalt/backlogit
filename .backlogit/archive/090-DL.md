# CAP-2 (17214531): Self-installing workspace runtime executable and ignore-file wiring during init/install

## Problem Frame

<!-- BEGIN:problem-frame -->
Sandbox environments (GitHub Copilot CLI sandbox, Docker containers, GitHub workspaces) need `backlogit init` and `backlogit install` to self-install the runtime executable into the workspace storage directory root (`.backlogit/` or `.backlog/`) AND add an ignore entry for the executable in `.gitignore` or `.git/info/exclude` so the workspace versions its supported runtime binary without polluting git status.
<!-- END:problem-frame -->

## Options

<!-- BEGIN:options -->
Option A: Require manual copy of `backlogit` binary into `./bin/backlogit.exe` outside `init`/`install`. Pros: no CLI change. Cons: fails `17214531` requirement for self-installing runtime executable in `.backlogit` root during `init`/`install` and ignore-file wiring in sandbox/container environments.
Option B (Recommended): Extend `init` and add `install` alias (`internal/cli/root.go`, `internal/cli/self_install.go`) to self-install the runtime executable into the workspace storage root (`<storage_root>/backlogit[.exe]`) via handle-confined atomic replacement and idempotently record ignore entries in `.gitignore` and `.git/info/exclude` (when `.git/info` exists). Pros: satisfies `17214531` completely, preserves `TestInitCommand_*` and `TestU12_*`, and avoids `CLI Reference Drift`. Cons: requires symlink/reparse guards on both target binary and ignore files.
Option C: Install only into `./bin/backlogit.exe` and rewrite `.gitignore`. Pros: aligns with `./bin/`. Cons: violates `17214531` explicit requirement to install in `.backlogit` directory root and breaks `TestU12_NegativePinningGlobalPATHRefusalAndPathTraversalContainment` which calls `init` and asserts `./bin/backlogit.exe` is absent.
<!-- END:options -->

## Chosen Direction

<!-- BEGIN:chosen-direction -->
Option B (Selected): Support both `backlogit init` and `backlogit install` (via `Aliases: ["install"]` on `newInitCommand` in `internal/cli/root.go` plus a dedicated helper in `internal/cli/self_install.go`). During `init` or `install`, copy the resolved running executable (`os.Executable()`, with an injectable test seam `selfInstallExecutablePathFn` and handle-confined no-follow regular-file validation) into the resolved workspace storage root (`<storage_root>/backlogit.exe` on Windows, `<storage_root>/backlogit` on POSIX) using `atomicfile.ReplaceTempFile`, and idempotently ensure ignore entries (`/.backlog/backlogit`, `/.backlog/backlogit.exe`, `/.backlogit/backlogit`, `/.backlogit/backlogit.exe`) are present in `.gitignore` and (when `.git/info` exists as a real non-symlink directory) `.git/info/exclude`. When invoked as `backlogit install`, allow targeting an existing `.backlogit` or `.backlog` workspace (or defaulting to `.backlogit` when neither exists) without failing the legacy-root guard that `backlogit init` enforces.
<!-- END:chosen-direction -->

## Open Questions

<!-- BEGIN:open-questions -->
None. Existing `TestInitCommand_CreatesBacklogDirectory`, `TestInitCommand_RefusesLegacyWorkspaceRoot`, and `TestU12_NegativePinningGlobalPATHRefusalAndPathTraversalContainment` invariants are preserved.
<!-- END:open-questions -->
