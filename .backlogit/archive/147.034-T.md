Plan unit **U11** (partition 2). Declares the single seam through which every in-place checkpoint rewrite must pass.

Files: `internal/events/checkpoint_rewrite.go` (new), `internal/events/checkpoint_rewrite_test.go` (new).

Created in PR #377 cycle 17 to close gate finding **H8**. The cycle-16 gate ruled that an AST enumeration of write calls cannot fully enforce protected invariant I1, so enforcement becomes architectural.

```go
// RewriteCheckpointFile is the only sanctioned in-place rewrite path for a stored
// checkpoint. It reads the file, requires ParseCheckpoint, ValidateCheckpoint, and
// CheckConformingTopLevelNamespace to all succeed, applies mutate to the parsed
// document, and only then marshals and atomically replaces the file.
func RewriteCheckpointFile(
    ctx context.Context,
    checkpointDir, filename string,
    mutate func(*CheckpointV1) error,
) error
```

**Harness-first, declaration/behaviour split (cycle-31, P-002.1).** The compile-capable **source-shape** harness lands **first** and is observed red: `TestU11_RewriteSeamDeclared` parses `internal/events/checkpoint_rewrite.go` with `go/parser` and asserts through `go/ast` that `RewriteCheckpointFile` is declared with the exact four-parameter signature above. It compiles against the pre-declaration tree (the file does not yet exist, which is itself the assertion — not a build error, because the harness names no undeclared identifier) and fails on that assertion.

Only then does the seam land. **No stub carrying read/mutate/atomic-write behaviour is committed ahead of the harness.** The cycle-17 "declaration step lands a compilable stub performing the currently shipped behaviour" instruction is **withdrawn**: that stub was observable production behaviour landing with no observed failing test, the exact Principle II carve-out the `declaration-only` withdrawal was meant to eliminate. The seam's **behaviour** red is owned by **147.035-T / U12**, whose contract harness lands in a strictly later wave against this landed declaration and is turned green by **147.036-T / U13**. Declaration → behaviour harness → implementation, each gated by a harness that precedes it.

Scope boundary: `QuarantineCheckpoint`''s `moveNoReplace`, `CleanupCheckpoints`'' `os.Rename`, and `CreateCheckpoint`''s new-file writes are explicitly **outside** the seam.

**Test-lifecycle classification**: one source-shape red harness function plus one green-step guard. `TestU11_RewriteSeamDeclared` is red before the seam exists and green when it lands. The exported-surface reachability assertion is green on landing and is committed with the implementation as `TestU11Guard_ExportedSurfaceReachable`, never in the harness commit.

Red verification: `go test -count=1 -run '^TestU11_' ./internal/events`.
