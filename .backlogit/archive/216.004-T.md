## Objective

Memoize verified replacement-free `(ancestorSHA, descendantSHA)` commit ancestry checks in `isAncestor` (`internal/core/workspace.go`, `internal/core/shipment_gate.go`) (`76553D8D` / `097-DL` / Unit U3b) by passing `--no-replace-objects` to `git merge-base --is-ancestor` and restricting caching to complete, ungrafted repository history (invalidating/bypassing on shallow or graft boundary changes) so repeated `(memberHead, shipmentHead)` pairs across members and across the two `ShipShipment` gate passes avoid redundant subprocess executions while preserving both gate passes, verdict timing, error classification, and lock order.

## Implementation Details

1. In `internal/core/workspace.go` and `internal/core/shipment_gate.go` (`isAncestor`, lines 77-115):
   * Invoke Git with `--no-replace-objects` (`exec.CommandContext(runCtx, "git", "--no-replace-objects", "merge-base", "--is-ancestor", ancestor, descendant)`) so `refs/replace/*` refs can never alter commit ancestry evaluation or poison cached verdicts.
   * Check `if err := ctx.Err(); err != nil { return false, fmt.Errorf("ancestor check aborted: %w", err) }` FIRST before consulting the cache.
   * Restrict the thread-safe bounded `Workspace` ancestry cache (capped at 4,096 entries under a mutex, keyed by `strings.ToLower(ancestor) + "|" + strings.ToLower(descendant)` when both `isGitObjectName(ancestor)` and `isGitObjectName(descendant)` are full 40/64-hex commit SHAs) **strictly to complete, ungrafted repository history**: inspect `.git/shallow` and `.git/info/grafts` under the resolved repository `.git` directory on every lookup and store; when either `.git/shallow` or `.git/info/grafts` exists (or cannot be confirmed absent via `os.IsNotExist`), clear/invalidate any cached entries and bypass the cache completely (so deepening a shallow repository or modifying grafts never retains a stale `exit 1` or `exit 0` verdict). When both `.git/shallow` and `.git/info/grafts` are absent, memoize only definitive `exit 0` (`true, nil`) and `exit 1` (`false, nil`) outcomes when `runCtx.Err() == nil` (never caching `exit 128` or exec/timeout errors).
2. Preserve both `gateShipmentCompletion` passes in `ShipShipment` (`shipment_lifecycle.go:605,629`), member status/event-log reloads, `headSHABounded` drift checks, error classification, and lock order unchanged.
