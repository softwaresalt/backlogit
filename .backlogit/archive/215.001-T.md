## Objective

Harden `WriteToolchainManifest` final replacement in `internal/toolchain/launcher.go` (`C5189EAF` / `094-DL` / Unit U1) to perform directory-handle-relative replacement via `internal/atomicfile` (`atomicfile.ReplaceTempFileInRoot(storageHandle, filepath.Join(abs, storageDir), tmpName, "toolchain.yaml", true)`), preserving Windows `MoveFileExW` sharing-violation retry semantics, permanent-denial detection, `MOVEFILE_WRITE_THROUGH` durability, and `ErrWriteNotApplied` error classification while preventing any parent storage-directory swap between validation and replacement from redirecting writes outside the workspace and supporting target workspaces that differ from process CWD.

* **Execution posture**: `test-first` (P-002.1 compile PASS + runtime assertion RED before production edit)

## Implementation Details

1. In `internal/atomicfile/atomicfile.go`, export `ReplaceTempFileInRoot(root *os.Root, dirAbs, tmpRel, dstRel string, durable bool) error`:
   * Validate `root != nil`, `filepath.IsAbs(dirAbs)`, and clean single-component (or root-relative) `tmpRel` and `dstRel` names; inspect `root.Lstat(tmpRel)` (requiring a regular non-reparse file) and `root.Lstat(dstRel)` (requiring either `os.ErrNotExist` or an existing regular non-reparse file), and open the pinned directory handle `dirFile, err := root.Open(".")` (closing `dirFile` on return).
   * Execute directory-handle-relative replacement bound to `dirFile` / `root` while preserving `internal/atomicfile`'s platform retry and durability semantics:
     * On POSIX (`runtime.GOOS != "windows"`), perform handle-relative replacement on `dirFile` (and `dirFile.Sync()` when `durable` is true, returning `ErrWriteIndeterminate` if post-rename directory fsync fails and `ErrWriteNotApplied` if pre-rename or replacement fails) without re-resolving parent pathnames on disk.
     * On Windows, verify `dirFile` (`windows.Handle(dirFile.Fd())`) via `GetFileInformationByHandle` (directory, non-reparse) and resolve its live kernel path via `windows.GetFinalPathNameByHandle`, verifying that `dirFile`'s live kernel path still matches the canonical `EvalSymlinks(dirAbs)` path of the caller-supplied verified absolute directory path `dirAbs` (never `root.Name()`, because nested `*os.Root` handles opened via `root.OpenRoot(storageDir)` have a relative `Name()` like `".backlogit"` that would erroneously resolve against process CWD; failing closed with `blerrors.ErrWriteNotApplied` / `blerrors.ErrValidation` if the parent directory was swapped, renamed, or redirected after `root` was opened) and that `root.Lstat(tmpRel)` / `root.Lstat(dstRel)` match the target handles inside `dirFile` before invoking `atomicReplace(tmpPathInDir, dstPathInDir, durable)` (`MoveFileExW` with `MOVEFILE_REPLACE_EXISTING` and `MOVEFILE_WRITE_THROUGH` when `durable` is true, 6-attempt transient `ERROR_SHARING_VIOLATION` / `ERROR_ACCESS_DENIED` exponential backoff, permanent-denial check on `FILE_ATTRIBUTE_READONLY | FILE_ATTRIBUTE_DIRECTORY`, and `blerrors.ErrWriteNotApplied` wrapping).
2. In `internal/toolchain/launcher.go` (`WriteToolchainManifest`, lines 830-885), retain `*os.Root`-confined temp file creation (`storageHandle.OpenFile(tmpName, os.O_CREATE|os.O_EXCL|os.O_WRONLY, 0o600)` using `toolchainManifestTempSeq`), `os.SameFile(openedStat, lstatAfterOpen)`, `file.Sync()`, and `file.Close()`. Immediately before final replacement, re-verify `storageHandle.Lstat("toolchain.yaml")` + `core.IsSymlinkOrReparsePoint` so a destination swapped for a symlink, reparse point, or directory during temp write is rejected with `corerrors.ErrValidation`.
