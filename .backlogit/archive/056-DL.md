# Backlogit MCP startup timeout in engram workspace

## Problem Frame

<!-- BEGIN:problem-frame -->
MCP initialize in engram exceeds the Copilot 60s timeout because MigrateDBOnlyLinks rescans artifact trees per link source (91s vs 20s baseline).
<!-- END:problem-frame -->

## Options

<!-- BEGIN:options -->
- Option A: Increase timeout and defer code changes
- Option B: Build canonical artifact index + diagnostics + critical-path refactor
- Option C: Defer to maintainers with issue-only handoff
<!-- END:options -->

## Chosen Direction

<!-- BEGIN:chosen-direction -->
Proceed in backlogit codebase with Option B; classify as a reliability performance bug with architectural impact and no DB reset.
<!-- END:chosen-direction -->

## Open Questions
