New package internal/gateproof. The signed envelope carries magic, purpose (task|shipment), schema, alg, key_id, workspace_id, item_id, event_type, ran, actor, timestamp_utc, head_sha, report_digest, counter, and (shipment only) manifest_digest — ALL inside the MAC. Only the MAC bytes are stored outside. API is Sign(env, key) (string, error) and Verify(env, mac, key) error returning ErrProofInvalid or ErrProofUnverifiable; no dual-return enum. Use internal/canonical.Canonicalize, crypto/hmac, crypto/sha256, hmac.Equal, and fixed-size MAC decoding. Files: internal/gateproof/gateproof.go, internal/gateproof/doc.go.
