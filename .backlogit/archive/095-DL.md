# CAP-2 (1CED4AD6): Repair ExecGitRunner.Verify ambient TEMP/TMPDIR Git discovery ceiling for repositories rooted at TEMP

## Problem Frame

<!-- BEGIN:problem-frame -->
Deferred scope expansion `1CED4AD6` from `211.022-T` (`U1k`, `211-F`, `212-S`, PR #645 thread `PRRT_kwDORzozKM615Onq`): `withTempGitCeiling` in `internal/core/gate/baseref.go:154-184` synthesizes `GIT_CEILING_DIRECTORIES=os.TempDir()` whenever `g.Dir` is a subdirectory of `os.TempDir()`. Because Git does not inspect `.git` inside a directory listed in `GIT_CEILING_DIRECTORIES`, when `TMPDIR` is set to a valid repository root (`/work/repo` with `/work/repo/.git`) and `g.Dir` is a nested workspace (`/work/repo/subproject`), the synthesized ceiling blocks Git from discovering `/work/repo/.git`.
<!-- END:problem-frame -->

## Options

<!-- BEGIN:options -->
Option A: Remove `withTempGitCeiling` from `ExecGitRunner.Verify`. Pros: allows repos rooted at `TMPDIR`. Cons: breaks `TestU1k_ExecGitRunnerVerifyIsolatesTempDirFromOuterCheckout` and re-exposes temporary non-repo directories under `TEMP` to ancestor checkout leakage.
Option B (Recommended): Refine `withTempGitCeiling` in `internal/core/gate/baseref.go` to check whether `tempDir` / `evalTemp` itself contains `.git` (`os.Lstat(filepath.Join(evalTemp, ".git")) == nil`). When `tempDir` is itself a repository root, set the ceiling to `filepath.Dir(tempDir)` (and `filepath.Dir(evalTemp)`) so Git can discover `tempDir/.git` from nested subdirectories (`/work/repo/subproject`) while still blocking upward traversal into any ancestor checkout above `tempDir`. When `tempDir` has no `.git`, retain `tempDir` as the ceiling. Pros: solves Copilot's `TMPDIR=/work/repo` + `/work/repo/subproject` case while preserving 100% of U1k ancestor-checkout isolation and explicit caller `GIT_CEILING_DIRECTORIES` precedence. Cons: none.
Option C: Walk all directories between `dir` and filesystem root in Go before running Git. Pros: full custom control. Cons: unnecessary complexity when checking `os.Lstat(filepath.Join(tempDir, ".git"))` at the ceiling boundary directly resolves the exact boundary condition.
<!-- END:options -->

## Chosen Direction

<!-- BEGIN:chosen-direction -->
Option B (Selected): Update `withTempGitCeiling` in `internal/core/gate/baseref.go` (lines 154-184) so that when `dir` is nested inside `tempDir` / `evalTemp` AND a valid Git repository marker (`.git` directory or gitfile) is rooted directly at `tempDir` / `evalTemp` (`hasGitEntry(tempDir) || hasGitEntry(evalTemp)`), the synthesized `GIT_CEILING_DIRECTORIES` entry uses the parent directory (`filepath.Dir(tempDir)` / `filepath.Dir(evalTemp)`) rather than `tempDir` itself (or omits the ceiling when `filepath.Dir(evalTemp) == evalTemp`). When no `.git` exists at `tempDir`, preserve `ceiling = tempDir` so temporary non-repository directories inside `TEMP` remain isolated from any ancestor checkout above `TEMP`.
<!-- END:chosen-direction -->

None. Both `TestU1k_ExecGitRunnerVerifyIsolatesTempDirFromOuterCheckout` (`tempRoot` without `.git` inside `outer` repo) and the new nested-workspace-at-`TMPDIR`-repo test (`TMPDIR=/work/repo`, `.git` at `/work/repo/.git`, workspace at `/work/repo/subproject`) pass simultaneously.
