Define a streaming `LogParser` adapter interface with callback-based event emission and implement `CopilotCLIParser` for Copilot CLI process logs. Parse `cli.model_call` events (token counts, model, session_id, duration) and `cli.tool_call` events (tool_name, model_call_id, duration). Define `ModelCall`, `ToolCall`, `TelemetryEvent`, and `EventKind` types in `types.go`.

Files: `internal/telemetry/parser.go`, `internal/telemetry/types.go`
Tests: `internal/telemetry/parser_test.go`
Patterns: `internal/stash/jsonl.go`, `internal/events/stream.go`
Dependencies: none

Verification:
- Contract tests parse captured log samples (3+ model calls, 5+ tool calls)
- Malformed lines skipped with slog warning, not fatal
- Empty files return no events via callback
- Edge cases: corrupt JSON, truncated lines, mixed non-telemetry output
