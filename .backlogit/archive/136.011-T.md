Register backlogit_abandon_checkpoint and backlogit_quarantine_checkpoint routed through the same shared core functions. Because MCP carries NO authenticated operator identity, operator is a REQUIRED tool parameter on both tools and is never inferred. Map each U3 sentinel to a structured machine-readable error: stable code, the offending input, a CLASS-DERIVED retryable flag (true for not-applied, false for a validation or confinement refusal, and a distinct indeterminate outcome carrying recovery guidance rather than a bare retryable:false), and operator remediation.
