Create package.json manifests for @backlogit/linux-x64, linux-arm64, darwin-x64, darwin-arm64, win32-x64 with os/cpu fields for npm platform filtering.

<!-- BEGIN:acceptance-criteria -->
- Each package.json passes `npm pack --dry-run` without errors
- os/cpu fields match expected platform filters
- Version placeholder is documented for CI substitution
<!-- END:acceptance-criteria -->

<!-- BEGIN:description -->
Create `npm/platforms/` with 5 platform package directories, each containing a minimal `package.json`:

```json
{
  "name": "@backlogit/{platform}-{arch}",
  "version": "{synced-from-go-release}",
  "os": ["{platform}"],
  "cpu": ["{arch}"],
  "preferUnplugged": true,
  "bin": { "backlogit": "bin/backlogit" },
  "files": ["bin/"]
}
```

Platforms: linux-x64, linux-arm64, darwin-x64, darwin-arm64, win32-x64.
The `bin/` directory is populated by CI — repo packages contain only manifests.
<!-- END:description -->
