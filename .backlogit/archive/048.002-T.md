Create the @backlogit/backlogit-mcp npm package with three-tier binary resolver: PATH check → npm optional deps → GitHub Releases download with SHA256 verification.

<!-- BEGIN:acceptance-criteria -->
- Unit tests for resolve.js cover all 3 tiers with mocked fs/network
- `npx @backlogit/backlogit-mcp version` returns backlogit version
- Fallback download creates cached binary with correct permissions
- SHA256 verification rejects tampered binaries
- First-run latency documented (addresses plan review P2-2)
<!-- END:acceptance-criteria -->

<!-- BEGIN:description -->
Create `npm/backlogit-mcp/` with:

1. `package.json`: name `@backlogit/backlogit-mcp`, bin entry `bin/backlogit-mcp`, postinstall `node install.js`, optionalDependencies for 5 platform packages.
2. `lib/resolve.js`: Hybrid resolver:
   - Tier 1 (PATH): `which`/`where` finds `backlogit`, validates with `backlogit version`
   - Tier 2 (npm): `require.resolve('@backlogit/{platform}-{arch}/bin/backlogit')` using `process.platform` + `os.arch()`
   - Tier 3 (GH download): fetch from `github.com/softwaresalt/backlogit/releases/download/v{version}/backlogit-{goos}-{goarch}[.exe]`, cache at `~/.cache/backlogit/bin/`, verify SHA256
3. `bin/backlogit-mcp`: Entry point — calls `resolve()` then `execFileSync(binary, argv.slice(2), {stdio:'inherit'})`
4. `install.js`: Postinstall pre-resolves binary (tiers 2+3 only; tier 1 is runtime)

Platform mapping: linux/x64→linux-amd64, linux/arm64→linux-arm64, darwin/x64→darwin-amd64, darwin/arm64→darwin-arm64, win32/x64→windows-amd64.exe
<!-- END:description -->
