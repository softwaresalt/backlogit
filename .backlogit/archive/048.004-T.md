<!-- BEGIN:description -->
Extend `.github/workflows/release.yml` with two new jobs after the existing `build` job:

1. **npm-package**: Downloads build artifacts, copies each platform binary into `npm/platforms/{platform}/bin/`, sets version from Git tag in all package.json files, uploads packaged npm directories.
2. **npm-publish**: Downloads packaged npm artifacts, runs `npm publish --access public` for each platform package first, then the main wrapper. Uses `NPM_TOKEN` secret.

Existing build, changelog, and release jobs remain unchanged. npm publish failures MUST NOT block GitHub Release (addresses plan review P3-1 — use `continue-on-error: true` or separate needs chain).

Version sync: all npm packages use semver from Git tag (strip `v` prefix). Main wrapper pins optionalDependencies to exact same version.
