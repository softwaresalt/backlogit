# Stash Hygiene Protocol for Stage Agent

## Problem Frame

<!-- BEGIN:problem-frame -->
Stage agent guidance lacks a standard stale-stash pruning step. Agents fall back to raw stash.jsonl edits despite age_days, stash remove, and stash edit being available natively. The compound doc on stash staleness is outdated.
<!-- END:problem-frame -->

## Options

<!-- BEGIN:options -->
1. Add a stash hygiene phase to stage.agent.md with age-based triage using native tools
2. Build automated pruning into backlogit core — over-engineered for current needs
3. Leave as informal guidance — perpetuates ad-hoc scripting
<!-- END:options -->

## Chosen Direction

<!-- BEGIN:chosen-direction -->
Option 1: Add a structured stash hygiene step to stage.agent.md that checks age_days on all active entries, flags entries older than a configurable threshold, and uses backlogit_stash_remove or backlogit_stash_edit to handle them. Refresh the compound doc to reflect current tooling.
<!-- END:chosen-direction -->

## Open Questions

<!-- BEGIN:open-questions -->
None — the tooling surface already exists. This is primarily an agent protocol and documentation update.
<!-- END:open-questions -->

## Notes

<!-- BEGIN:notes -->
age_days is already computed and returned by stash_get/fetch_stash. backlogit_stash_remove and backlogit_stash_edit MCP tools already exist. The compound doc at docs/compound/workflow-issues/stash-staleness-requires-custom-scripting-2026-04-09.md needs refresh to mark solutions as implemented.
<!-- END:notes -->
