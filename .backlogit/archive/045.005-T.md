Implement four checkpoint lifecycle functions in internal/events/checkpoint_lifecycle.go. Test-first. Depends on Unit 1 (schema) and Unit 3 (config for retention).

Files: internal/events/checkpoint_lifecycle.go, internal/events/checkpoint_lifecycle_test.go

Functions (all take ctx context.Context as first parameter; all filename params enforce basename-only + filepath.Abs containment):

1. ListCheckpoints(ctx, checkpointDir, filter CheckpointFilter) ([]CheckpointSummary, error)
   - Read checkpoint-*.json files; quarantine unparseable to .backlogit/quarantine/checkpoints/
   - Apply filters: consumer_id (agent), status, shipment_id, feature_id, max_age
   - Return summaries sorted by created_at descending

2. GetCheckpoint(ctx, checkpointDir, filename string) (*CheckpointV1, error)
   - Validate filename is basename-only; return ErrCheckpointNotFound on missing, ErrCheckpointInvalid on validation failure

3. ResolveCheckpoint(ctx, checkpointDir, filename string) error
   - Set status=resolved, updated_at=now; write back atomically via syncWriteFileAtomic
   - Idempotent: return nil if already resolved (D7)

4. CleanupCheckpoints(ctx, checkpointDir string, retentionDays int) (CleanupResult, error)
   - Guard retentionDays <= 0 with error; archive resolved/stale files to .backlogit/archive/checkpoints/
   - Windows-safe rename; crash-safe rollback on archive failure

Patterns: hook_checkpoint.go (file I/O + atomic writes), fsutil.go (syncWriteFileAtomic)

Verification: go test ./internal/events/... passes with filter, quarantine, path-traversal, concurrent access tests.
