# Adjudicate 60D799D9 Git discovery boundary & fixture contracts as Wave-1 prerequisites U1c/U1d and disposition 96F1DFFD in 211-F / 212-S

## Problem Frame

<!-- BEGIN:problem-frame -->
After U1b (211.008-T, commit 834972ab9108321c79c155022c5daaa9a9857d7f) repaired Windows Go 1.24 nested os.Root runtime path validation and cleared all ./internal/cli tests (324.828s unfiltered PASS), the Wave 1 Step 4.6 unfiltered full-suite gate (go test -timeout=30m ./...) under workspace-contained TEMP (C:\Source\GitHub\backlogit\bin\_authoringtmp) surfaced two distinct Git-discovery failure sub-families captured in 60D799D9 (plus intermittent Windows replacement observations captured in 96F1DFFD):
1. Family 1A (Narrow Production Boundary Bug): TestPlanArtifactMove_StrategyDetection/empty_git_directory_fails_closed (internal/core/archive_git_test.go:127) and TestInGitWorktreeBounded subcase (e) (internal/core/shipment_gate_ancestry_test.go:152) create an empty .git directory at the workspace root and assert fail-closed error return. Both planArtifactMove (internal/core/archive.go:843-855) and inGitWorktreeBounded (internal/core/shipment_gate.go:180-214) check for a present-but-broken .git directory only on the err != nil (exit 128) branch. Because Git's is_git_directory ignores an empty .git directory and continues walking parent directories, whenever an ancestor Git repository exists above workspaceRoot (nested workspaces in production or contained TEMP in tests), git rev-parse exits 0 with the ancestor's worktree root, bypassing the err != nil guard and failing open.
2. Family 1B (Non-Hermetic No-Usable-Repo Test Fixtures): TestInGitWorktreeBounded subcase (b) (shipment_gate_ancestry_test.go:117), TestHeadSHABounded (shipment_gate_headdrift_test.go:76), TestRepairShipmentMemberEvidence_NoRepoHead_Errors (shipment_repair_test.go:248), and TestU163_002_ExecGitRequiresARepositoryDirectory (internal/policyengine/u163_002_record_test.go:215) use plain t.TempDir() directories with no .git boundary. When TEMP resides inside the repository checkout, ordinary Git walks up and discovers the outer checkout (HEAD 834972a), whereas production runners rightly strip ambient GIT_CEILING_DIRECTORIES.
3. Family 3 (96F1DFFD Windows Observations): TestNormalizeBlockedShipmentForRecovery_UnrelatedPoisonRemainsDiagnosable and TestUCYA1_ShipmentLifecycleStepErrorsKeepSentinelChain/U20C5_commit_journal saw transient Windows AccessDenied during the parallel full run but passed 1/1 in Ship's isolated Windows probe (3.668s and 2.661s), and the internal/core 30m0s alarm fired 1s into TestCheckChildrenTerminal_AllDone_NoError after steady progress across 1,184 top-level tests.
