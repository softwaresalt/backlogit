## 126-S — Formal Gate Shipment-Completion HEAD Guard (repository-ref CAS) (COMPLETE, shipped/archived)

* Task `106.033-T` (repository-ref CAS/guard for the post-manifest-signing
  HEAD-drift window in `ShipShipment`) staged as single-item shipment `126-S`
  by Stage (PR #357), then implemented and shipped by Ship (implementation
  PR #358 → `49d742fc`; closure PR #359 → `c9c010d1`). All three merges
  verified as true two-parent merge commits.
* **Design decision**: implemented option **(a)+(c)** from the staging
  memory's three candidates — an additional CAS-style HEAD re-check
  immediately before the shipment-status persist
  (`moveShipmentStatusWithHeadGuard`, replacing
  `moveShipmentStatusWithTopLevel`), paired with accepting the
  further-narrowed (not eliminated) residual window as a documented,
  monitored limitation. Option (b) (git-level advisory ref-lock) was
  explicitly NOT implemented — materially larger design surface, deferred.
* `gateShipmentCompletion` now returns `(shipmentHead string, err error)` so
  `ShipShipment` can thread the already-validated-stable HEAD into the final
  guard call. An empty `expectedHeadSHA` leaves the new guard inert for
  every other call site (`ClaimShipment`, tests) — only the `active→shipped`
  transition passes a non-empty head.
* TDD: `TestShipmentGate_HeadDriftBetweenGateCheckAndPersist_Refuses`
  (RED-first, injects a concurrent commit via a `HookMoveShipmentStatus`
  pre-hook) and `TestShipmentGate_NoHeadDriftBeforePersist_ShipsCleanly`
  (happy-path regression) — **note for future sessions**: this second test
  name recurred during the 128-S closure session's `go test ./...` run as a
  Windows environment flake (panic in a hook-event `os.OpenFile` call after
  ~616s of full-suite runtime); it passed cleanly in isolation both then and
  presumably here — treat full-suite-only failures of this specific test as
  suspect-environment, not regression, unless they also reproduce in
  isolation.
* 2 Copilot review rounds, 6 findings, all addressed or explicitly deferred
  with rationale (compensating rollback of `completeReleaseScope`/
  `returnUnreleasedFeatureItems`/`setArtifactStatus` on a late `ShipShipment`
