## Technical Reference

### The Bug Fixed
`AdoptItem` rewrites the adopted artifact's ID in DB + files, but does NOT update
other artifacts' Markdown frontmatter that reference the old ID. The next
`backlogit sync` (full DELETE+rebuild from Markdown) reverts the corrected DB
edges because stale Markdown is the source of truth.

### The Fix
`findCrossArtifactReferences` walks all `.md` files before the transaction,
collecting artifacts that reference oldID. `applyCrossArtifactRewrites` rewrites
those files atomically and syncs DB edges inside the adoption transaction.
