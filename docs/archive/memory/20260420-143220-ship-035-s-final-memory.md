## Build Decisions and Rationale

### go.mod directive bump prevention
Running `go get golang.org/x/term` (unpinned) fetched v0.42.0, which transitively
depends on x/sys@v0.43.0. x/sys v0.43.0 declares `go 1.25.0`, bumping our module
directive. Fix: pin both `x/term@v0.38.0` AND `x/sys@v0.39.0` explicitly; manually
reset the directive to `go 1.24.0` (go mod tidy never lowers it once bumped).
Compound learning captured at:
`docs/compound/config-issues/go-xterm-unpinned-dep-bumps-go-directive-2026-04-20.md`

### isTerminal unexported (white-box test)
`isTerminal` is package-private. The test file must use `package cli` (not
`package cli_test`). Two paths tested: `bytes.Buffer` (not *os.File → false) and
`os.Pipe()` read end (pipe fd → false).

### Review artifact parent constraint
Creating a review artifact with `parent_id: "035-S"` (shipment) fails — review
types require a non-shipment parent. Used `parent_id: "033-F"` instead; archived
parent doesn't block child creation. Artifact ID: `033.002-R`.

### Workflow permissions layering
CI security instructions require BOTH workflow-level `permissions: contents: read`
(safety net for future jobs) AND explicit job-level declarations. Copilot correctly
caught the missing workflow-level default in 033.011-T's original fix.
