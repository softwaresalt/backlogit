## Key Decisions

1. **DB-before-JSONL ordering** (041.002-T): Stash harvest now runs all DB ops before JSONL rewrite so a DB failure leaves JSONL untouched and artifact file can be cleanly removed. Tradeoff: if writeStashEntries fails after DB ops, DB shows "harvested" but JSONL shows "active" until next sync — acceptable transient inconsistency.

2. **DeleteArtifact temp file naming**: Changed from `foo.md.deleting` to `foo.deleting.md` to preserve .md discoverability for crash recovery and rehydration. Copilot reviewer correctly identified that invisible orphan files are harder to recover.

3. **Archive restore unconditional**: Removed `currentPath == archivePath` guard — always write raw bytes back to currentPath on DB failure. When paths are equal (already-archived items), the file may have been overwritten with archive frontmatter, so restoration is needed regardless.

4. **Best-effort DB rollback in stash.go**: Added `db.DeleteItemCascade` calls before `os.Remove` in UpsertStashEntry/LinkStashEntry failure paths to prevent orphaned DB rows pointing to removed artifact files.
