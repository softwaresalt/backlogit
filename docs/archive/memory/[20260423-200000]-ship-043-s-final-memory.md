## Key Technical Decision

**The real bug**: ALL `.backlogit/archive/*.md` files lack a `level:` frontmatter field. `ArtifactFromFrontmatter` leaves `Level` as 0 when the field is absent. The original guard `info.level == 1` was therefore always false — the orphan check was silently broken for the entire archive.

**Fix**: `levelFromID()` counts dots in the numeric ID prefix (`001-T` → 1, `001.001-T` → 2). `effectiveLevel` falls back to this when frontmatter `Level` is zero.

**Test discipline**: Fixtures for legacy root artifacts must NOT include `level:` or `hierarchy_path:` fields — real archive files never have them. Explicit `level: 1` in test fixtures masks the `levelFromID()` code path entirely.
