- **Decision and rationale — Option (a) selected**:
  - **Semantic correctness**: In `EventWriter.appendFast` (`internal/events/stream.go:332-353`, routed by `199.006-T` / `1ded9cbf` through `syncAppendLineDetailed` in `internal/events/fsutil.go:26-53`), an `os.MkdirAll` or `os.OpenFile(path, os.O_CREATE|os.O_APPEND|os.O_WRONLY, 0o644)` failure occurs before any writable file handle is returned and before `f.Write(data)` is ever invoked. Zero bytes can have been written to the item log regardless of `w.durable`.
