## What shipped

Converged two divergent per-item JSONL event-log parsers onto a single
skip-with-warning policy via a shared `events.ParseEventLine` helper:

- `internal/events/reader.go:ReadAllEvents` — previously **silently** skipped a
  malformed line (silent data loss).
- `internal/db/rehydration.go:parseItemLogFile` — previously `return nil, err`,
  causing the caller to drop **all** of the item's events (bricked rehydration).

Both now skip only the malformed line, retain valid events, and emit a
structured `slog.Warn` (`item_id`, `path`, 1-based `line`, `error`). Removed the
now-unused `encoding/json` import from `rehydration.go`. `go vet` clean.

## Key decisions

- **Policy A — skip-with-warning** (from deliberation), **Approach 2 — shared
  helper** (single source of truth for blank/malformed/valid classification).
- Log key aligned to `item_id` (Copilot consistency comment) to match the
  existing `rehydration.go` convention.
- Only deterministic per-record parse errors skip; transient/structural failures
  (`os.ReadFile`/`os.Open`, `scanner.Err()`, `bufio.ErrTooLong`) still propagate
  — a retryable failure is never masked as a permanent skip.
