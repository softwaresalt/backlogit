## Key decisions / rationale (durable)

- **U2 fail-loud, no auto-regen:** guard returns `ErrIDCollision` rather than advancing
  past the canonical max. Auto-regen explicitly out of scope; keeps the sentinel testable.
- **U3 discriminator = id AND title:** distinguishes a foreign occupant (refuse) from the
  legitimate 060.002-T half-archive recovery of the SAME item (allow). `currentPath ==
  archivePath` is never a collision. Guard hoisted before pre-archive hooks → refusal has
  zero side effects.
- **U4 observational only:** one `slog.Warn` per duplicated id before Phase 2; atomic
  clear+rebuild byte-for-byte unchanged (honors `atomic-rehydration-sqlite-transaction`).
- **Doctor refactor:** consumes the single shared `scanCanonicalArtifacts` walk;
  `FindingRootIDCollision` additive to `FindingDuplicateID`; level-2+ duplicates excluded;
  sorted ids for determinism.
