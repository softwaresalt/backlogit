## Key learnings

* A `backlogit_ship_shipment` MCP timeout means the result is unknown. The
  handler runs on the request context, so the call may also have been
  cancelled. In 195-S and 196-S the call kept running. Observe until
  quiescence, then classify the state from evidence; never retry or restore
  (`docs/compound/2026-10-06-ship-shipment-mcp-timeout-result-unknown.md`).
* CI `pipeline-topology (ambient)` fails with
  `PREDECESSOR_CLOSURE_INCOMPLETE` because PyPI `autoharness==1.5.0` lacks the
  `dag-root` waiver that the local build honours. The check is non-required and
  tracked as `F88FE051`.
* On this CRLF checkout, check gofmt against LF-normalized blobs.
  `gofmt -l .` gives false positives.
* U6 manifest checksums are SHA-256 over LF-normalized content with a trailing
  newline.
