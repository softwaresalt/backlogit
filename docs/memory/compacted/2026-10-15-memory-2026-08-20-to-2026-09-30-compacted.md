  proof-of-concept workspaces. Scoped to Azure DevOps only for V1.
* Decisions:
  * V1 is an explicit, one-way, plan-then-apply push. No pull, no bidirectional
    merge, no lifecycle-hook writes, no remote deletion. Keeps remote state derivable
    from Markdown.

    becoming remote work items.

    `integrations/azure-devops.yaml`. No hardcoded Feature, User Story, or Task hierarchy.

    drift override.

    `internal/core` (orchestration and persistence).
  * Jira and GitHub get no implementation units until the Azure DevOps path is validated.

  confidence) and `docs/archive/plans/2026-08-20-azure-devops-sync-plan.md`.

  frozen-plan, and orphan-reporting inconsistencies. All P0 and P1 findings were fixed.
* Failed or rejected: porting either Python proof of concept wholesale; reusing the
  inbound `migration.yaml` for outbound sync; correlating by mutable artifact ID;
