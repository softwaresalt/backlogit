## Key Decisions

- `_txlock=immediate` in DSN (not `sql.LevelReadCommitted`) is the correct
  mechanism for `modernc.org/sqlite` to emit `BEGIN IMMEDIATE`
- `RetryWrite` must wrap entire `BeginTx→work→Commit` units, not single statements
- `defaultRetryDelays` unexported to prevent external mutation affecting all callers
- `time.NewTimer` + `defer Stop()` instead of `time.After` to avoid goroutine leak
- Batched rehydration: old single-tx atomicity traded for smaller retry windows;
  documented as acceptable since `backlogit.db` is ephemeral
