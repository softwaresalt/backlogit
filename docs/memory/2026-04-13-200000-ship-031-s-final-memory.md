## Key Decisions

* `HarvestOptions` lives in `checkpoint.go` (colocated with incremental semantics), not `harvest.go`
* `Since` is `*time.Time` (pointer) — `nil` means no filter; callers parse string then pass `&t`
* `Limit` applies after aggregation in `GenerateReport` — must compute over all sessions before slicing
* `GroupBy` validation: only `"session"` and `"server"` are valid; `"model"` and `"tool"` return errors early
* `ALTER TABLE ADD COLUMN` swallows `duplicate column name` because SQLite has no `IF NOT EXISTS` support for columns
* Windows atomic rename requires `os.Remove` before `os.Rename` (unlike POSIX)
