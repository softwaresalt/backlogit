## Key Technical Decisions

### Ghost rehydration (019.004-T)
- Root cause: `Rehydrate()` used `INSERT OR REPLACE` but never cleared `items` first
- Fix: `DELETE FROM items` + `DELETE FROM item_deps` before WalkDir
- FTS5 (`items_fts`) preserved via `items_ad` AFTER DELETE trigger — no manual FTS cleanup needed

### Stash locking (019.007-T)
- `EnsureStashFile` must be called INSIDE the lock scope — it calls `writeStashEntries` which uses
  `os.Rename()`, which fails on Windows if any other goroutine has the target open
- Pattern mirrors `memoriesMu` in `SaveMemory` (Pattern 8, feature-001-core-implementation.md)
- `go test -race` unavailable on this environment (CGO_ENABLED=0); tests pass without -race flag

### LIMIT/OFFSET gap (P2, tracked as 001-T)
- `QueryItems` appends LIMIT/OFFSET with no preceding ORDER BY — non-deterministic pagination
- SQLite does not guarantee row order without ORDER BY; fix is ORDER BY id ASC before LIMIT
