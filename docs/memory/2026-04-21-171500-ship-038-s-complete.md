## Key Technical Decisions

* **Incremental diff via manifest**: `BuildManifest` snapshots file paths and mtimes;
  `ComputeDiff` returns changed/added/removed sets; `ShouldFallback` gates full-
  rehydration when diff size exceeds threshold.
* **CAS version scheme**: `manifestVersion uint64` on `Server` struct prevents
  concurrent `handleMergeSync` calls from regressing the manifest to a staler
  snapshot. Seeded in `ensureWorkspace` via `BuildManifest`.
* **Additive, non-disruptive**: Full `backlogit_sync_index` rehydration path is
  unchanged; `backlogit_merge_sync` is purely additive.
