## Key decisions

* `rehydrateStash` treats `stash.jsonl` as authoritative only when non-empty;
  empty JSONL (written by `backlogit init`) falls back to `.stash.md`. This
  prevents silent data loss when `init` is run on a legacy workspace.
* `UpsertItemsTx` is a new exported API but not yet wired into `ReturnBlockedItem`.
  The production path still uses compensating rollback. Wiring is deferred as
  a follow-up item.
* `ReconcileCompletionScope` uses `setArtifactStatus` per child, which triggers
  `cascadePersistedParentStatuses` per call. This produces transient spurious
  JSONL events on the parent but final state is always correct. Accepted as
  advisory; fixing requires a batch cascade refactor.
* Copilot review comment C4 (use `setArtifactStatus` for parent setup in
  completion-scope tests) was intentionally declined. The tests need a bypass
  path to create the inconsistent precondition they are designed to repair.
