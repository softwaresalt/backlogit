* **Pre-transaction scan**: `findCrossArtifactReferences` runs before `BeginTx` to
  avoid holding a write lock during filesystem I/O. Accepted trade-off: TOCTOU
  window (035.004-T tracks context propagation for cancellation).
* **Single-read parse**: eliminated double file read by using `models.ParseFrontmatter`
  + `models.ArtifactFromFrontmatter` in one pass.
* **dep_type preservation**: SELECT-before-DELETE pattern in `item_deps` preserves
  the existing `dep_type` rather than defaulting everything to `"blocks"`.
* **Atomic rollback**: commit-failure rollback uses `WriteArtifactFile` (tmp+rename)
  rather than bare `os.WriteFile`.
